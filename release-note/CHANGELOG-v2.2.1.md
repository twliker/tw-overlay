# 📦 TW-Overlay Release Note - [Mandatory Update] v2.2.1 (2026-08-03)

이번 v2.2.1 버전은 버프 타이머의 잘못된 시간 갱신을 줄이고, 경험치 HUD의 위치 안정성을 보완한 버그 수정 업데이트입니다.

---

## 🛠️ Fixed (버그 수정)

- **이자벨의 비법(대미지) 타이머 오탐 방지**
  - 마을 이동 등으로 효과 적용 문구가 다시 기록되어도, 이미 실행 중인 타이머는 갱신되지 않습니다.
  - 타이머가 만료되거나 수동으로 제거된 뒤에는 다음 효과 문구에서 다시 감지됩니다.

- **경험치 HUD 화면 이탈 방지**
  - 잘못 저장된 음수 좌측 좌표를 자동으로 `0`으로 보정합니다.
  - 설정 저장 및 인게임 렌더링 단계에서도 동일하게 보정하여 HUD가 화면 밖으로 벗어나지 않도록 했습니다.

## ⚙️ Changed (개선 사항)

- **신속 포션 자동 감지 제외**
  - 신속 포션 효과 문구는 버프 타이머를 자동으로 시작하지 않도록 변경했습니다.

---

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 최신 버전의 `twOverlay-Setup-2.2.1.exe` 파일을 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 `.exe` 설치 파일을 실행합니다.
