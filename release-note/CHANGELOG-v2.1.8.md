# 📦 TW-Overlay Release Note - [Mandatory Update] v2.1.8 (2026-07-31)

이번 v2.1.8 버전은 숙제 체크리스트의 정렬 편의성을 높이고, 버프 타이머의 재감지 동작을 개선한 업데이트입니다.

---

## 🚀 주요 변경 사항

### ✨ Added (신규 기능)

- **숙제 및 카테고리 순서 편집**
  - 관리 모드에서 숙제 항목을 드래그 앤 드롭하여 원하는 순서로 배치할 수 있습니다.
  - 일일 및 주간 카테고리도 각각 드래그하여 순서를 변경할 수 있습니다.
  - 변경한 순서는 저장되어 앱을 다시 실행해도 유지됩니다.

### ⚙️ Changed (개선 사항)

- **드래그 위치 미리보기 추가**
  - 숙제나 카테고리를 이동하는 동안 실제로 배치될 위치를 화면에서 바로 확인할 수 있습니다.
  - 유효한 위치에 놓은 뒤에도 미리보기 순서가 원래대로 돌아가지 않도록 드롭 처리를 개선했습니다.
- **버프 타이머 재감지 갱신**
  - 활성화된 버프가 다시 감지되면 최근 사용 시점을 기준으로 타이머가 갱신됩니다.
  - 동일하거나 과거 시점의 중복 이벤트는 무시하여 타이머가 잘못 변경되지 않도록 했습니다.

### 🛠️ Fixed (버그 수정)

- **버프 감지 대상 정리**
  - 버프 타이머 화면에 표시되지 않는 `改-신뢰의 물약`을 채팅 로그 자동 감지 대상에서 제외했습니다.

---

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 최신 버전의 `twOverlay-Setup-2.1.8.exe` 파일을 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 `.exe` 설치 파일을 실행합니다.
