# 📦 TW-Overlay Release Note - v3.1.1 (2026-08-30)

이번 **v3.1.1 업데이트**는 모험일지의 득템 확인 방식을 개선하고, 장사 수익·더블 리워드 기록과 HUD 위치 저장 문제를 수정한 안정화 업데이트입니다.

---

## Added

### 모험일지 품목별 합계

- 선택한 주간·월간 기간에 같은 아이템을 합산해 품목별 총 획득 수량을 표시합니다.
- 품목 종류 수와 아이템별 이미지·이름·총수량을 일자별 기록 위에서 바로 확인할 수 있습니다.
- 품목별 합계와 일자별 기록 사이의 구분선을 위아래로 드래그해 두 영역의 높이를 조절할 수 있습니다.
- 조절한 높이는 PC에 저장되어 앱을 다시 실행해도 유지됩니다.

---

## Changed

### HUD 위치 편집 흐름 개선

- HUD 위치 편집 중에는 일반 `저장 및 적용` 버튼을 잠그고 `위치 저장 및 종료` 또는 `취소`를 먼저 선택하도록 안내합니다.
- 위치 편집 중 설정 창을 닫으면 저장하지 않고 편집 전 위치로 돌아갑니다.

---

## Fixed

- 직접 입력한 장사 수익이 활동 기록에는 표시되지만 SEED 통계에 반영되지 않던 문제를 수정했습니다.
- 기존 DB에서 금액이 0으로 저장된 직접 입력 수익은 업데이트 후 최초 실행 시 표시 문구의 금액을 기준으로 한 번 복구합니다.
- 더블 리워드 추가 보상으로 획득한 아이템을 실시간 감지와 과거 채팅 로그 재분석에서 기록하지 못하던 문제를 수정했습니다.
- 직접 추가한 득템의 수량이 기간별 합계에 정확히 반영되도록 수정했습니다.
- HUD 위치 편집 중 일반 설정을 적용하면 숨겨진 HUD 좌표가 잘못 저장되어 화면에서 사라지던 문제를 수정했습니다.
- 이전 오류로 화면 밖에 저장된 HUD 위치는 정상 사용자 좌표를 유지하면서 오류 형태에 해당하는 위치만 기본값으로 한 번 복구합니다.

---

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.1.1.exe`를 다운로드합니다.
2. 설치 프로그램을 실행하면 기존 설정과 모험 일지 데이터를 유지하며 업데이트됩니다.
3. 자동 업데이트를 사용 중이면 v3.1.1 게시 후 앱 시작 화면에서 다운로드와 설치가 진행됩니다.
