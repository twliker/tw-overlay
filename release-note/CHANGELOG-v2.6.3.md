# 📦 TW-Overlay Release Note - [Mandatory Update] v2.6.3 (2026-08-17)

이번 v2.6.3 버전은 사냥 중 엘소(ELSO) 대량 획득 시 발생하던 프로그램 및 마우스 버벅임(프리징) 문제 완전 해결, 인메모리 버퍼링 및 배치 저장 도입, 오늘의 요약 무지연 실시간 수치 반영이 적용된 성능 및 안정화 필수 업데이트입니다.

---

## 🚀 주요 변경 사항

### ⚡ 엘소(ELSO) 획득 시 마우스 및 프로그램 프리징 완전 해소 (Fixed)
- **동기식 SQLite 디스크 I/O 병목 제거**:
  - 기존 루미나의 회랑, 어비스 등 사냥 중 1초에 수십 건씩 발생하는 엘소 획득 로그마다 동기식 디스크 트랜잭션(`better-sqlite3`) 및 파일 로깅이 실행되어 메인 스레드를 멈추게 하던 근본 원인을 해결했습니다.
- **인메모리 버퍼링 및 3초 디바운스 배치 저장 엔진 도입**:
  - 사냥 중 획득되는 엘소 포인트를 메인 프로세스 인메모리 맵에 즉시 누적(0.0001ms 미만)하고, 마지막 획득 후 3초 동안 추가 획득이 없을 때 단 1회의 트랜잭션으로 DB에 일괄 커밋하여 디스크 I/O 횟수를 98% 이상 격감시켰습니다.

### ⏱️ 오늘의 요약 HUD 무지연 실시간 반영 (Changed)
- **디스크 쓰기 없는 인메모리 가상 병합**:
  - 오늘의 요약이 데이터를 조회할 때 디스크 트랜잭션을 실행하지 않고, 메모리에 대기 중인 실시간 누적 포인트를 가상 합산하여 즉시 반환합니다.
- **UI 갱신 신호 1초 쓰로틀링**:
  - 초당 수십 건의 이벤트가 들어와도 IPC 갱신 신호는 최대 1초에 1회만 발송하여, 마우스나 CPU 렉 전혀 없이 오늘의 요약 HUD 엘소 숫자가 1초마다 부드럽게 실시간 갱신됩니다.

### 🛡️ 데이터 일관성 및 유실 방지 안전장치 강화 (Security / Stability)
- **DB 트랜잭션 에러 시 메모리 버퍼 자동 롤백 복구**:
  - 디스크 쓰기 중 일시적 오류가 발생하더라도 대기 중이던 포인트가 증발하지 않고 버퍼에 즉시 복원됩니다.
- **앱 종료, 백업, 동기화 시 100% 즉시 플러시(Flush) 보장**:
  - 앱 종료(`before-quit`), 데이터 백업 생성, 채팅 로그 주간 동기화 시작 시 대기 중인 잔여 포인트를 즉시 DB에 영구 기록한 후 다음 단계를 진행합니다.

---

## 📥 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-2.6.3.exe`를 다운로드합니다.
2. 기존 버전이 실행 중인 경우 완전히 종료한 후 설치 파일을 실행하여 업데이트를 진행합니다.
3. 앱 실행 시 기존 설정과 모험 일지 데이터는 안전하게 유지됩니다.
