# 📦 TW-Overlay Release Note - [Mandatory Update] v2.1.6 (2026-07-28)

이번 v2.1.6 버전은 공허의 영역 특별 몬스터 출현 알람과 이터널 플로어 주간 숙제를 추가하고, 변경된 게임 채팅 로그에 맞춰 주요 숙제의 자동 감지를 복구했습니다. 채팅 및 숙제 화면의 표시를 개선하고 내부 코드 구조도 함께 정리한 **강제 업데이트** 버전입니다.

---

## 🚀 주요 변경 사항

### 🔔 Added (새로운 기능)

- **공허의 영역 특별 몬스터 출현 알람 추가**
  - 특별 몬스터 출현 채팅 로그를 감지하면 게임 오버레이에 알람을 표시합니다.
- **이터널 플로어 주간 숙제 추가**
  - 재화 카테고리에 주간 10회 숙제로 추가했습니다.
  - 이터널 플로어 보상 상자 획득 로그를 감지하면 숙제 횟수가 자동으로 증가합니다.
- **사용자 추가 숙제 구분 표시**
  - 사용자가 직접 추가한 숙제에 `CUSTOM` 딱지를 표시합니다.

### 🛠️ Fixed (버그 수정)

- **주요 주간 숙제 채팅 로그 미감지 문제 수정**
  - 변경된 채팅 로그 형식에 맞춰 오를리 방어전, 베스티지, 신조의 둥지 자동 감지를 수정했습니다.
- **채팅 오버레이 특수 공백 표시 수정**
  - 채팅 메시지에 포함된 `&nbsp`와 특수 공백을 제거하여 정상적인 문장으로 출력합니다.
- **자동 업데이트 및 패키징 의존성 보안 업데이트**
  - 자동 업데이트, 압축 파일 처리와 Electron 패키징 관련 의존성을 보안 수정 버전으로 갱신했습니다.
- **Google Analytics 이벤트 수집 안정성 수정**
  - GA4 규격에 맞게 사용자 식별자, 동적 이벤트 이름과 문자열 파라미터를 정규화하여 일부 이벤트가 누락될 수 있는 문제를 수정했습니다.

### ⚙️ Changed (개선 사항)

- **코드 구조 개선 및 효율화**
  - 중복 상수와 공통 로직을 재사용 모듈로 통합했습니다.
  - 메인 프로세스, preload, 빌드 및 테스트 도구의 TypeScript 구조를 정리했습니다.
  - 중복 이벤트 등록을 방지하고 정적 회귀 검사와 Electron 렌더러 동작 검사를 추가했습니다.

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 최신 버전의 `twOverlay-Setup-2.1.6.exe` 파일을 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 `.exe` 설치 파일을 실행합니다.
