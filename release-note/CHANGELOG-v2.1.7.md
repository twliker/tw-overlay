# 📦 TW-Overlay Release Note - [Mandatory Update] v2.1.7 (2026-07-30)

이번 v2.1.7 버전은 버프 타이머 알림 기능에서 `통찰의 비약(대/특대)` 등 일부 아이템이 감지되지 않던 문제를 수정한 **버그 수정** 버전입니다.

---

## 🚀 주요 변경 사항

### 🛠️ Fixed (버그 수정)

- **버프 타이머 아이템 감지 누락 수정**
  - `통찰의 비약(대)`, `통찰의 비약(특대)` 등 괄호가 포함된 아이템명이 감지되지 않던 문제를 수정했습니다.
  - 파티원이 아이템을 사용할 때(`[닉네임]님이 [아이템명] 아이템을 사용하셨습니다`) 이전에는 일부 아이템만 버프 타이머를 활성화하던 제한을 제거했습니다. 이제 `buffs.json`에 등록된 모든 버프가 채팅 로그 감지 시 정상적으로 타이머를 시작합니다.

### ⚙️ Changed (개선 사항)

- **버프 감지 로직을 전담 모듈로 이관**
  - 버프 활성화 처리를 `xpTracker`에서 `buffTimerManager`로 이관하여 역할을 명확히 분리했습니다.
  - 채팅 로그 파서의 `PARTY_ITEM`, `SELF_USE`, `EFFECT_APPLIED` 패턴에 대괄호·조사·띄어쓰기 변형을 유연하게 처리하도록 정규식을 개선했습니다.

---

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 최신 버전의 `twOverlay-Setup-2.1.7.exe` 파일을 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 `.exe` 설치 파일을 실행합니다.
