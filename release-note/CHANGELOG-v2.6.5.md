# 📦 TW-Overlay Release Note - v2.6.5 (2026-08-18)

이번 v2.6.5 버전은 **스플래시 화면 기반 실시간 자동 업데이트 UI 개편**, **환경설정 6대 대메뉴 개편 및 검색/포커스 안정화**, **초고속 대량 로그 유입 처리 및 렌더링 성능 대폭 최적화**, **DB 복합 인덱스 및 버프 파서 O(1) 고속화**, **게임창 최소화 시 모니터 좌표 보존 및 DWM 창 드래그 간섭 해결**이 적용된 대규모 기능 개선 및 성능 최적화 업데이트입니다.

---

## 🚀 주요 변경 사항

### ⚡ 스플래시 화면 기반 실시간 자동 업데이트 라이프사이클 및 UI 개편 (Added / UX)
- **앱 시작 시 스플래시에서 실시간 자동 업데이트**:
  - 앱 실행 즉시 스플래시 화면에서 최신 릴리즈를 감지하고, 다운로드 진행률(%), 프로그레스바, 전송 속도를 실시간으로 표시합니다.
  - 다운로드가 완료되면 1.5초 후 앱이 자동으로 재시작되어 새 버전으로 즉시 업데이트됩니다.
- **자동 업데이트 비활성화(`autoUpdateEnabled: false`) 사용자 경험 분기**:
  - 자동 업데이트를 꺼둔 경우 스플래시 화면에서 대기하지 않고 즉시 메인 앱으로 진입합니다.
  - 사이드바 설정(톱니바퀴) 아이콘 및 환경설정 [앱 정보] 탭에 레드닷(알림 뱃지)을 표시하고 데스크톱 알림을 전송하여 새 버전이 있음을 안내합니다.
  - 환경설정 [앱 정보] 메뉴에서 `다운로드 시작` 버튼을 눌러 원하는 시점에 수동으로 업데이트할 수 있습니다.
- **긴급 배포를 위한 강제 업데이트(`[Mandatory Update]`) 지원**:
  - 긴급 보안/버그 패치 시 사용자의 자동 업데이트 설정 여부와 상관없이 스플래시 화면을 잠그고 강제 다운로드 및 재시작을 진행합니다.

### ⚙️ 환경설정(Settings) 6대 대메뉴 개편 및 실시간 검색/포커스 고도화 (Changed & Fixed)
- **직관적인 6대 대메뉴 체계 개편**:
  - 기존 8개 메뉴 체계를 **[일반 설정]**, **[오버레이 위젯]**, **[채팅 & 외치기]**, **[사냥 & 경험치]**, **[데이터 관리]**, **[앱 정보]**의 직관적인 6대 카테고리로 전면 개편했습니다.
  - 가로 서브 탭 바(Sub Tab Bar)를 도입하여 복잡한 설정 화면을 세부 기능별로 깔끔하게 정리했습니다.
- **실시간 검색 색인 및 부드러운 스크롤/포커스 하이라이트**:
  - 6대 메뉴 및 서브 탭 구조에 맞춰 전체 검색 인덱스를 완벽히 갱신했습니다.
  - 검색 결과 클릭 시 해당 서브 탭을 자동으로 열고 해당 설정 항목으로 부드럽게 스크롤하며 펄스 애니메이션으로 하이라이트 표시합니다.
- **오버레이 가이드창 렌더링 및 모니터 전환 안정화**:
  - 가이드창 열기/닫기 및 모니터 전환 시 DOM 렌더링 및 윈도우 크기/위치 동작의 불안정성을 수정했습니다.

### 🏎️ 초고속 대량 로그 유입 처리 & 렌더링 성능 대폭 최적화 (Performance)
- **SQLite WAL(Write-Ahead Logging) 저널 모드 적용**:
  - DB 동시 읽기/쓰기 락 병목을 원천 해소하여 대량 로그가 동시에 쏟아져도 끊김 없이 부드럽게 저장됩니다.
- **채팅 오버레이 & 포커스 대화창 렌더링 최적화**:
  - 포커스 대화창: 전체 재렌더링 방식에서 단건 증분(`appendChild`) 방식으로 전환하여 CPU 점유율을 크게 낮췄습니다.
  - 채팅 오버레이: `requestAnimationFrame` 배치 렌더링 및 타이머 폴백을 적용하여 초당 수십 건 이상의 대화가 쏟아지는 파티/외치기 상황에서도 UI 프리징이나 프레임 드롭이 전혀 발생하지 않습니다.
- **활동 기록 및 경험치 HUD 쓰로틀링**:
  - 활동 기록 알림 1초 쓰로틀링 및 경험치 HUD IPC 전송 150ms 쓰로틀링을 적용하여 불필요한 메인-렌더러 프로세스 간 IPC 오버헤드를 획기적으로 줄였습니다.

### 🗄️ 데이터베이스 복합 인덱스 & 파서 O(1) 인덱싱 & 백그라운드 I/O 최적화 (Performance)
- **SQLite 복합 인덱스(Composite Index) 생성**:
  - `activity_logs`, `shout_history`, `homework_logs` 등 조회 빈도가 높은 테이블에 복합 인덱스를 추가하여 일지 조회 및 검색 속도를 대폭 향상했습니다.
- **채팅 파서 버프 키워드 O(1) Map 인덱싱**:
  - 기존 반복문 탐색 방식에서 Map 기반 O(1) 키워드 트리거 매칭으로 전환하고 정규식을 사전 컴파일 상수화하여 파싱 성능을 극대화했습니다.
- **대용량 ETA 랭킹 데이터 비동기 압축 캐싱**:
  - 대용량 랭킹 JSON 데이터를 비동기/압축 저장 방식으로 전환하여 파일 저장 시 메인 UI가 일시 멈추는 현상을 완전히 해결했습니다.
- **설정창 지연 초기화(Lazy Init) 및 위젯 창 닫기 응답성 개선**:
  - 설정창 오픈 시 필요한 탭만 지연 로딩하여 진입 속도를 단축하고, 오버레이 창 닫기/숨김 처리 반응 속도를 가속했습니다.

### 🖥️ 게임창 최소화 시 모니터 좌표 보존 & DWM 창 드래그 깜빡임 간섭 해결 (Feature & Fixed)
- **게임창 최소화 시 게임 모니터 기준 창 중앙 배치**:
  - 게임이 최소화된 상태에서 오버레이나 팝업 창을 열 때, 게임이 실행 중이던 마지막 활성 모니터를 기억(`lastKnownGameRect`)하여 해당 모니터의 작업 영역 중앙에 정확히 배치합니다.
- **창 드래그 깜빡임 및 DWM(Desktop Window Manager) 리페인트 간섭 완벽 해결**:
  - 게임창 영역 중첩 시 마우스 훅 깜빡임을 제거하고, 윈도우 위치/z-order 무차별 호출을 차단(`SetWindowPos` 변경 감지 시에만 호출)했습니다.
  - 윈도우 배치 시 `SWP_NOREDRAW` 플래그 및 사용자 마우스 드래그 추적기(`programmaticMoveTracker`)를 적용하여 드래그 중 백그라운드 위치 보정 간섭을 차단했습니다.
  - 보조 모니터 우측 경계 좌표 계산 시 1픽셀 안전 샘플링을 적용하여 멀티 모니터 경계선 오작동을 방지했습니다.

## 📥 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-2.6.5.exe`를 다운로드합니다.
2. 기존 버전이 실행 중인 경우 자동으로 스플래시 화면에서 업데이트가 진행되거나, 설치 파일을 실행하여 즉시 업데이트할 수 있습니다.
3. 앱 실행 시 기존 설정과 모험 일지 데이터는 안전하게 유지됩니다.
