# 📦 TW-Overlay Release Note - v3.1.4 (2026-09-12)

이번 **v3.1.4 업데이트**는 설정과 백업·동기화를 안정화하고, 숙제 기록·거래 알림·장비 계산기의 오류를 수정한 업데이트입니다.

---

## Added

- 데이터 관리의 ZIP 백업에 보조 도구의 저장 데이터를 포함합니다. 버프 프리셋, 계수 계산기 프로필, 진화 계산기 입력·기록·재료 가격, QTE 기록과 일부 계산기·표시 설정을 함께 복원할 수 있습니다.

## Changed

- 갤러리·거래 게시판 연결에 실패하면 재시도 간격을 점차 늘려 불필요한 요청을 줄입니다.
- 거래 알림의 검색별 확인 위치를 저장해 앱을 다시 실행한 뒤에도 이어서 확인합니다. 일부 검색어에서 오류가 나더라도 성공한 검색의 새 글 알림은 처리합니다.

## Fixed

- Windows 로그인 시 Microsoft Store 설치본에서 경로 접근 오류가 표시되던 자동 실행 문제를 수정했습니다. 특정 버전의 설치 폴더를 직접 실행하지 않고 Windows가 현재 설치된 패키지를 찾아 실행합니다.
- 업데이트 후 첫 실행 때 이전 버전의 잘못된 Store 자동 실행 등록을 정리합니다. 일반 설치본의 등록과 사용자 설정은 보존하며, Windows에서 사용자가 직접 끈 시작 앱 설정을 강제로 다시 켜지 않습니다.
- 자동 실행을 빠르게 켰다 꺼도 마지막 선택이 적용되도록 개선하고, 일반 설치본의 한글·공백 경로 및 바로가기 생성 오류를 수정했습니다. 개발용 실행은 설치된 앱의 자동 실행 설정을 변경하지 않습니다.
- 설정 창에서 키워드·단축키·빠른 슬롯·색상 등을 편집하는 동안 다른 설정이 갱신되면 작성 중인 내용이 덮어써지던 문제를 수정했습니다. 편집하지 않은 항목은 최신 값을 반영합니다.
- 설정 저장 성공 여부를 확인한 뒤 창을 닫도록 개선했습니다. 저장 실패와 저장 도중 추가 편집 시에도 입력 내용을 보존합니다.
- ZIP 복원 도중 기존 설정이나 동기화 데이터가 복원 결과를 다시 덮어쓰는 상황을 방지하고, 복원 실패 시 기존 데이터로 되돌리는 처리를 보강했습니다. 보조 도구 데이터가 없는 이전 백업은 해당 도구의 현재 데이터를 유지합니다.
- Google Drive에서 여러 PC의 변경이 겹치면 최신 내용을 다시 확인해 병합하도록 수정했습니다. 동기화된 알림·단축키 등의 설정과 숙제 목록 순서도 실행 중인 앱에 반영합니다.
- 숙제 최대 횟수를 늘리거나 줄였을 때 완료 상태가 맞지 않던 문제를 수정했습니다. 초기화 규칙 변경과 완료 취소 시 원래 완료한 날짜를 기준으로 일지 기록을 반영합니다.
- 거래 게시판을 수동 새로고침한 뒤 새 글 알림이 누락되거나, 같은 서버 설정을 다시 저장한 뒤 알림 기준이 초기화되던 문제를 수정했습니다.
- 인챈트 기댓값에서 축복이 첫 성공 이후에도 남아 있던 문제와 비아누 성공 횟수가 다음 강화 계산에 반영되지 않던 문제를 수정했습니다.
- 인크립트 목표를 1~20 범위의 정수로 보정해 범위를 벗어난 입력과 소수 입력을 올바르게 처리합니다.
- 사기꾼 탐지 AI를 시작·중지하는 과정에서 중복 실행되거나 중지 후 다시 시작될 수 있던 문제를 수정했습니다.
- ZIP 처리와 업데이트 정보 읽기에 사용하는 라이브러리를 보안 수정 버전으로 갱신했습니다.

---

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.1.4.exe`를 다운로드합니다.
2. Microsoft Store 설치본은 Store 라이브러리에서 업데이트할 수 있습니다.
   업데이트 후 시작 메뉴에서 앱을 한 번 실행하면 기존 Store 자동 실행 등록이 정리됩니다. 자동 실행 시 필요한 Windows 관리자 권한 확인은 기존처럼 표시됩니다.
3. 업데이트 전에 환경 설정의 **데이터 관리 → ZIP 백업**으로 설정과 기록을 보관할 수 있습니다.
