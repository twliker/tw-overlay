# TW-Overlay v3.3.5-beta.2 (2026-11-06)

일부 PC에서 실행 직후 화면 표시 오류가 나는 문제의 원인을 확인하기 위한 테스트 버전입니다.

- Electron의 공식 `45.2.2` Windows 런타임을 사용합니다. `45.2.3`의 기본 `ffmpeg.dll`이 Defender에 탐지되는 현상을 확인했고, `45.2.2`의 공식 런타임과 테스트 패키지는 Defender 검사를 통과했습니다. 이 임시 베타에는 `45.2.3`에서 추가된 FFmpeg 및 Chromium 등의 수정이 포함되지 않습니다.
- 화면이 열리지 않으면 오류창에 앱 버전, 화면 이름, 오류 코드가 표시됩니다. 같은 오류가 나면 창 아래의 `TW-Overlay 3.3.5-beta.2 | …` 한 줄을 전달해 주세요.
- 배포판의 `debug.log`에도 화면 프로세스가 종료되거나 응답하지 않은 이유를 남깁니다.
- GitHub에서 업데이트 파일을 찾지 못했을 때 앱이 계속 시작하도록 오류 처리를 보완했습니다. **앱 정보 → 업데이트 확인**에서 다시 확인할 수 있습니다.

기존 베타 사용자는 설치 파일을 직접 실행해 주세요. 화면 프로세스를 강제로 종료하는 회귀 검사와 업데이트 파일이 없는 상태에서의 시작 및 재시도 검사가 통과했습니다. 회사 PC의 화면 표시 실패 원인과 실제 설치 전환, 실게임, 두 PC 간 Google 동기화는 별도 확인이 필요합니다.

프로필과 모험일지, Google 동기화의 변경 내용은 [v3.3.5-beta.1 릴리즈 노트](https://github.com/twliker/tw-overlay/blob/v3.3.5-beta.1/release-note/CHANGELOG-v3.3.5-beta.1.md)를 참고하세요.
