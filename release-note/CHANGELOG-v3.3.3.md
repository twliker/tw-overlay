# 릴리즈 노트: v3.3.3

**릴리즈 날짜:** 2026년 10월 27일

TW-Overlay v3.3.3은 다중 프로필 시스템 도입 이후 발생했던 계정 간 숙제 복제, 일일 숙제 미초기화, 재시작 시 카운트 변경 및 게임 로그 가로채기 문제를 근본적으로 해결하기 위해 **프로필별 물리 독립 파일 분리 아키텍처(File-per-Profile Architecture)**를 구축하고 전체 파이프라인을 정류한 대규모 안정화 릴리즈입니다.

---

## 🚀 주요 변경 사항

### 1. 프로필별 물리 독립 파일 분리 아키텍처 (File-per-Profile Architecture) 구축
- **물리 파일 격리:**
  - 매니페스트(`profiles/manifest.json`): 활성 프로필 ID와 프로필 목록 메타데이터만 경량 관리.
  - 개별 데이터 파일(`profiles/data/{profileId}.json`): 각 계정 전용 체크리스트와 설정을 단독 파일에 물리 격리 저장.
- **원자적 쓰기(Atomic Write) 도입:** 임시 파일 생성 후 OS 수준 교체(`renameSync`)를 적용하여 비정상 종료 시 0바이트 손상 원천 방지.
- **기존 데이터 자동 정제:** 최초 실행 시 기존 레거시 `profiles.json`을 안전하게 백업(`profiles.json.bak`)하고 타 계정 오염 키를 제거하여 독립 파일들로 1회성 자동 마이그레이션.

### 2. 전 프로필 만료 숙제 자정 일괄 전수 리셋 체계 확립
- **비활성 계정 전수 리셋:** 부계정으로 로그인하지 않고 하루나 일주일이 지나도, 자정/월요일 00시 리셋 시점에 디스크에 보관된 모든 비활성 계정 파일들을 순회하여 만료 숙제를 0으로 일괄 초기화 (`resetAllProfilesExpiredHomeworks`).
- **전환 시 만료 검사:** 프로필 전환(`switchProfile`) 시 대상 프로필 로드 직전 만료 리셋을 사전 수행하여 즉시 최신 상태 반영.

### 3. UI 조작 및 실시간 게임 로그 활성 프로필 단일 진실 공급원(SSOT) 일원화
- **UI 프리셋 ID 고정 바인딩:** 부계정 화면에서 체크박스를 클릭했을 때 본계정 ID로 요청이 가로채이던 렌더러 결함을 수정하여 현재 활성 프로필 ID로만 IPC 전송.
- **실시간 게임 로그 타겟팅:** 테일즈위버 채팅 로그 파서가 숙제 완료를 감지했을 때, 현재 플레이 중인 활성 프로필을 최우선 단독 대상으로 지정하여 부계정 플레이 중 본계정으로 완료가 넘어가던 문제 해결.
- **재시작 활성 상태 유지:** 앱 부팅 시 `profileManager.getActiveProfileId()`를 최우선으로 복원하여 재시작 시 본계정 기본 ID로 덮어씌워지던 현상 차단.

### 4. Google Drive 클라우드 동기화 3-Way 머지 안전 보호
- **3-Way 머지 결과 보존:** 클라우드에서 데이터를 내려받을 때, 로컬과 원격이 합쳐진 활성 프로필의 3-way 머지 결과를 안전하게 유지하여 로컬 체크 내역이 원격 과거 스냅샷으로 되돌아가지 않도록 보강.
- **비활성 프로필 키 정규화:** 다른 PC에서 동기화된 부계정 데이터 파일 저장 시 타 프로필 키 오염 배제.
