# 📦 TW-Overlay Release Note - [Mandatory Update] v2.6.0 (2026-08-16)

이번 v2.6.0 버전은 장비 강화/인챈트/인크립트 기댓값 계산기 신규 추가, 인게임 채팅 오버레이 당일 전체 로그 실시간 검색 기능 추가 및 어벤던로드 마정석 집계 오류가 수정된 기능 업데이트입니다.

---

## ✨ Added (신규 기능)

- **장비 강화 / 인챈트 / 인크립트 기댓값 계산기 신규 추가**
  - 장비의 단계별 강화 성공 확률, 인챈트 주문서 확률, 인크립트 한계 돌파 확률을 바탕으로 목표 수치까지 필요한 예상 비용(Seed, 강화석, 부가 재료)의 기댓값을 정밀하게 시뮬레이션 및 계산합니다.
  - 다양한 옵션과 안전 장치 조건을 유연하게 설정하여 직관적인 기댓값 결과를 확인할 수 있습니다.

- **인게임 채팅 오버레이 당일 전체 로그 실시간 검색 기능**
  - 인게임 채팅 오버레이 창에서 `Ctrl + F` 단축키 또는 상단 검색 아이콘을 눌러 당일 기록된 전체 채팅 로그를 실시간으로 검색할 수 있습니다.
  - 검색어 실시간 하이라이트 표시 및 일치하는 로그 필터링, 검색 결과 건수 표시를 지원합니다.

---

## 🛠️ Fixed (버그 수정)

- **어벤던로드 타인의 마정석 획득 공지 메시지 오인 집계 버그 수정**
  - `"누군가 어밴던로드에서 주문을 통해 하급 마정석 1000개를 획득 하였습니다."`와 같은 서버 전체 공지 메시지가 개인의 마정석 획득으로 오인되어 어벤던 수익에 잘못 합산되던 문제를 수정했습니다.

---

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-2.6.0.exe`를 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 설치 파일을 실행합니다.
