# 📦 TW-Overlay Release Note - v3.1.3 (2026-09-05)

이번 **v3.1.3 업데이트**는 Microsoft Store 업데이트 설치 과정에서 발생하던 오류를 수정한 안정화 업데이트입니다.

---

## Fixed

- Microsoft Store 업데이트 도우미가 설치 시작 단계에서 출력 인코딩 오류로 종료되던 문제를 수정했습니다.
- Store가 목표 버전을 제공하지 않을 때 현재 설치된 버전을 새 버전으로 표시하던 문제를 수정했습니다.
- Store 업데이트 설치에 실패하면 오류 상태와 함께 다시 시도 및 Microsoft Store 열기 동작을 표시합니다.

---

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.1.3.exe`를 다운로드합니다.
2. Microsoft Store 설치본은 Store 라이브러리에서 업데이트할 수 있습니다.
