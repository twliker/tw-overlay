# 📦 TW-Overlay Release Note - [Mandatory Update] v2.3.0 (2026-08-13)

이번 v2.3.0 버전은 여러 사람의 메시지가 한 채팅창에 섞이는 환경에서도 원하는 사용자와의 대화를 놓치지 않도록 카카오톡 형태의 `집중 대화방`을 추가하고, 창 복원과 설정 이동 안정성을 개선한 업데이트입니다.

> [Mandatory Update] 모든 사용자가 설치해야 하는 필수 업데이트입니다.

---

## ✨ Added (신규 기능)

- **집중 대화방**
  - 내 닉네임과 여러 대화 상대를 등록하면 해당 사용자들의 일반, 팀, 클럽, 귓속말 채팅만 별도 창에 모아 표시합니다.
  - 내 메시지는 오른쪽 노란 말풍선, 상대 메시지는 왼쪽 말풍선으로 구분합니다.
  - 말풍선 위에 닉네임, 채널, 에타 정보를 함께 표시합니다.

- **닉네임 자동완성과 직접 입력**
  - 현재 앱 세션에서 감지한 닉네임을 자동완성 후보로 제공합니다.
  - 방향키로 후보를 이동할 때 선택 항목을 명확하게 강조하며 `Enter` 선택과 `Esc` 닫기를 지원합니다.
  - 자동완성에 없는 닉네임도 직접 입력할 수 있습니다.

- **집중 대화방 창 제어**
  - 상단 닉네임 설정 영역을 접거나 펼칠 수 있습니다.
  - 오른쪽 아래 손잡이로 창 크기를 조절할 수 있으며 조절한 크기를 유지합니다.

## ⚙️ Changed (개선 사항)

- **임시 대화 상대 데이터 처리**
  - 내 닉네임만 앱 설정에 저장합니다.
  - 대화 상대와 자동완성 후보는 집중 대화방이 열린 동안만 메모리에 유지하고 창을 닫으면 삭제합니다.
  - 다시 열면 현재 세션의 최근 채팅에서 자동완성 후보를 새로 구성합니다.

- **집중 대화방 표시 밀도 개선**
  - 카카오톡형 말풍선 구조를 유지하면서 닉네임, 채널, 에타, 내용과 시간을 더 간결하게 배치했습니다.

- **의존성 보안 고정값 정리**
  - 중복된 `overrides` 선언을 하나로 통합하고 `fast-uri`, `js-yaml`의 안전한 버전을 적용했습니다.
  - 지원이 종료되고 보안 권고의 영향을 받는 Electron 40 런타임을 Electron 42.9.0으로 업그레이드했습니다.
  - 설치 후 `better-sqlite3`, `koffi`를 Electron ABI에 맞춰 자동 재빌드하도록 구성했습니다.
  - Electron 42의 V8 API와 호환되는 `better-sqlite3 13.0.3`을 적용했습니다.
  - Electron 42 네이티브 ABI와 호환되는 `koffi 3.1.4`를 적용했습니다.

## 🛠️ Fixed (버그 수정)

- **채팅 오버레이 설정 바로가기**
  - 채팅 오버레이의 설정 버튼을 눌렀을 때 일반 설정 화면만 열리고 채팅 설정 탭으로 이동하지 않던 문제를 수정했습니다.

- **숙제 체크리스트 복원 위치**
  - 게임을 장시간 최소화한 뒤 복원했을 때 숙제 체크리스트가 저장 위치가 아닌 화면 중앙에 나타날 수 있던 문제를 수정했습니다.

- **집중 대화방 외곽 표시**
  - 창 바깥 여백으로 투명 배경이 테두리처럼 보이던 현상을 제거했습니다.
  - 닉네임 설정 접기 아이콘이 화면 배율과 글꼴에 따라 어색하게 표시되던 문제를 벡터 아이콘으로 수정했습니다.

- **창 종료 중 채팅 IPC 오류**
  - 채팅창이 닫히는 순간 폐기된 렌더 프레임으로 새 채팅을 전송하며 오류가 출력되던 경쟁 상태를 방어했습니다.

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 최신 버전의 `twOverlay-Setup-2.3.0.exe` 파일을 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 `.exe` 설치 파일을 실행합니다.
