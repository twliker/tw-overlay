# 📦 TW-Overlay Release Note - [Mandatory Update] v2.2.0 (2026-08-02)

이번 v2.2.0 버전에서는 별도 창에서 즐길 수 있는 **검 강화하기** 게임을 추가했습니다.

---

## 🚀 주요 변경 사항

### ✨ Added (신규 기능)

- **검 강화하기 게임 추가**
  - 사이드바에서 바로 실행할 수 있는 독립 1depth 메뉴를 추가했습니다.
  - `twliker`의 검 강화하기 게임을 1300×850 전용 창에서 이용할 수 있습니다.
  - 게임 사이트의 LocalStorage를 그대로 사용하여 게임 데이터가 유지됩니다.

### ⚙️ Changed (개선 사항)

- **이미지 메뉴 아이콘 지원**
  - 사이드바와 메뉴 표시 관리 화면에서 Lucide 아이콘 대신 전용 PNG 아이콘을 표시할 수 있습니다.

---

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 최신 버전의 `twOverlay-Setup-2.2.0.exe` 파일을 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 `.exe` 설치 파일을 실행합니다.
