# 📦 TW-Overlay Release Note - [Mandatory Update] v2.5.0 (2026-08-15)

이번 v2.5.0 버전은 게임 오버레이 HUD의 마우스 드래그 위치 이동 편집 모드 지원, HUD별 단축키 미니 뱃지 표시, 숙제 체크리스트의 카테고리 간 드래그 이동 지원, 어벤던로드 HUD 단축키 추가 및 정산 집계 버그 수정을 포함한 기능 업데이트입니다. 또한, 업데이트 후 새로운 기능을 한눈에 확인할 수 있는 1회성 공지 팝업 기능이 추가되었습니다.

---

## ✨ Added (신규 기능)

- **게임 오버레이 HUD 마우스 드래그 위치 이동 (편집 모드)**
  - **환경 설정 > 화면 & 메뉴 > 게임 오버레이** 화면에서 `위치 설정` 버튼을 눌러 편집 모드를 시작할 수 있습니다.
  - 편집 모드에서는 비활성화/숨김 상태인 HUD를 포함한 모든 컴포넌트(오늘 요약, 단어 알림, 버스 알림, 득템 알림, 지능형 버프 타이머, 어벤던로드 등)가 화면에 표시되며 마우스 드래그로 원하는 위치로 자유롭게 배치할 수 있습니다.
  - 배치가 끝난 후 `저장`을 누르면 변경된 좌표가 즉시 저장되고 클릭 투과 상태로 안전하게 복귀합니다.
  - 가이드 화면에서도 각 오버레이 컴포넌트별 상세 설명과 단축키/설정 바로가기를 지원합니다.

- **게임 오버레이 HUD 단축키 미니 뱃지 표시**
  - 단축키로 제어 가능한 게임 오버레이 내 HUD 컴포넌트에 현재 설정된 단축키가 미니 뱃지(예: `C+S+A`, `C+S+Y` 등)로 깔끔하게 표시됩니다.
  - 단축키 약어 표기(Ctrl -> C, Shift -> S, Alt -> A)를 통해 화면을 가리지 않고 직관적인 키 확인이 가능합니다.

- **어벤던로드 HUD 토글 단축키 추가**
  - 사냥 중 어벤던로드 HUD를 빠르게 켜고 끌 수 있는 전용 단축키가 추가되었습니다.
  - 기본 단축키: `Ctrl+Shift+A` (환경 설정 > 단축키 설정에서 원하는 키로 변경 가능)

- **숙제 체크리스트 창 헤더 소리 설정 바로가기**
  - 숙제 체크리스트 창 상단 헤더에 소리 설정 버튼을 추가하여 클릭 시 소리 설정 화면으로 즉시 이동할 수 있습니다.

- **앱 업데이트 후 1회성 안내 공지 팝업**
  - 새 버전으로 업데이트 설치 후 첫 실행 시 주요 변경점과 팁을 친절하게 안내하는 공지 팝업을 표시합니다.
  - 첨부 이미지가 있는 경우 번호 순서대로 표시되며, 클릭 시 확대 보기(Lightbox)를 제공합니다.

---

## ⚙️ Changed (개선 사항)

- **숙제 체크리스트 카테고리 간 드래그 이동 지원**
  - 숙제 순서 변경 모드에서 같은 카테고리 내 이동뿐만 아니라 다른 카테고리로의 드래그 앤 드롭 이동이 가능해졌습니다.
  - 나만의 숙제 루틴과 카테고리 분류를 더욱 유연하게 커스텀할 수 있습니다.

- **오늘의 요약 HUD 접힘 상태 표시 및 좌표계 개선**
  - 접힘 모드에서 필수 정보인 SEED, ELSO, 경험의 정수, 남은 숙제 개수가 균형 있게 표시되도록 개선했습니다.
  - 위치 좌표계를 top/left 기준으로 정규화하고 기본 위치를 `(0, 200)`으로 조정하여 시야 간섭을 줄였습니다.
  - SEED 표시 형식을 가독성 높은 단위 체계로 정리했습니다.

---

## 🛠️ Fixed (버그 수정)

- **어벤던로드 마정석/입장료 집계 파싱 오류 수정**
  - 3단계 이상 보스방 승리 후 등장하는 마정석 지키기/도박 컨텐츠에서 마정석 추가 획득 또는 잃음 로그가 정상적으로 집계되지 않던 문제를 수정했습니다.
  - 1인 입장료(50만 SEED) 차감 로그가 획득량 합산에서 올바르게 반영되도록 파싱 로직을 보완했습니다.

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-2.5.0.exe`를 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 설치 파일을 실행합니다.
