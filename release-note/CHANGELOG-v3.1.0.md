# 📦 TW-Overlay Release Note - v3.1.0 (2026-08-30)

이번 **v3.1.0 업데이트**는 테일즈위버 QTE 연습과 발굴지 포탈 현황판을 추가하고, 진화 재료 비용 계산기와 버프 백과의 사용 흐름을 전면 개선한 기능 업데이트입니다.

---

## Added

### QTE 챌린지

- 테일즈위버 QTE처럼 한 바퀴 안에 마우스 왼쪽 버튼을 눌러 판정받는 연습 게임을 추가했습니다.
- 파란색 일반 성공 영역과 그 뒤에 붙는 노란색 대성공 영역이 매 판 다른 위치와 크기로 표시됩니다.
- 실전 연습과 챌린지 모드, 점수·콤보·목숨·스테이지·개인 기록·도전과제를 제공합니다.
- 기존 `테일즈위버 무기 강화하기`와 별도 창으로 구성하고 두 기능을 `미니게임` 메뉴 아래에 배치했습니다.

### 발굴지 포탈 현황판

- 발굴지 입장 뒤 5분 동안 보상과 미방문 포탈을 게임 HUD에 표시합니다.
- 포탈 번호를 실제 맵 배치와 같은 `2·4 / 1·3` 순서로 표시합니다.
- 설정에서 현황판 사용 여부와 HUD 위치를 관리할 수 있습니다.

### Microsoft Store 앱 내 업데이트

- Microsoft Store 설치본도 앱 시작 시 새 버전을 확인합니다.
- 자동 업데이트를 켠 경우에는 시작 화면에서 업데이트를 진행하고, 끈 경우에는 앱을 연 뒤 업데이트 알림을 표시합니다.
- 필수 업데이트는 자동 업데이트 설정과 관계없이 시작 화면에서 진행합니다.

---

## Changed

### 진화 재료 비용 계산기 개편

- 무기와 각 장비 부위를 한 줄에서 바로 선택하고, 진화 구간별 재료와 비용을 계산할 수 있도록 화면을 다시 구성했습니다.
- 어비스 장비 직접 진화, 완성된 어비스 장비 구매, 가짜 달여왕 군단의 무구 구매를 구분해 이클립스 진화 비용을 계산합니다.
- 인장 직접 제작 여부, 재료별 단가, 장비 구매·강화·인챈트·어빌리티·속성 부여 등 후처리 비용과 각 항목의 소계를 표시합니다.
- 계산 이력에 장비 부위와 선택 조건을 함께 저장하며, 수정 중인 이력을 명확하게 표시하고 저장·취소 뒤 이전 입력 상태로 돌아가도록 개선했습니다.
- 가로로 긴 이미지와 세로로 긴 이미지를 구분해 재료 이미지가 잘리지 않도록 표시하고 글자 크기·정렬·스크롤을 개선했습니다.

### 버프 백과 및 계산기 개편

- 프리셋 없이 버프를 직접 선택해 계산할 수 있고, `빈 프리셋 만들기`와 `선택된 버프로 프리셋 만들기`를 구분했습니다.
- 새 프리셋과 수정 중인 프리셋을 목록에서 강조하고 저장·수정·취소·삭제 흐름을 명확하게 정리했습니다.
- 버프 목록을 가나다순으로 정렬하고 선택된 버프만 보기, 이미지 표시, 스크롤 위치 유지 동작을 개선했습니다.
- 더 이상 게임에서 사용하지 않는 버프를 목록에서 제거하고, 누락되거나 잘못 연결된 버프 이미지를 보완했습니다.
- 의미가 겹치거나 불필요한 `사망 시 삭제`, `재접속 시 삭제` 안내는 표시하지 않도록 정리했습니다.

### 메뉴와 가이드 정리

- 기존 검 강화하기의 아이콘은 유지하면서 `미니게임` 1depth 아래에 검 강화하기와 QTE 챌린지를 각각 배치했습니다.
- 신규 기능과 변경된 계산기·버프 화면을 앱 가이드와 문서에 반영했습니다.

---

## Fixed

- QTE의 성공 영역이 한 바퀴 범위를 벗어나거나 파란색·노란색 영역이 떨어져 표시되던 문제를 수정했습니다.
- HUD 위치 설정을 시작할 때 테일즈위버가 실행 중인데도 게임을 실행하라는 안내가 표시되던 문제를 수정했습니다.
- 버프 목록에서 항목을 펼치거나 추가할 때 스크롤이 화면 맨 위로 이동하던 문제를 수정했습니다.
- 진화 재료 비용 계산기에서 일부 재료 이미지가 표시되지 않거나 세로로 긴 이미지가 잘리던 문제를 수정했습니다.
- 진화 계산 이력을 수정한 뒤 저장하거나 취소할 때 단계와 금액 입력이 남아 중복 이력을 만들기 쉬웠던 문제를 수정했습니다.

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.1.0.exe`를 다운로드합니다.
2. 설치 프로그램을 실행하면 기존 설정과 모험 일지 데이터를 유지하며 업데이트됩니다.
3. 자동 업데이트를 사용 중이면 v3.1.0 게시 후 앱 시작 화면에서 다운로드와 설치가 진행됩니다.
