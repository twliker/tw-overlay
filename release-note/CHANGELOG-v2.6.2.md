# 📦 TW-Overlay Release Note - [Mandatory Update] v2.6.2 (2026-08-17)

이번 v2.6.2 버전은 신규 숙제 3종(혼란한 대지, 색을 잃은 땅, 설계자의 채굴장) 추가, ELSO 및 경험의 정수 자동 획득 파싱 지원, 게임 오버레이 위치 설정 창 Z-Order 개선이 적용된 기능 및 안정화 업데이트입니다.

---

## 🚀 주요 변경 사항

### 🗺️ 신규 숙제 컨텐츠 및 자동 체크 연동 (Added)
- **혼란한 대지 (`daily-confused-land`)**:
  - 일일 1회 숙제 목록에 신규 추가되었습니다.
  - 감정 균형 장치 방어 보상 획득 시 자동으로 일일 숙제가 완료 처리됩니다.
  - 방어 보상 및 미션 성공 시 지급되는 ELSO 포인트(가변 금액)를 실시간 감지하여 모험일지에 자동 적립합니다.
- **색을 잃은 땅 (`daily-colorless-land`)**:
  - 일일 1회 숙제 목록에 신규 추가되었습니다.
  - 색을 잃은 땅 미션 성공 로그 감지 시 자동으로 일일 숙제가 완료 처리됩니다.
  - 미션 성공 및 미션 효과 미적용 보상 ELSO 포인트를 실시간 감지하여 자동 적립합니다.
  - 긴 문장으로 인해 줄바꿈 분리된 보상 로그를 안전하게 결합하여 **경험의 정수** 획득 수량을 누락 없이 자동 추출 및 모험일지에 기록합니다.
- **설계자의 채굴장 (`daily-architect-mine`)**:
  - 일일 1회 숙제 목록에 신규 추가되었습니다.
  - 채굴장 입장 시 확정 획득하는 하급 조합 조각 로그를 감지하여 자동으로 일일 숙제가 완료 처리됩니다.

### 💎 로그 정규화 및 ELSO/아이템 파싱 확장 (Changed)
- **범용 ELSO 포인트 파싱 지원**:
  - 다양한 형태의 ELSO 획득 및 추가 보상 문구를 모두 지원하도록 파서를 고도화했습니다.
- **다중 아이템 획득 문구 파싱**:
  - 쉼표(`,`)로 나열된 복합 보상 로그에서 주요 추적 아이템(경험의 정수 등)을 정확히 인식하도록 지원을 강화했습니다.
- **줄바꿈 분리 로그 정규화(Normalizer) 개선**:
  - CRLF 줄바꿈 환경 및 미션 성공/보상 어미 미완결 줄바꿈 로그의 연속 결합 안전성을 개선했습니다.

### 🪟 게임 오버레이 위치 설정 창 UX 개선 (Fixed)
- **오버레이 위치 설정 가이드 창 Z-Order 개선**:
  - 게임 오버레이 위치 설정 시 가이드 창이 게임창 뒤로 숨겨지지 않도록 개선하고, 최소화되어 있던 게임 창이 자동으로 정상 복원되도록 처리했습니다.

## 📥 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-2.6.2.exe`를 다운로드합니다.
2. 기존 버전이 실행 중인 경우 완전히 종료한 후 설치 파일을 실행하여 업데이트를 진행합니다.
3. 앱 실행 시 기존 설정과 모험 일지 데이터는 안전하게 유지되며, 신규 숙제 목록이 자동으로 병합됩니다.
