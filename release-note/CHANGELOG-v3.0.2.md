# 📦 TW-Overlay Release Note - v3.0.2 (2026-08-29)

이번 **v3.0.2 업데이트**는 v3.0.1 배포 뒤 확인한 데이터 보호·복원·보안 결함을 보완하고, 설정 화면과 게임 기록 기능에서 발견된 누락 및 사용성 문제를 수정한 안정화 패치입니다.

---

## Added

### 게임 완료 알림 설정

- 경험의 정수 교환, 도전과제 완료, 심연의 보물창고 완료 알림을 각각 켜거나 끌 수 있습니다.
- 각 알림의 소리와 음량을 개별 설정할 수 있습니다.

### 과거 채팅 로그 전체 재분석

- 이미 동기화한 로그까지 다시 분석하는 선택 항목을 추가했습니다.
- 전체 재분석 시 기존 채팅 로그 기반 자동 기록을 날짜별로 다시 만들며, 사용자가 직접 작성한 기록은 보존합니다.
- 과거 로그만으로 수행 캐릭터를 알 수 없는 숙제는 메인 캐릭터 기록으로 안내하고 복원합니다.

### 계수 계산기 주스탯 합계

- 총합 계수와 명중 사이에 사용자가 입력한 `캐릭터 스탯 / 장비 스탯` 주스탯 값을 함께 표시합니다.

---

## Changed

### 설정 화면 정리

- 여러 창과 설정 화면에 중복되어 있던 항목의 담당 위치를 정리하고, 필요한 경우 관련 설정으로 이동하는 안내를 추가했습니다.
- 설정 검색 결과와 실제 화면 연결을 보강하고, 중복된 화면 요소와 의미 없는 내부 탭을 제거했습니다.
- 새 설정이 추가되거나 일부 값이 안전한 기본값으로 복구됐을 때 표시하는 안내를 일반 사용자가 이해하기 쉬운 문장으로 바꿨습니다.

### 경험의 정수 및 모험 일지 정책

- 경험치가 정확히 100억 감소한 로그를 경험의 정수 교환 1회로 집계해 수동 교환과 자동 교환을 같은 기준으로 처리합니다.
- 경험의 정수 경고용 누적을 세션 통계에서 분리했습니다. 정상 자동 교환 직전 오경고를 피하도록 10억 여유를 두어 교환이 없으면 110억·210억·310억 경계에서 경고하고, 정확한 100억 감소를 감지하면 경고용 누적을 초기화합니다.
- 오늘 요약에서는 경험의 정수를 전용 합계로만 표시해 일반 득템 종류·목록과 중복되지 않도록 했으며, 과거 로그 동기화 결과도 로그 줄 수가 아닌 실제 정수 수량으로 안내합니다.
- 경험의 정수는 오늘 요약과 관련 통계에는 반영하지만, 사용자가 득템 키워드로 관리할 수 없는 모험 일지의 득템 목록·이번 달 누적 득템 목록에서는 제외합니다.

### 사용 통계 고지와 제어

- 정식 배포판의 익명 사용 패턴 전송은 유지하되 설정에서 사용자가 끌 수 있도록 했습니다.
- 전송 대상과 Google Analytics 처리 관계를 개인정보처리방침에 실제 동작과 맞게 설명하고, 오류 원문 대신 분류된 오류 정보만 전송합니다.

---

## Fixed

- Google Drive 원격 변경, 인증 만료·재로그인, 설정만 선택 복원과 앱 재시작이 겹칠 때 로컬 설정이나 숙제 변경이 사라질 수 있던 문제를 수정했습니다.
- 로컬·클라우드 복원 전 백업 실패, 복원 도중 종료, 허용 범위 밖 파일 복원과 이전 클라우드 캐시 재사용 문제를 보완했습니다.
- 관리자 권한으로 실행되는 AI 분석 서버와 모델을 검증하고, 다운로드 중단이나 동시 설치 뒤 서로 다른 파일이 섞이지 않도록 교체 절차를 강화했습니다.
- 업데이트 안내와 사용자 지정 알림의 문자열이 화면 코드로 해석될 수 있던 경로를 안전한 텍스트 렌더링으로 변경했습니다.
- 경험치 측정을 같은 분 안에서 일시정지했다 재개하면 현재 분 그래프 기록이 사라지던 문제를 수정했습니다.
- 설정 화면에서 검색·미리보기·단축키 입력 중 `Esc`를 누르면 해당 상태뿐 아니라 설정 창까지 닫히던 문제를 수정했습니다.
- 일일 숙제는 일일 항목 안에서, 주간 숙제는 주간 항목 안에서만 이동하고 변경한 순서가 재시작 뒤에도 유지되도록 수정했습니다.
- 실시간과 과거 채팅 로그에서 경험의 정수 교환 및 획득 집계가 누락되던 문제를 수정했습니다.
- 일반·클럽·팀·귓속말·외치기에서 사용자가 언급한 SEED 금액을 실제 획득으로 잘못 기록하던 문제를 수정했습니다.
- 게임 실행 중 과거 채팅 로그를 전체 재분석하면 오늘 기록 교체가 보류되거나 동기화 중 들어온 로그가 빠질 수 있던 문제를 수정했습니다. 시작 시점 이후의 오늘 로그도 순서대로 이어서 반영합니다.
- 경험치 세션을 정지하거나 초기화했을 때 경험의 정수 경고 추적까지 함께 끊기던 문제를 수정하고, 교환 로그가 세션 총 경험치를 차감하지 않도록 회귀 검사를 보강했습니다.
- 게임 재접속이나 해상도 전환 중 버프 타이머 등 게임 HUD의 저장 위치가 중앙 좌표로 바뀌던 문제를 수정했습니다.
- 과거 로그의 마정석, 지난주·지지난주 숙제 기록과 주간 상세 완료 수가 누락되던 문제를 수정했습니다.
- 장비 사전의 진화 비용 계산 버튼 연결을 복구했습니다.
- 외부 프로그램이 활성화된 상태에서 사이드바 1depth를 올려 열린 서브메뉴를 처음 클릭하면 입력이 무시되던 문제를 수정했습니다.
- 시작 메뉴 아이콘은 정상인데 실행 중 작업표시줄의 일부 창에 Electron 기본 아이콘이 표시되던 문제를 수정했습니다.
- 게임창 따라가기를 껐는데도 채팅·숙제·도구 창이 게임 위치를 기준으로 복원되어 재실행 뒤 위치가 초기화된 것처럼 보이던 문제를 수정했습니다. 따라가기를 켜면 게임 기준 위치, 끄면 화면 고정 위치를 각각 유지합니다.
- 게임 실행 중 창모드와 창모드 전체화면을 바꿀 때 보조 창이 전환 중간 좌표를 따라 화면 밖으로 이동한 뒤 중앙에 저장되던 문제를 수정했습니다. 두 화면 모드의 위치를 각각 기억하며, 전환 중에는 보조 창 위치 저장과 화면 이탈 복구를 잠시 멈춥니다.
- 게임이 없거나 최소화된 상태에서 트레이로 연 기능 창은 화면 중앙에 임시 표시하고, 이때 옮긴 위치는 게임용 위치에 저장하지 않도록 했습니다.
- 테일즈위버를 먼저 실행한 뒤 TW-Overlay를 실행하면 첫 포커스 판정이 누락되어 단축키가 동작하지 않던 문제를 수정했습니다.
- 채팅 계열 창의 최소 높이와 실시간 크기 변경 기준을 통일하고, 드래그와 스톱워치의 불필요한 화면 갱신을 줄였습니다.

---

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.0.2.exe`를 다운로드합니다.
2. 설치 프로그램을 실행하면 기존 설정과 모험 일지 데이터를 유지하며 업데이트됩니다.
3. 자동 업데이트를 사용 중이면 v3.0.2 게시 후 앱 시작 화면에서 다운로드와 설치가 진행됩니다.
