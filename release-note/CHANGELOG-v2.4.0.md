# 📦 TW-Overlay Release Note - [Mandatory Update] v2.4.0 (2026-08-15)

이번 v2.4.0 버전은 오늘의 플레이 현황을 게임 화면에서 바로 확인할 수 있는 요약 HUD와 사냥 경험치·렐릭 강화 계산기를 추가한 기능 업데이트입니다. 채팅 로그의 아이템 획득 감지와 환경 설정 구조도 함께 개선했습니다.

---

## ✨ Added (신규 기능)

- **오늘 요약 HUD**
  - 모험 일지의 오늘 획득 아이템, SEED, ELSO와 숙제 체크리스트의 미완료 항목을 게임 화면에 표시합니다.
  - 같은 아이템은 수량을 합산하고, 접힌 상태에서는 핵심 수치만 간략하게 보여줍니다.
  - 기본 단축키 `Ctrl+Shift+Y`로 접힘 → 펼침 → 숨김 → 접힘 상태를 순환합니다.

- **사냥 경험치 계산기**
  - 경험치 도핑 목록과 해피아워를 조합하여 1마리·시간당 예상 경험치를 계산합니다.
  - 예상 경험치를 100억당 경험의 정수 1개로 환산해 함께 표시합니다.
  - 사용자 도핑과 사냥터를 추가·수정할 수 있으며 기존 버프 이미지를 함께 표시합니다.

- **렐릭 강화 계산기**
  - 테일즈위버 공식 신조·루나리아 렐릭 강화 확률 400개를 기반으로 시뮬레이션과 기댓값 조회를 제공합니다.
  - 펜던트와 브라이슬릿의 현재 능력치를 항목별로 입력할 수 있습니다.
  - 목표 단계까지 예상 시도 횟수, 응축 가루·달의 파편, 신조의 정수·월광석과 총 SEED를 계산합니다.
  - 총 비용은 조·억·만 단위로 읽기 쉽게 표시합니다.

## ⚙️ Changed (개선 사항)

- **아이템 획득 로그 처리 강화**
  - 펫 자동 습득, 직접 습득과 시스템 보상 로그를 공통 획득 형식으로 정규화합니다.
  - 연속 메시지와 아이템 수량 표현을 정리해 모험 일지에 실제 획득 개수를 기록합니다.
  - 오케스트라 룸 보상으로 획득한 경험의 정수도 일반 득템과 동일하게 기록합니다.

- **사이드바·트레이 메뉴 재분류**
  - 기능을 플레이 관리 & 기록, 커뮤니티 & 채팅, 알림 설정, 계산기 & 시뮬레이터, 정보 & 도감으로 재분류했습니다.
  - 숙제 체크리스트와 검 강화하기의 기존 1depth 접근 방식은 유지합니다.

- **환경 설정 구조 개편**
  - 왼쪽에는 9개의 1depth 분류만 표시하고 세부 메뉴는 화면 상단의 가로 탭으로 이동했습니다.
  - 각 세부 메뉴를 독립 화면으로 분리해 항상 최상단부터 표시합니다.
  - 도전과제 기능을 HUD가 아닌 게임 오버레이 완료 알림으로 명확하게 표기했습니다.

- **내부 구조 개선**
  - 창 생성·배치·포커스·크기 조절과 설정 화면의 폼·단축키·메뉴·사운드 로직을 역할별 모듈로 분리했습니다.
  - 공통 메뉴·채팅 채널·창 위치 데이터를 단일 원본으로 관리하도록 정리했습니다.

## 🛠️ Fixed (버그 수정)

- 오케스트라 룸에서 경험의 정수 2개를 획득했을 때 아이템 이름에 `2개`가 포함되거나 수량이 1개로 기록되던 문제를 수정했습니다.
- 오늘 요약 HUD에서 같은 아이템이 여러 줄로 표시되던 문제와 간략 표시에서 ELSO가 누락되던 문제를 수정했습니다.
- 도핑 목록이 길어졌을 때 스크롤되지 않던 문제를 수정했습니다.
- 가이드의 사이드바·독 설정 바로가기와 모험 일지의 데이터 보관 바로가기가 잘못된 설정 화면을 열던 문제를 수정했습니다.
- 독립 설정 화면에 불필요한 상단 여백과 구분선이 남던 문제를 수정했습니다.

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-2.4.0.exe`를 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 설치 파일을 실행합니다.
