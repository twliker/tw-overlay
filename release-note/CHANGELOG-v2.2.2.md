# 📦 TW-Overlay Release Note - [Mandatory Update] v2.2.2 (2026-08-08)

이번 v2.2.2 버전은 창 위치 저장 안정성을 강화하고, 숙제 체크리스트 자동 복원 기능을 추가하며, 루미나의 회랑 ELSO 추가 획득 감지를 반영한 업데이트입니다.

---

## ✨ Added (신규 기능)

- **숙제창 열림 상태 자동 복원**
  - 설정 > 일반에서 "숙제창 상태 유지 및 자동 복원" 옵션을 활성화하면, 게임 복원/기동 시 이전에 열려 있던 숙제 체크리스트 창이 자동으로 다시 열립니다.

- **루미나의 회랑 ELSO 추가 획득 감지**
  - "루미나의 회랑 ELSO 획득량 증가 효과로 [N] ELSO 포인트를 추가로 획득했습니다." 패턴을 파싱하여 DB에 누적합니다.
  - 채팅 오버레이 엘소 필터 대상에도 동일하게 적용됩니다.

## 🛠️ Fixed (버그 수정)

- **서브2 및 숙제 체크리스트 창 위치 복원 안정성 개선**
  - 창을 닫을 때 설정이 즉시 저장되지 않아 위치가 유실되던 문제를 수정했습니다.
  - 화면 이탈 판정 최소 겹침 영역을 완화하여(30×30 → 10×10) 엣지 위치에서 창이 잘못 보정되는 현상을 줄였습니다.

- **숙제 체크리스트 토글 동작 개선**
  - 창 닫힘 시 `contentsCheckerEnabled` 상태가 설정에 즉시 반영되어, 재시작 후 상태가 올바르게 복원됩니다.

## ⚙️ Changed (개선 사항)

- **아이템 획득 문구 인식 범위 확장**
  - "획득했습니다" / "획득 했습니다" 표현도 아이템 획득 이벤트로 처리합니다.

- **설정 로드 시 `positions` 기본값 병합 보장**
  - 저장된 설정에 `positions` 키가 없거나 일부 항목만 있을 때도 기본값과 올바르게 병합됩니다.

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 최신 버전의 `twOverlay-Setup-2.2.2.exe` 파일을 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 `.exe` 설치 파일을 실행합니다.
