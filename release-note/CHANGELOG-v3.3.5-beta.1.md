# TW-Overlay v3.3.5-beta.1 (2026-11-05)

프로필 관리·모험일지·Google 동기화를 실제 PC에서 확인하기 위한 프리릴리즈입니다. 기존 프로필의 누락된 기본 숙제는 앱 시작 시 자동으로 보충합니다. 설치 전에 두 PC 각각 **환경설정 → 시스템 & 관리 → 데이터 관리 → ZIP 백업**으로 기존 데이터를 보관해 주세요.

## Added

- **프로필 관리**: 사이드바·독의 시스템 메뉴에서 관리합니다. 게임 시작 시와 게임이 실행된 상태에서 앱을 켰을 때 기록할 프로필을 선택합니다. 프로필 이름은 자유롭게 정하며 서버는 반드시 선택합니다.
- **프로필별 저장**: 숙제 전체, 알림·경험치 등 프로필 환경설정, 계수 계산기와 도핑 입력을 나눠 보관합니다. 기존 다중 캐릭터의 숙제·설정은 해당 수의 프로필로 이전하며 처음 설치하면 빈 기본 프로필 하나를 만듭니다.
- **새 Google 동기화**: 프로필·숙제·휴대 가능한 설정을 PC별 변경 파일로 동기화합니다. 처음 연결할 때 병합·Google 데이터 가져오기·이 PC 유지 중 선택하며 적용 전 ZIP 백업을 남깁니다.
- **모험일지 지출**: 어벤던로드 입장료를 음수 SEED로 자동 기록하고 수동 입력도 수익·지출을 선택할 수 있습니다. 선택한 프로필로 과거 로그를 복원할 때도 입장료 지출을 반영합니다.

## Changed

- 프로필 선택창을 간결하게 정리하고 일일·주간 숙제의 완료 수·비율·진행 막대를 표시합니다. 게임창 중앙에 처음 표시하며 최소화 상태에서는 자동 선택창을 보류합니다.
- **순서 변경**에서 드래그·위아래 버튼·손잡이의 방향키로 프로필을 정렬합니다. 이 PC의 순서로 즉시 저장하고 종료 리마인더 탭에도 적용합니다.
- 게임 종료 리마인더에서 프로필별 탭으로 남은 숙제를 확인합니다.
- 내용이 부족한 숙제 대기 기록은 원문을 보존한 채 **무시하기**로 목록에서 정리할 수 있습니다.
- 삭제된 프로필은 모험일지의 일반 조회 선택지에서 숨깁니다. **이전 프로필 정리 → 무시하기 → 미배정으로 옮기기**로 기록을 미배정에 합칩니다. 원본은 보존하며 현재 프로필에 배정하지 않습니다.
- 조회 범위와 새 수동 기록의 저장 대상을 명확히 구분하고 드롭다운을 어두운 테마에 맞췄습니다.

- 모험일지는 공유 저장소에서 프로필별·전체로 조회합니다. Google에는 모험일지·채팅 원본·시간 측정 기록·진행 중 HUD를 전송하지 않습니다.
- Google 동기화는 게임 표시 중 약 30초, 최소화·숨김·종료 중 약 5분마다 확인합니다. 같은 항목의 수정 순서를 확정할 수 없으면 양쪽 값을 보존하고 선택을 받습니다.
- 이전 Google 동기화 파일은 자동으로 가져오거나 삭제하지 않습니다. 사용할 PC들을 같은 베타 버전으로 업데이트한 뒤 연결해 주세요.
- 활동 프리셋을 제거하고 프로필별 설정으로 통합했습니다.

## Fixed

- 개발 콘솔의 연결이 끊겨도 숙제·모험일지 기록이 콘솔 오류 때문에 중단되지 않도록 수정했습니다.
- 게임 종료 안내가 반복 호출될 때 창이 계속 쌓이지 않고 기존 창의 내용을 갱신하도록 수정했습니다.

- 오늘 로그의 마지막 행에 줄바꿈이 없어도 완전한 기록은 복원하고 이후 실시간 기록을 이어받습니다.
- 거래 서버 변경이나 새로고침 응답이 역순으로 도착해도 이전 결과가 최신 목록을 덮어쓰지 않습니다.
- 앱 런타임을 지원 중인 Electron 45 계열로 올리고 빌드 도구의 보안 경고를 해결했습니다. 데이터 이전·화면 연결·배포 파일 구성을 검사하며 실제 설치와 관리자 권한 창 동작은 별도 확인합니다.

- 구버전 지불 원문과 과거 복원 입장료가 같은 날짜·초·금액으로 함께 집계되는 문제를 수정했습니다. 원본은 보존하고 1:1 대응하는 구형/복원 기록만 한 번 집계합니다. 서로 다른 현재 프로필과 수동 지출·정상 반복 기록은 유지합니다.
- 음수 SEED도 양수와 동일한 억·만 단위로 표시합니다.
- 프시키·아크론·이클립스 아티팩트의 디펜시오 이름을 복구하고 데이터 생성 시 이름이 다시 누락되지 않도록 수정했습니다.

- 과거 로그 복원 검사에서 특정 숙제의 상태를 ID로 확인하고, 복원 실패 시 기본 목록 전체와 다른 프로필의 상태 보존도 확인합니다.

- 새 프로필·설정 복사·마지막 프로필 삭제 후 기본 프로필 생성에 실제 기본 숙제 전체를 사용합니다.
- 이전 베타에서 누락된 기본 항목을 자동 복구합니다. 기존 완료 횟수·N/A·숨김·이름·분류·순서·커스텀 숙제는 보존하며 명시적으로 삭제한 항목은 되살리지 않습니다. 백업 복원과 Google 수신 후 빈 목록도 같은 기준으로 보충합니다.
- 임의의 테스트 숙제만 사용하던 검증에 실제 배포 기본 목록과 제품 체크리스트 화면 검사를 추가했습니다. 복구 실패 시 부분 저장 방지와 재시작 후 중복 없는 복구도 확인합니다.

- 메모 저장과 창 배치·HUD 편집의 자동 검사를 현재 설정 저장 경로에 맞췄습니다. 제거한 활동 프리셋 메뉴를 호출하던 검사 코드를 정리하고 실제 저장·공유·좌표 복원 검증을 유지합니다.

- 자동 빌드의 설정 화면 검사에서 발생한 GPU 화면 캡처 중단을 수정했습니다. 검사 화면에 소프트웨어 렌더링을 사용하며 실제 캡처와 기능 검사는 그대로 수행합니다.

- 커스텀 숙제 추가 결과를 눈에 띄게 표시하고 추가한 숙제 위치로 스크롤합니다.
- 숙제 창의 닫기 버튼 잘림, 프로필과 숙제 드롭다운의 낮은 대비, 좁은 모험일지의 월 제목과 합계 표시를 개선했습니다. 일별 **시드 합계**에는 지출도 포함됩니다.
- 앱을 열 때 메뉴 로딩과 클릭 통과 설정이 겹쳐 사이드바에서 오류가 나는 문제를 수정했습니다. 에타 랭킹의 검색창과 안내 메시지도 읽기 쉽게 정리했습니다.
- 다른 PC 백업을 복원했을 때 원래 PC의 전송 완료 상태 때문에 새 PC의 변경 전송이 누락되는 문제를 방지합니다.
- Google 데이터로 교체할 때 미저장 설정·숙제 입력을 보존하고 먼저 저장하도록 안내합니다.

## 설치 및 두 PC 테스트

1. 이 프리릴리즈의 Assets에서 `twOverlay-Setup-3.3.5-beta.1.exe`를 받아 두 PC에 설치합니다.
2. 각 PC에서 기존 데이터의 이전 결과와 서버를 확인하고, 게임 시작 시 사용할 프로필을 선택합니다.
3. **환경설정 → 시스템 & 관리 → 데이터 관리**에서 같은 Google 계정으로 연결합니다. 첫 연결의 병합·가져오기 선택을 확인합니다.
4. 서로 다른 프로필 수정, 같은 설정·숙제 동시 수정, 한쪽 종료·재접속을 확인합니다.

이 프리릴리즈는 정식 최신 버전으로 지정하지 않습니다. 정식 버전 사용자는 베타 설치 파일을 직접 선택해 설치합니다.

## 검증 상태와 남은 확인

프로필·동기화 관련 자동 검사와 독립 앱 프로세스 2개의 동시성 시나리오 10개가 통과했습니다. 프로필·숙제·모험일지·환경설정의 주요 흐름을 기본 크기의 Windows 창에서 직접 확인했습니다. 실제 Google 연결과 두 PC 간 동기화, 실게임, 관리자 권한 창 순서, 설치 업데이트는 이 프리릴리즈에서 확인할 항목입니다.

3.5.0 베타를 이미 설치했다면 이 버전의 설치 파일을 직접 실행해 주세요. 기존 데이터는 유지하도록 설계했으며 실제 설치 전환은 이번 실사용 검증에 포함됩니다.
