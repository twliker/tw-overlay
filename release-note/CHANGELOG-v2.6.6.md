# 📦 TW-Overlay Release Note - v2.6.6 (2026-08-19)

이번 v2.6.6 버전은 **채팅 오버레이 제외 필터 기능 추가 및 최소 세로 크기 완화**, **전역 숫자 UI tabular-nums 적용**, **앱 정보 넥슨 저작권 고지 추가**가 적용된 패치 업데이트입니다.

---

## 🚀 주요 변경 사항

### 💬 채팅 오버레이 제외 필터 기능 추가 (Added)
- **채팅 오버레이 전용 블랙리스트 필터 추가**:
  - 채팅 오버레이에서 특정 키워드가 포함된 메시지를 숨기는 제외 필터 기능을 추가했습니다.
  - 채팅 종류(일반/시스템/클럽 등)에 관계없이 모든 채팅에 적용됩니다.
  - 기믹 알림, 득템 DB, 디스코드 전송 등 다른 기능에는 영향을 주지 않습니다.
  - 필터 키워드는 최소 5글자 이상으로 강제 검증되며 즉시 적용 버튼으로 실시간 반영됩니다.
  - 설정창 [채팅 & 외치기] → [채팅 오버레이] 탭에서 제외 필터 카드를 통해 관리할 수 있습니다.

### 📏 채팅 오버레이 최소 세로 크기 완화 (Changed)
- 채팅 오버레이 최소 세로 크기를 **200px에서 80px로 완화**하여 더 얇은 형태로 사용할 수 있습니다.
  - 마우스 드래그 리사이즈 및 설정창 세로 크기 입력 모두 80px까지 허용.

### 🔢 전역 숫자 UI 흔들림 방지 (Changed)
- 전역 스타일 및 팝업 화면(game-overlay.html, update-notice.html, welcome-guide.html)에 tabular-nums를 적용하여, 숫자 자릿수가 바뀔 때 주변 레이아웃이 흔들리는 현상을 방지했습니다.

### ⚖️ 앱 정보 저작권 고지 추가 (Added)
- [앱 정보] 탭에 테일즈위버 게임 리소스에 대한 넥슨 저작권 고지를 추가했습니다.

---

## 📥 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 twOverlay-Setup-2.6.6.exe를 다운로드합니다.
2. 기존 버전이 실행 중인 경우 자동으로 스플래시 화면에서 업데이트가 진행되거나, 설치 파일을 실행하여 즉시 업데이트할 수 있습니다.
3. 앱 실행 시 기존 설정과 모험 일지 데이터는 안전하게 유지됩니다.
