# 📦 TW-Overlay Release Note - v3.1.2 (2026-09-05)

이번 **v3.1.2 업데이트**는 채팅 오버레이 설정과 창 조작을 개선하고, 프로그램 화면이 보이지 않거나 게임 복원 뒤 늦게 표시되는 문제를 완화한 안정화 업데이트입니다.

---

## Added

### 채팅 오버레이 기본 탭 표시 설정

- 통합·일반·귓속말·팀·클럽·외치기·시스템 중 필요한 기본 탭만 상단에 표시할 수 있습니다.
- 기본 탭 표시 설정과 여러 채널을 묶는 사용자 정의 탭 관리를 구분했습니다.
- 모든 기본 탭을 해제해도 채팅창이 비지 않도록 통합 탭을 유지합니다.

### 보조 창 크기 조절

- 설정·계산기·도구 등 일반 보조 창의 크기를 조절할 수 있습니다.
- 조절한 크기는 저장되어 다음 실행에서도 유지됩니다.
- 테두리가 없는 창에는 우측 하단 크기 조절 손잡이를 표시합니다.

---

## Changed

### 창 닫기와 오버레이 복원 흐름

- 일반 설정·도구·팝업 창은 ESC로 닫을 수 있습니다.
- 검색·입력·도움말·편집 화면이 열려 있으면 ESC가 내부 화면을 먼저 닫습니다.
- 게임 조작 중 실수로 닫히지 않도록 채팅 오버레이, 웹 오버레이, Dock과 게임 HUD는 ESC 닫기 대상에서 제외했습니다.
- 게임 최소화 시 자주 사용하는 오버레이 렌더러를 보존해 게임 복원 뒤 다시 표시되는 지연을 줄였습니다.

### 버프 타이머 안내

- 버프 타이머 HUD 단축키를 누르면 켜짐·꺼짐 상태와 활성 버프 유무를 안내합니다.
- 설정 화면의 미리보기를 배포 빌드에서도 확인할 수 있도록 정리했습니다.

---

## Fixed

- 채팅 오버레이 탭 설정을 적용할 때 선택한 탭이 사라지거나 설정이 올바르게 반영되지 않던 문제를 수정했습니다.
- 마우스 투과 중 조작할 수 없는 채팅 스크롤바가 표시되던 문제를 수정했습니다.
- 화면 로드 실패나 렌더러 이상으로 UI가 보이지 않을 때 투명 창이 게임의 마우스 입력을 가로막는 문제를 방지했습니다.
- 게임을 오래 최소화한 뒤 채팅 오버레이와 숙제창이 늦게 나타나는 현상을 완화했습니다.
- 사용되지 않던 Win32 가상 키보드 입력 함수 `keybd_event`와 관련 상수를 제거했습니다.
- 프로덕션 간접 의존성을 안전한 버전으로 갱신해 알려진 보안 취약점을 해소했습니다.
- 아퀼루스에서 어비스로 진화할 때 손 부위 재료명이 `고대 기사의 건틀릿 파편`으로 표시되던 오타를 `고대 기사의 건틀렛 파편`으로 수정했습니다.
- 숨겨졌거나 사용할 수 없는 채팅 탭이 저장돼 있어도 표시 가능한 탭으로 안전하게 전환합니다.

---

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.1.2.exe`를 다운로드합니다.
2. 설치 프로그램을 실행하면 기존 설정과 기록 데이터를 유지하며 업데이트됩니다.
3. 자동 업데이트를 사용 중이면 v3.1.2 게시 후 앱 시작 화면에서 다운로드와 설치가 진행됩니다.
