# 📦 TW-Overlay Release Note - v3.0.0 (2026-08-27)

이번 **v3.0.0 업데이트**는 TW-Overlay가 테일즈위버와 하나처럼 자연스럽게 움직이도록 창 표시 정책을 다시 정리하고, 일반 설정과 숙제 체크리스트를 여러 PC에서 이어 쓰는 Google Drive 동기화를 정식으로 추가한 버전입니다.

---

## Added

### Google Drive 동기화

- 일반 설정과 숙제 체크리스트를 Google Drive의 앱 전용 저장 공간에 각각 저장하고 여러 PC에서 이어서 사용할 수 있습니다.
- 설정 변경과 숙제 변경을 따로 감지해 필요한 데이터만 자동 저장하며, 다른 PC의 변경은 게임 실행 중 약 30초, 게임 미실행 시 약 5분 간격으로 확인합니다.
- 데이터 관리 화면에서 클라우드에 지금 저장, 파일별 선택 불러오기, 저장 데이터 확인과 계정 연결 해제를 사용할 수 있습니다.
- 사이드바·독·숙제 체크리스트에서 정상, 변경 확인, 업로드, 다운로드, 오류 상태를 간단한 아이콘으로 확인할 수 있습니다.
- Discord Webhook URL, OAuth 토큰, 로컬 파일 경로, 커스텀 사운드, 창 위치와 크기, 모험 일지 DB·채팅 원본·알림 이력은 동기화하지 않습니다.

### 기록과 알림

- 금화 주머니 획득 수익을 `1개 = 500,000 SEED`로 계산해 모험 일지에 하루 한 줄로 누적 기록합니다.
- 심연의 보물창고 종료 메시지를 감지하면 알림음과 게임 오버레이로 완료를 알려줍니다.
- 여러 캐릭터가 같은 숙제에 참여할 때 남은 대상이 한 명이면 자동 체크할지, 캐릭터 선택창에서 직접 고를지 설정할 수 있습니다.

---

## Changed

### 자연스러운 창 순서

- TW-Overlay의 모든 창은 테일즈위버 바로 위에 함께 표시되며, 브라우저·메신저 등 사용자가 선택한 외부 프로그램의 Windows 창 순서를 강제로 바꾸지 않습니다.
- 게임으로 돌아오면 보이는 TW-Overlay 창들이 기존 내부 순서를 유지한 채 게임 위로 복귀하고 게임 포커스를 빼앗지 않습니다.
- 창모드와 창모드 전체화면, 같은 모니터·다른 모니터 전환에서 동일한 정책을 사용합니다.
- 독의 투명 여백은 마우스 입력을 게임으로 통과시키고 숨겨진 독 창은 다시 만들지 않고 재사용합니다.

### 화면과 가이드

- Google 동기화 화면은 일반 사용자가 상태와 주요 동작을 바로 이해할 수 있도록 단순화했습니다.
- 버프 백과는 이미지·이름·효과·지속시간 중심의 목록으로 정리하고 상세 정보는 툴팁으로 제공합니다.
- 모험 일지 달력은 기록이 많은 날짜를 접거나 펼칠 수 있으며, 에타 랭킹 창은 더 넓게 표시하고 사용자 크기를 기억합니다.
- 사용자 가이드의 누락 기능과 설명을 보완하고 현재 화면을 기준으로 기능 이미지를 전면 갱신했습니다.

### 성능과 안정성

- 대용량 채팅 로그, 잠긴 파일, 인코딩 변화와 로그 파일 재생성 상황에서도 정상 파일을 계속 처리하고 감시를 복구합니다.
- 채팅 기록은 화면 주변 행만 렌더링해 긴 기록에서도 DOM이 계속 증가하지 않도록 개선했습니다.
- 실제 채팅 로그 빈도를 기준으로 아이템 획득·일반 채팅·숙제 자동 감지의 불필요한 전체 설정 복사와 동일 상태 저장을 줄였습니다.

---

## Fixed

- 외부 프로그램을 선택했는데 테일즈위버와 TW-Overlay가 함께 앞으로 튀어나오는 문제를 수정했습니다.
- 외부 프로그램 위로 게임 HUD나 다른 TW-Overlay 창이 다시 올라오는 문제를 수정했습니다.
- 설정창을 열어 둔 채 채팅 오버레이 크기를 바꾸면 저장 및 닫기에서 이전 크기로 되돌아가던 문제를 수정했습니다.
- 독 모드에서 숙제 체크리스트와 검 강화하기 메뉴가 보이지 않거나 동기화 상태 아이콘이 즉시 갱신되지 않던 문제를 수정했습니다.
- 숙제 자동 감지가 이미 완료된 캐릭터 대신 다른 캐릭터 선택창을 반복해서 띄우던 회귀를 수정했습니다.
- 다른 PC에서 불러온 일일·주간 숙제가 리셋 시각을 지났는데도 완료 상태로 남던 문제를 수정했습니다.
- 손상된 클라우드 파일 하나 때문에 정상 설정 또는 숙제까지 복원하지 못하던 문제를 수정하고 파일별 결과를 안내합니다.
- 앱 종료·응답 유실·네트워크 단절 뒤에도 숙제 작업과 설정 변경을 다음 실행에서 확인하고 복구하도록 보완했습니다.
- 설정 저장이 최신 자동 시작 선택이나 열린 거래 게시판 창 연결을 이전 상태로 되돌릴 수 있던 문제를 수정했습니다.

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.0.0.exe`를 다운로드합니다.
2. 다운로드한 설치 프로그램을 실행하면 기존 설정과 모험 일지 데이터를 유지하며 업데이트됩니다.
3. Google 동기화를 사용하려면 **설정 → 시스템 & 관리 → 데이터 관리**에서 Google 계정을 연결하고 로그인 화면에서 Google Drive 권한을 확인해 주세요.
