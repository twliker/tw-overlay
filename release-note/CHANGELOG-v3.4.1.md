# TW-Overlay v3.4.1

어벤던로드 10회 완료 알림에 알림음을 추가했습니다. 오늘의 요약에 엘소·금화 주머니·등록 마정석이 바로 반영되지 않던 문제도 수정했습니다.

## Added

- 어벤던로드 지역 도전이 10회에 도달하면 카드와 함께 알림음을 냅니다. **설정 → 알림 → 게임 진행 → 어벤던로드 10회 완료 알림**에서 알림음과 볼륨을 고르고 미리 들어 볼 수 있습니다.
  - 기본 알림음은 `orb.mp3`, 볼륨은 40%입니다. 이 알림을 켜 두었다면 업데이트 후 10회 도달 때 소리가 납니다. 카드만 보려면 알림음을 **사용 안 함**으로 고르세요.
  - 알림음과 볼륨은 프로필 설정과 Google 동기화에 포함됩니다.

## Fixed

- 엘소 포인트, 금화 주머니, 등록 마정석만 얻는 동안 오늘의 요약 HUD가 다음 기록이 들어올 때까지 갱신되지 않던 문제를 수정했습니다.

## Changed

- 프로필을 선택한 뒤 HUD나 모험일지가 오류 없이 멈추는 경우를 찾기 위해 진단 기록(`[PROFILE_DIAG]`)을 `debug.log`에 남깁니다. 상태가 바뀔 때만 남기므로 로그 파일이 크게 늘지 않습니다. 이런 증상이 있으면 `debug.log`를 함께 보내 주세요.
