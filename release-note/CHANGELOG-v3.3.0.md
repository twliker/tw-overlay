# 📦 TW-Overlay Release Note - v3.3.0 (2026-10-26)

이번 **v3.3.0 업데이트**는 테일즈위버 19종 전체 캐릭터 아바타 연동과 함께 사용자의 여러 캐릭터/계정을 완벽하게 독립 분리하여 관리할 수 있는 **다중 프로필(Multi-Profile) 시스템**을 구축한 대규모 기능 업데이트입니다.

---

## Added

- **다중 프로필(Multi-Profile) 시스템 구축**:
  - 본캐 및 여러 부캐의 숙제 체크리스트 완료 상태(`completedState`), 창 위치 및 크기(`positions`), 단축키, 퀵슬롯, 버프 타이머, 채팅 오버레이, 알림 설정을 프로필별로 완전 독립 관리합니다.
  - 프로필 선택창(`profile-selector.html`)을 통해 전체 프로필 목록과 일일/주간 숙제 진행률을 한눈에 확인할 수 있습니다.
  - 사이드바, 하단 독(Dock), 트레이 메뉴, 숙제 체크리스트 상단에 프로필 전환/선택 버튼이 추가되었습니다.
- **테일즈위버 19종 전체 캐릭터 아바타 기본 탑재**:
  - 루시안, 보리스, 막시민, 시벨린, 티치엘, 밀라, 이스핀, 나야트레이, 조슈아, 클로에, 란지에, 이자크, 아나이스, 이솔렛, 벤야, 로아미니, 녹턴, 리체, 예프넨 19종 전체 캐릭터의 얼굴 중심(미간/콧대) 256×256 정밀 크롭 아바타를 기본 제공합니다.
  - 사용자 소장 스크린샷 이미지 업로드(PNG, JPG, WebP)도 지원합니다.
- **원클릭 프로필 복제(Duplicate)**:
  - 새 부캐 생성 시 기존 프로필의 UI 배치, 단축키, 버프 타이머 설정을 그대로 복제하여 새 프로필을 즉시 생성할 수 있습니다.
- **어벤던로드 입장료 모험일지 자동 지출 반영**:
  - 인게임 어벤던로드 입장 시 차감된 입장료(SEED)를 실시간 감지하여 모험일지의 지출(음수 `calc`)로 자동 기록합니다.
  - 마정석 교환 수익과 합산 시 정확한 던전 순수익이 산출됩니다. 과거 로그 재동기화 시에도 입장료가 정상 복원됩니다.
- **모험일지 프로필 필터 및 수동 지출 입력 지원**:
  - 모험일지 상단 프로필 필터를 통해 전체 모험 기록 또는 특정 캐릭터의 활동 타임라인만 모아볼 수 있습니다.
  - 수동 SEED 기록 시 수익(+) 외에 지출(-) 모드 토글 입력을 지원합니다.

---

## Changed & Improved

- **시작 팝업 자동 노출 최적화**:
  - 등록된 프로필이 1개 이하일 때는 앱 또는 게임 시작 시 프로필 선택창이 자동으로 뜨지 않도록 처리하여 불필요한 팝업 피로도를 제거했습니다.
  - 프로필이 2개 이상일 때만 설정된 자동 노출 옵션에 따라 선택창이 표시됩니다.
- **실시간 프로필 동기화 전파**:
  - 프로필 전환 시 열려 있는 모든 창(사이드바, 독, 체크리스트 등)의 아바타와 상태가 창 재시작 없이 즉시 실시간 동기화됩니다.
- **기존 숙제 체크리스트 단일 캐릭터 모달 정리**:
  - 기존 체크리스트 내 레거시 캐릭터 관리 팝업을 전용 프로필 시스템으로 완전히 일원화하여 조작 흐름을 단순화했습니다.
- **사이드바 메뉴 카테고리 세분화**:
  - 기존 '계산기 & 시뮬레이터' 카테고리를 '계산기'와 '시뮬레이터'(루미나의 회랑, 사냥터 동선 등)로 깔끔하게 분리했습니다.
- **Google Drive 동기화 무결성 강화**:
  - 클라우드 동기화 페이로드에 `profileStore`를 통합하여 다른 PC와의 다중 프로필 상태 동기화를 보장합니다.

## Fixed & Security

- **프로필 동시성 및 삭제 레이스 컨디션 해결**:
  - 활성 프로필 삭제 시 다음 프로필로의 전환이 완벽히 완료된 후 안전하게 스토어에서 제거하도록 비동기 순서를 보장하여 파일 충돌 및 상태 역전을 원천 차단했습니다.
- **특수문자/따옴표 포함 이름 예외 방어 (XSS 방지)**:
  - 프로필 이름에 따옴표나 특수문자가 포함되어도 아바타 로드 실패 시 인라인 자바스크립트 문법 에러가 발생하지 않도록 DOM API 및 이벤트 리스너로 렌더링 파이프라인을 개선했습니다.
- **프로필 모달 ESC 키 UX 보완**:
  - 생성/수정 모달이 열려 있을 때 ESC를 누르면 선택창 전체가 닫히지 않고 해당 모달만 닫히도록 개선했습니다.
- **모험일지 지출 삭제 시 점수 불변 유지**:
  - 지출(음수 금액) 행을 삭제하더라도 활동 점수가 부당하게 차감되지 않도록 보호 로직을 적용했습니다.

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.3.0.exe`를 다운로드합니다.
2. Microsoft Store 설치본은 Store 라이브러리에서 업데이트할 수 있습니다.
3. 업데이트 전에 환경 설정의 **데이터 관리 → ZIP 백업**으로 설정과 기록을 보관할 수 있습니다.
