# 릴리즈 노트: v3.3.4

**릴리즈 날짜:** 2026년 10월 28일

TW-Overlay v3.3.4는 다중 기기(회사-집 등) 간 원격 세션 동기화 안정성을 대폭 강화하고, 앱 실행 시 원치 않는 프로필 팝업 억제 및 숙제 화면의 렌더링 무결성을 확립한 긴급 패치 릴리즈입니다.

---

## 🚀 주요 변경 사항

### 1. 다중 기기 원격 활성 계정 자동 수렴 & 디스크 영속화
- **원격 최신 플레이 계정 자동 수렴:** 다른 PC(예: 회사)에서 특정 계정으로 플레이한 뒤 귀가했을 때, 클라우드 동기화 수신 시 원격에서 가장 최근에 플레이한 활성 계정으로 집 PC의 활성 프로필이 자동 전환되어 숙제 화면이 즉시 맞춰집니다.
- **활성 계정 디스크 영속화:** 클라우드에서 병합된 활성 계정의 최신 진행 상태가 디스크 물리 파일(`profiles/data/{id}.json`)에 즉시 기록되어 재시작이나 계정 전환 시에도 데이터가 100% 보존됩니다.
- **구글 드라이브 업로드 검증 안정화:** 업로드 직후 구글 드라이브 서버 전파 지연으로 인해 발생하던 불필요한 재시도 및 경고 로그 루프를 완화했습니다.

### 2. 앱 시작 시 강제 팝업 억제 및 레거시 마이그레이션 정상화
- **강제 팝업 차단:** `showOnAppLaunch` 기본값을 `false`로 변경하여, 앱 실행 시 사용자가 원치 않는데 프로필 선택창이 불쑥 뜨는 현상을 원천 차단했습니다.
- **레거시 프로필 경로 완벽 복원:** 기존 버전의 프로필 파일 위치(`userData/profiles.json`)를 정확하게 탐색하여, 버전 업데이트 시 사용자 동의 없이 엉뚱한 임의 프로필이 자동 생성되던 결함을 근본적으로 해결했습니다.

### 3. 숙제 화면(`contents-checker.html`) 프로필 ID 영속성 보장
- **IPC 수신 시 계정 유실 방지:** 백그라운드 동기화 신호(`config-data`)가 전달될 때 숙제 창이 활성 프로필 ID를 잃어버리고 빈 화면(0%)으로 리셋되던 렌더러 결함을 수정했습니다.
- **프로필 ID 매칭 방어 가드:** 계정 키 불일치 방어 로직을 적용하여 화면 렌더링 시 현재 활성 계정의 완료 내역이 항상 정확히 표시되도록 보강했습니다.
- **프로필 안내 툴팁 강화:** 숙제 화면 상단 프로필 버튼에 현재 활성화된 프로필 이름이 툴팁으로 명확히 안내됩니다.

- [Fixed] 버전 업데이트 직후 의도치 않은 임의 프로필이 자동 생성되고 프로필 선택창이 강제로 팝업되던 문제 해결
- [Fixed] 클라우드 동기화 수신 직후 숙제 창의 체크가 일시적으로 0%로 초기화되던 렌더러 버그 수정
- [Fixed] 활성 프로필의 원격 수신 데이터가 디스크 파일에 즉시 기록되지 않던 누락 수정
- [Fixed] 구글 드라이브 업로드 확인 시 서버 전파 지연으로 인해 재시도가 반복되던 현상 개선
