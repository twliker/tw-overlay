# 📦 TW-Overlay Release Note - v3.0.1 (2026-08-28)

이번 **v3.0.1 업데이트**는 v3.0.0 배포 후 확인된 창 전환과 표시 회귀를 수정하고, 모험 일지와 과거 채팅 로그 복원의 정합성·사용성을 보완한 안정화 패치입니다.

---

## Added

### 모험 일지 득템 목록

- 주간 또는 월간으로 전환해 날짜, 아이템 이미지, 아이템명과 수량만 모아보는 득템 전용 목록을 추가했습니다.
- 일자 달력에서는 같은 아이템을 한 줄로 합산하고, `더보기`와 `접기`를 누르면 같은 주의 모든 날짜 높이가 함께 바뀝니다.
- 앱 내부 시작 가이드에 과거 채팅 로그 복원의 용도와 설정 화면 바로가기를 추가했습니다.

---

## Changed

### 과거 채팅 로그 복원

- 이번 주 로그만 보던 수동 동기화 범위를 모험 일지 보관 기간 안에 남은 전체 채팅 로그로 넓혔습니다.
- 로그가 많을 때 앱이 멈추는 현상을 줄이기 위해 파일 확인과 상태 저장을 비동기로 처리하고, 준비·분석·마무리 진행률과 실패 파일을 계속 표시합니다.
- 오늘 로그는 안전한 파일 상태일 때 자동 기록을 다시 구성하며, 분석 중 새 로그가 생기면 기존 기록을 지우지 않고 병합합니다.
- 과거 숙제 기록은 현재 일일·주간 초기화 주기에 해당하는 내용만 체크리스트에 반영합니다.

### 알림 설정 접근성

- `설정 → 외부 알림 & 소리`에 `커스텀 알림음` 메뉴를 다시 독립적으로 표시합니다.
- MP3, WAV, OGG, WebM, M4A 파일 추가·미리듣기·이름 변경·삭제 기능과 설정 검색 바로가기를 유지합니다.

---

## Fixed

- 다른 프로그램이 게임을 완전히 가린 상태에서 작업표시줄의 TW-Overlay를 선택하면 오버레이만 떠 있던 문제를 수정했습니다. 사용자가 직접 TW-Overlay를 선택한 경우에만 게임을 먼저 표시하고 선택한 TW-Overlay 창으로 포커스를 돌립니다.
- `Ctrl + Shift + Z`로 경험치 측정을 일시정지했을 때 경험치 HUD가 함께 숨겨지지 않던 회귀를 수정했습니다.
- 등록 해제한 자동 득템과 마정석이 모험 일지에 계속 표시되던 문제를 수정했습니다. 사용자가 직접 추가한 수동 기록은 유지됩니다.
- 마정석 수량이 주간·월간 일반 득템 개수를 수천 건씩 부풀리던 문제를 수정했습니다.
- `룬 경험의 심장`이 등록 목록의 `경험의 심장`과 부분 일치해 잘못 기록되던 문제를 수정하고 실제 아이템명 정확 일치로 판정합니다.
- 득템이 많은 날짜의 아이템 배지가 찌그러지거나 같은 아이템이 수량별 여러 줄로 나뉘던 문제를 수정했습니다.

---

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.0.1.exe`를 다운로드합니다.
2. 설치 프로그램을 실행하면 기존 설정과 모험 일지 데이터를 유지하며 업데이트됩니다.
3. 자동 업데이트를 사용 중이면 v3.0.1 게시 후 앱 시작 화면에서 다운로드와 설치가 진행됩니다.
