# 📦 TW-Overlay Release Note - v2.6.7 (2026-08-20)

이번 v2.6.7 버전은 **커스텀 마우스 커서 깜박임 버그 수정**이 적용된 패치 업데이트입니다.

---

## 🚀 주요 변경 사항

### 🖱️ 커스텀 마우스 커서 깜박임 수정 (Fixed)
- 전역 :active 커서 CSS 규칙이 커스텀 마우스 커서와 충돌하여 클릭 시 커서가 순간적으로 깜박이는 현상을 수정했습니다.

---

## 📥 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 twOverlay-Setup-2.6.7.exe를 다운로드합니다.
2. 기존 버전이 실행 중인 경우 자동으로 스플래시 화면에서 업데이트가 진행되거나, 설치 파일을 실행하여 즉시 업데이트할 수 있습니다.
3. 앱 실행 시 기존 설정과 모험 일지 데이터는 안전하게 유지됩니다.
