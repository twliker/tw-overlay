# 📦 [Mandatory Update] TW-Overlay Release Note - v2.7.0 (2026-08-24)

이번 **v2.7.0 업데이트**는 채팅 오버레이 **커스텀 탭 및 시스템 6대 색상군 정밀 필터링**, **필수 업데이트([Mandatory Update]) 다운로드 엔진 고도화**, **게임 미실행 시 알림 수신 지원**이 적용된 **필수 업데이트([Mandatory Update])** 버전입니다.

---

## 🛠️ 주요 변경 사항

### 💬 1. 채팅 오버레이 커스텀 탭 & 시스템 6대 색상군 상세 필터링
- **사용자 정의 커스텀 탭 지원:** 일반, 귓속말, 팀, 클럽, 외치기, 시스템 대화 채널 중 원하는 채널만 조합하여 나만의 탭(예: `거래+귓`, `사냥 전용` 등)을 생성할 수 있습니다.
- **인게임 시스템 메시지 6대 색상군(`SystemColorGroup`) 정밀 분류:**
  - 🟣 **보라색 (경험치/버프/소모품/코어):** 경험치 획득, 군고구마, 심장류, 버프 만료 알림, 코어 세트 발동 등
  - 🟡 **노란색 (아이템 획득/긴급 공지):** 아이템 획득(득템, 엘소 등), 전 서버 긴급 점검 공지, 핫타임 이벤트
  - 🔴 **붉은색 (시스템 공지/팁):** 사기 주의 공지, 단축키 팁, 거래소 수수료 안내 등
  - 🟢 **초록색 (던전 진행/상태이상/앰플):** 남은 공격 횟수, 자동 퇴장 카운트, 속성 앰플 효과, 무력화, 피버 등
  - 🔵 **파란색 (인게임 알림):** 테일즈위버 인게임 채팅로그 동작 안내 등
  - ⚪ **흰색/회색 (보스 기믹 대사/NPC 대사):** 보스/사제 패턴 대사, NPC 일반 대사, SEED 획득 등
- **헤더 액션 분리 및 UI 개선:** 탭바에 위치하던 `채팅로그`, `검색(Ctrl+F)`, `설정` 버튼을 상단 드래그 헤더 우측의 컴팩트 아이콘으로 재배치하여 탭바 가독성과 탭 전환 편의성을 극대화했습니다.
- **커스텀 탭 히스토리 및 검색 연동:** 커스텀 탭에서도 상단 스크롤을 통한 과거 대화 내역 조회(무한 스크롤) 및 검색 기능이 완벽하게 연동됩니다.

### 🔄 2. 필수 업데이트([Mandatory Update]) 다운로드 엔진 고도화
- **다중 릴리즈 히스토리 탐색:** 이전 버전을 사용 중이던 사용자가 여러 버전을 건너뛰어 업데이트할 때도 상위 릴리즈 중 가장 최신의 필수 업데이트 버전을 감지하여 안전하게 순차 적용합니다.
- **스플래시 화면 무조건 잠금 & 자동 복구:** 필수 업데이트 감지 시 스플래시 화면을 유지하며 즉시 다운로드를 진행하고, 업데이트 체크/오류 발생 시 기본 GitHub 릴리즈 피드로 안전하게 복귀합니다.
- **다중 릴리즈 노트 표시:** 버전 간 누적된 여러 릴리즈 노트를 통합 포맷으로 스플래시 및 설정 창에 안내합니다.

### 🔔 3. 게임 미실행 시 알림 수신 옵션 추가
- **`notifyWhenGameClosed` 옵션 지원:** 테일즈위버 게임이 실행 중이지 않을 때에도 필드보스 알림 및 커스텀 알림(소리 및 Windows 토스트 알림)을 정상 수신할 수 있는 옵션이 추가되었습니다. (환경설정 및 보스 설정 창에서 토글 가능)
