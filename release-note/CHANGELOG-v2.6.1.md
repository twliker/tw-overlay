# 📦 TW-Overlay Release Note - [Mandatory Update] v2.6.1 (2026-08-17)

이번 v2.6.1 버전은 마우스 버벅임 및 간헐적 프리징 완화, 테일즈위버 게임창 항상 위 고정 방지, 경험의 정수 알림 개선 및 성능 최적화가 적용된 안정화 업데이트입니다.

---

## 🚀 주요 변경 사항

### ⚡ 성능 및 시스템 최적화 (Fixed & Changed)
- **마우스 버벅임 및 프리징(Stuttering) 완화**:
  - `WinEventHook` 범위를 포그라운드 활성화 감지(`EVENT_SYSTEM_FOREGROUND`) 단일 이벤트로 축소하여, 고폴링 게이밍 마우스 사용 시 발생하던 초당 수천 회의 Native $\to$ JS 콜백 오버헤드를 99% 이상 제거했습니다.
  - 사이드바 렌더러의 마우스 투과 상태 캐싱을 적용하여 마우스 이동 시 불필요하게 연속 호출되던 IPC 통신을 차단했습니다.
- **프로덕션 환경 로깅 최적화**:
  - 패키징된 배포 환경에서는 불필요한 정보성 로그 파일 쓰기를 제거하고 실제 오류 및 예외 로그만 기록하도록 필터링을 강화하여 디스크 I/O와 메인 스레드 부하를 최소화했습니다.

### 🛡️ 버그 수정 (Fixed)
- **테일즈위버 게임창 항상 위(Topmost) 고정 방지**:
  - 오버레이 윈도우 조작 시 Windows Z-Order 전염 현상으로 인해 게임 창이 간헐적으로 `WS_EX_TOPMOST` 계층으로 승격 고정되던 버그를 수정했습니다.
  - 게임 창 Z-Order 배치 시 `HWND_NOTOPMOST` 플래그를 적용하여 Non-Topmost 상태를 명시적으로 보장하고, `BringWindowToTop` 부작용을 제거했습니다.

### ✨ 기능 개선 (Changed & Added)
- **경험의 정수 알림 및 편의 기능 개선**:
  - 경험의 정수 획득 알림 및 쿨타임 추적 안정성을 강화했습니다.
- **주간 채팅 로그 데이터 동기화 및 어벤던로드 정산 안정화**:
  - 주간 채팅 로그 데이터 동기화 안정성 개선 및 어벤던로드 수익 계산 정산 로직을 고도화했습니다.
