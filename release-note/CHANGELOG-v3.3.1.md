# 📦 TW-Overlay Release Note - v3.3.1 (2026-10-27)

이번 **v3.3.1 업데이트**는 다중 프로필 시스템과의 숙제 감지 및 귀속·전환 연동을 완성하고, 보류 숙제 대기열의 정제 및 만료 폐기 라이프사이클을 개선한 안정화 릴리즈입니다.

---

## Added

- **다중 프로필 숙제 보류 귀속 및 프로필 전환 연동**:
  - 다른 캐릭터(프로필)로 플레이 중 이미 완료된 숙제가 감지될 경우, 해당 숙제를 아직 완료하지 않은 부캐릭터에게 손쉽게 귀속/배분할 수 있는 보류 모달을 제공합니다.
  - 보류 팝업에서 특정 부캐 카드를 클릭하면 해당 프로필로 즉시 전환되면서 감지된 숙제가 자동 완료 처리됩니다.
  - 미완료 부캐릭터가 1명뿐인 경우, 사용자 설정(`단일 후보 시 자동 귀속`)에 따라 팝업 없이 해당 캐릭터에게 즉시 자동 귀속되도록 지원합니다.

---

## Changed & Improved

- **보류 숙제 대기열 라이프사이클 일원화**:
  - 앱 시작(부팅), 정기 자정 리셋 타이머, 팝업 후보 조회, 새 숙제 유입 등 모든 진입점에서 보류 대기열 정제 함수(`sanitizeAndFilterPendingHomeworks`)를 일괄 경유하도록 개선했습니다.
  - 대기열에 남은 유효 숙제가 없는 경우 불필요한 팝업 렌더링 및 프로필 상태 조회를 조기 차단하여 성능을 최적화했습니다.

---

## Fixed

- **보류 팝업 `[주간] undefined 143회` 노출 버그 근본 해결**:
  - 사용자 설정 및 동기화 상태에 ID 필드가 누락된 비정상 객체가 저장되었을 때 발생하던 렌더링 결함을 수정하고, 부팅 시 손상 데이터를 자동으로 탐지하여 정제하도록 처리했습니다.
- **당일 미플레이 숙제(테시스 코어 던전 등) 보류 팝업 노출 결함 해결**:
  - 리셋 경계(일일 오전 0시 / 주간 월요일 오전 0시)가 지난 과거 보류 숙제가 자동 폐기되지 않고 영구 잔존하던 결함을 수정하여, 리셋 경과 시 자동으로 만료 폐기(GC)되도록 개선했습니다.
- **Google Drive 3방향 동기화 손상 객체 배제**:
  - 클라우드 3-way 병합 과정에서 ID가 없는 객체는 엔티티 키 맵 및 병합 결과에서 원천 배제하여 로컬과 클라우드 간의 무한 부활을 차단했습니다.
