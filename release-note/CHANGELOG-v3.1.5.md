# 📦 TW-Overlay Release Note - v3.1.5 (2026-09-28)

이번 **v3.1.5 업데이트**는 오늘의 요약 HUD와 신규 화면 고정 메모를 비롯해 보스전·사냥 보조 도구를 대폭 강화하고, 알림 드래그 배치·전체 음소거·활동 프리셋 등 사용자 편의 기능을 대거 도입한 업데이트입니다.

---

## Added

- **오늘의 요약 HUD 진행 중인 숙제 실시간 배지 표시**:
  - 던전 포탈 입장 시 오늘의 요약 HUD 상단에 현재 진행 중인 숙제(예: 어비스 심층 1/2)를 강조 배지로 즉시 표시합니다.
  - 당일 획득한 SEED, ELSO, 아이템 목록과 함께 현재 접속 중인 캐릭터의 잔여 숙제 현황(예: 본캐 숙제 3/6)을 실시간으로 집계합니다.
- **화면 고정 메모 HUD**:
  - 오늘의 모험 목표, 도핑 체크, 거래할 물품 등을 게임 화면 위에 항상 띄워둘 수 있는 '화면 고정 메모 HUD'가 추가되었습니다.
  - 드래그를 통한 자유 배치, 이동 잠금 모드 및 접기/펼치기를 지원합니다.
- **심층 보스 발판 보급품 실시간 안내**:
  - 어비스 심층 등 보스전에서 발판 기믹과 보급품 생성 타이머를 실시간으로 안내합니다.
- **미니 스톱워치 타임어택 HUD**:
  - 사냥터 및 보스전 타임어택 측정, 랩타임 기록, 배율 및 시간당 기댓값 연산을 지원합니다.
- **마정석 실시간 수익 집계 HUD**:
  - 사냥 중 획득한 마정석 수량을 실시간 감지하고 시세에 따른 순수익을 게임 화면에 표시합니다.
- **사냥터별 최적 이동 동선 가이드 HUD**:
  - 사냥터 진입 시 주요 몬스터 젠 위치와 최적의 사냥 동선을 오버레이 가이드로 안내합니다.
- **알림 팝업 드래그 배치 지원**:
  - 득템, 보스 출현, 단어 알림 등의 토스트 팝업을 게임 화면 내 원하는 위치로 마우스 드래그하여 배치할 수 있습니다.
- **전역 음소거(Mute All) 토글 지원**:
  - 게임 플레이 또는 디스코드 통화 중 프로그램의 모든 사운드 알림을 한 번에 끄고 켤 수 있는 단축키 및 트레이 옵션을 지원합니다.
- **활동 프리셋 및 기록 내보내기**:
  - 사냥, 보스 레이드, 일일 컨텐츠 등 상황에 맞는 오버레이 창 배치와 알림 설정을 프리셋으로 저장하고 전환할 수 있습니다.
  - 모험 일지 및 획득 내역을 CSV/JSON 파일로 내보낼 수 있습니다.

## Changed

- **업데이트 안내 팝업(Notice) 갤러리 UI 개선**:
  - 공지 팝업의 12종 스크린샷 썸네일 비율을 원본 비율 유지(`contain`)로 최적화하여 텍스트 및 UI 잘림 없이 한눈에 확인할 수 있도록 개선했습니다.
  - 스크린샷 클릭 시 고해상도 확대 보기(Lightbox)를 제공합니다.

## Fixed

- **게임 최소화 중 전체 창 숨기기/복원 시 창이 나타나지 않던 데드락 수정**:
  - 게임이 최소화된 상태에서 전체 창 숨기기 실행 후 게임 복귀 시 복원 대상 창들이 영구 억제 목록에 갇혀 나타나지 않던 가시성 동기화 문제를 근본적으로 해결했습니다.
  - 전체 창 숨김/복원 단축키가 게임 최소화 또는 백그라운드 상태에서도 즉시 반응하도록 전역 동작을 보장했습니다.

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.1.5.exe`를 다운로드합니다.
2. Microsoft Store 설치본은 Store 라이브러리에서 업데이트할 수 있습니다.
3. 업데이트 전에 환경 설정의 **데이터 관리 → ZIP 백업**으로 설정과 기록을 보관할 수 있습니다.
