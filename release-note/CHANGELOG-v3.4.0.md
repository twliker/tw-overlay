# TW-Overlay v3.4.0

사냥하는 동안 데이터 파일(`app-data.db`)이 커지던 문제를 줄이고, 프로필이 하나뿐이면 선택창 없이 바로 시작합니다.

## Added

- 프로필이 하나뿐이고 이름과 서버가 정해져 있으면 게임을 켤 때 선택창을 띄우지 않고 그 프로필로 바로 시작합니다. 게임을 최소화한 채 시작해도 같습니다.
  - 처음 설치해 이름·서버가 비어 있거나 프로필이 둘 이상이면 지금처럼 선택창이 열립니다.
  - 플레이 중 Google 동기화로 사용 중인 프로필의 이름·서버가 바뀌면 선택창에서 다시 확인합니다.

## Changed

- 사냥 중 데이터 파일이 거의 커지지 않습니다. v3.3.5는 채팅 줄마다 기록을 남겨 하루 사냥에 약 9~13MB씩 늘었는데, 이제 같은 사냥에서 1MB 안팎만 늘어납니다. 모험일지·숙제 기록과 중복 방지 방식은 그대로입니다.
- 디스크에 쓰는 횟수도 크게 줄였습니다. 경험치만 오르는 동안에는 최대 1분 간격으로 모아서 저장합니다.
- v3.3.5에서 업데이트하면 이미 쌓인 기록을 백그라운드에서 조금씩 새 방식으로 옮깁니다. 옮기는 동안에도 게임과 앱은 평소처럼 쓸 수 있고, 다 옮긴 뒤 빈 공간이 많으면 다음 실행 때 한 번 파일 크기를 줄입니다.
- 앱이 비정상 종료되면 마지막 1분 이내에 오른 경험치·처치 수가 경험치 HUD에서 빠질 수 있습니다. 모험일지와 숙제 기록에는 영향이 없습니다.
- PC 전원이 갑자기 꺼지면 마지막 몇 초 사이의 득템·SEED 기록이 자동 기록 대신 **미배정 기록**으로 돌아올 수 있습니다. 미배정 기록에서 프로필을 골라 배정해 주세요.

## Fixed

- 백신이나 검색 색인 프로그램이 설정 파일을 잠깐 열어 두면 프로필 선택이나 설정 저장이 취소되던 문제를 수정했습니다. 잠깐 기다렸다가 다시 저장합니다.

## v3.3.5로 돌아가기

v3.4.0에서 v3.3.5로 버전을 내리는 경우는 확인하지 않았습니다. 되돌릴 계획이 있으면 업데이트 전에 **환경설정 → 데이터 → ZIP 백업·복구**로 데이터를 보관해 주세요.
