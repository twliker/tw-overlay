# 📦 TW-Overlay Release Note - v3.2.0 (2026-10-14)

이번 **v3.2.0 업데이트**는 신규 컨텐츠 도구인 **루미나의 회랑 최적 경로 분석기**를 정식 추가하고, 이클립스 사도 에토스 보스전에서 기믹을 보다 명확히 파악할 수 있도록 **에토스 기믹 알림 커스터마이징 기능**을 전면 제공하는 업데이트입니다.

---

## Added

- **루미나의 회랑 최적 경로 분석기 (`lumina-corridor.html`)**:
  - 루미나의 회랑 맵 구조를 실시간으로 분석하여 점수 최대화 및 소요 시간 최소화 경로를 탐색해 주는 전문 도구를 사이드바에 추가했습니다.
  - **클립보드 스크린샷 자동 인식**: 게임 내 루미나 회랑 맵 창을 캡처한 후 `Ctrl+V`로 붙여넣으면 노드 종류(일반/특수)와 이동 경로 연결선을 자동으로 판독합니다.
  - **파티원 수별 점수 & 시간 계산**: 1인 솔로 플레이부터 4인 파티까지 인원수에 맞춘 획득 점수와 예상 클리어 시간을 실시간 시뮬레이션합니다.
  - **인터랙티브 경로 캔버스**: 자동 판독된 노드를 직접 클릭하여 연결 상태를 토글하거나 수동 보정할 수 있으며, 최적 경로를 시각적인 형광 하이라이트로 안내합니다.
- **에토스 기믹 알림 커스터마이징 & 실시간 미리보기**:
  - 황토색·베이지 바닥과 화려한 스킬 이펙트로 인해 묻히기 쉬웠던 에토스 기믹 알림을 사용자가 직접 커스터마이징할 수 있는 설정 섹션을 추가했습니다.
  - **4종 네온 색상 테마**: 핫 핑크/마젠타(기본값), 네온 옐로우, 네온 시안, 퓨어 레드 중 원하는 색상을 선택할 수 있습니다.
  - **화살표 크기 & 거리 조절**: 화살표 크기(60~180px, 기본 110px)와 캐릭터 중심으로부터의 표시 거리(60~240px, 기본 130px)를 슬라이더로 조절할 수 있습니다.
  - **시계 방향 & 암호 텍스트 배너**: 12시, 3시 등 직관적인 시계 방향 안내와 암호명(예: `⚡ [번개] 12시 (북쪽)`)을 화면에 함께 띄울 수 있습니다.
  - **[화면 미리보기] 지원**: 설정창에서 슬라이더나 색상을 변경한 후 [화면 미리보기] 버튼을 누르면 설정창을 닫지 않고 실제 인게임 오버레이에 가상 알림을 즉시 띄워 시인성을 바로 확인할 수 있습니다.

## Changed

- **에토스 기믹 알림 기본 시인성 강화**:
  - 기존의 작은 80px 흰색/하늘색 화살표에서 다중 레이어 글로우 필터와 굵은 네온 외곽선이 적용된 110px 핫 핑크 화살표로 기본 사양이 대폭 상향되었습니다.
- **사이드바 계산기 메뉴 확장**:
  - 사이드바 계산기 카테고리에 '루미나의 회랑' 런처 아이콘(`compass`)을 정식 배치했습니다.

---

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.2.0.exe`를 다운로드합니다.
2. Microsoft Store 설치본은 Store 라이브러리에서 업데이트할 수 있습니다.
3. 업데이트 전에 환경 설정의 **데이터 관리 → ZIP 백업**으로 설정과 기록을 보관할 수 있습니다.
