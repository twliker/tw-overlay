# 📦 TW-Overlay Release Note - v3.2.2 (2026-10-18)

이번 **v3.2.2 업데이트**는 유저 피드백을 반영하여 어벤던로드 보스 '누(Nu)' 공략에 필수적인 **마정석 대량 획득 서버 전체 공지 실시간 감지 및 마지막 수신 경과 시간 표시 기능**을 추가한 업데이트입니다.

---

## Added

- **어벤던로드 HUD 누(Nu) 마정석 획득 서버 공지 경과 시간 표시**:
  - 인게임 서버 전체 공지(`누군가 [ 누 ] 에게서 하급 마정석을 대량으로 획득 하였습니다`)를 실시간 감지하여, 마지막 획득 시점으로부터 흐른 시간(`방금 전` / `N분 전` / `N시간 전`)을 어벤던로드 위젯에 표시합니다.
  - 마우스를 올리면 실제 공지가 발생한 정확한 로그 시각을 툴팁으로 확인할 수 있습니다.
- **마정석 계산기 화면 내 동시 확인 지원**:
  - 마정석 계산기 화면의 `어벤던로드 오버레이 제어` 영역(즉시 표시 버튼 상단)에도 동일한 `누 전체 알림` 행을 추가하여, 계산기 창을 열어둔 상태에서도 마지막 공지 시각을 실시간으로 확인할 수 있습니다.

## Changed & Improved

- **마정석 누적 상태 판단 신호등 색상 적용**:
  - 유저들의 플레이 패턴(방금 털렸을 때는 누적량이 부족하고, 30분 이상 경과해야 충분히 누적됨)에 맞춰 직관적인 3단계 색상 구분을 적용했습니다:
    - 🔴 **10분 미만 (`text-rose-400`)**: 방금 누군가 마정석을 가져가서 수량이 부족한 주의 구간
    - 🟡 **10분 ~ 30분 미만 (`text-amber-400`)**: 서버에 마정석이 점차 누적되는 충전 구간
    - 🟢 **30분 이상 (`text-emerald-400`)**: 마정석이 충분히 누적되어 안심하고 누를 공략할 수 있는 안전 구간
- **테일즈위버 실제 로그 공백 완벽 대응**:
  - 테일즈위버 실제 로그 출력 형식인 `[ 누 ] 에게서`처럼 대괄호 안팎에 공백이 포함된 패턴을 완벽히 인식하도록 정규식을 정밀 최적화했습니다.
- **1초 단위 실시간 자동 갱신**:
  - HUD 또는 마정석 계산기 화면이 켜져 있는 동안 매초 경과 시간을 계산하여 분/시간 단위가 자연스럽게 올라가도록 처리했습니다.

## Fixed & Policy

- **비침해 상태 보존 정책**:
  - 서버 전체 공지는 개인 던전 플레이 활동이 아니므로, 마을이나 다른 사냥터에 있을 때 숨겨진 HUD가 화면을 가리며 강제로 튀어나오지 않고 내부 상태만 안전하게 기록합니다.
- **세션 초기화 시 서버 월드 상태 보존**:
  - 개인 어벤던로드 세션 통계(수익, 입장 횟수 등)를 초기화하더라도 서버 월드 정보인 마지막 공지 시각은 초기화되지 않고 유지됩니다.
