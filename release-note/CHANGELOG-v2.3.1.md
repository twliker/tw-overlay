# 📦 TW-Overlay Release Note - [Mandatory Update] v2.3.1 (2026-08-14)

이번 v2.3.1 버전은 게임 최소화, 재실행, 전체화면 전환과 모니터 구성 변경 이후에도 각 창의 저장 위치를 안정적으로 유지하도록 개선한 패치입니다. 독 런처의 펼침 메뉴도 독 영역에 맞춰 자동으로 줄바꿈됩니다.

> [Mandatory Update] 모든 사용자가 설치해야 하는 필수 업데이트입니다.

---

## ⚙️ Changed (개선 사항)

- **창 위치 복원 규칙 통합**
  - 일반 보조 창, 숙제 체크리스트, 브라우저 오버레이와 특수 도구 창에 동일한 화면 이탈 판정을 적용했습니다.
  - 창이 화면에 일부라도 보이면 사용자가 정한 위치를 유지하고, 모든 화면에서 완전히 사라진 경우에만 현재 게임 디스플레이 중앙으로 복구합니다.
  - 실제로 저장한 사용자 위치와 기본 위치를 구분하여 최초 배치와 복원 동작이 충돌하지 않도록 개선했습니다.

- **독 런처 반응형 펼침 메뉴**
  - 카테고리 메뉴가 독 창의 너비를 넘으면 여러 행으로 자동 배치됩니다.
  - 좌우 끝의 카테고리에서도 펼침 메뉴가 창 경계 밖으로 잘리지 않도록 위치를 보정합니다.

- **창·HUD 기본 위치 단일화**
  - 창과 게임 HUD의 기본 위치를 공통 원본에서 관리하도록 정리했습니다.
  - 경험치, 버프 타이머, 어벤던로드와 퀘스트 HUD가 게임 해상도 변경 후 완전히 사라진 경우 안전한 위치로 복구됩니다.

## 🛠️ Fixed (버그 수정)

- **최소화·재실행 후 창 위치 변경**
  - 프로그램이 이동한 창을 사용자 드래그로 잘못 저장하던 문제를 수정했습니다.
  - 창을 연 직후 빠르게 드래그한 위치가 무시될 수 있던 문제를 수정했습니다.
  - 게임 종료 후 이전 해상도와 전체화면 상태가 다음 실행에 남지 않도록 세션 상태를 초기화합니다.

- **실행 중 모니터 구성 변경**
  - 창이 열린 상태에서 게임 모니터를 옮기거나 모니터를 분리했을 때 보조 창이 화면 밖에 남을 수 있던 문제를 수정했습니다.
  - 게임 창 따라가기를 끈 브라우저 오버레이는 계산된 예정 위치가 아닌 실제 현재 위치를 기준으로 복구합니다.

- **숙제 체크리스트와 설정 창 복원**
  - 숙제 체크리스트가 저장 위치와 다른 화면 밖 좌표에 남을 수 있던 문제를 수정했습니다.
  - 설정 창이 멀티 모니터 환경에서 주 모니터 기준으로 강제 이동되던 예외 처리를 제거했습니다.

- **설정 파일 하위 호환성과 복구**
  - 구형 퀘스트 HUD 위치가 새 위치 설정을 계속 덮어쓰던 문제를 수정하고 자동 이전을 추가했습니다.
  - 손상된 설정 파일은 원본을 별도로 보존한 뒤 기본 설정으로 시작하고 복구 경로를 안내합니다.

## 📥 설치 및 적용 방법

**방법 1: 앱 내 설정 메뉴를 통한 업데이트 (권장)**

1. 앱 내부에서 **[설정]** 메뉴를 엽니다.
2. **[앱 정보]** 탭으로 이동한 뒤 **[업데이트 확인]** 버튼을 클릭하여 업데이트를 진행합니다.

**방법 2: 직접 다운로드하여 업데이트**

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 최신 버전의 `twOverlay-Setup-2.3.1.exe` 파일을 다운로드합니다.
2. 기존 앱을 완전히 종료한 후 다운로드한 `.exe` 설치 파일을 실행합니다.
