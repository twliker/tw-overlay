# TW-Overlay v3.3.5

정식 설치 파일 후보는 Electron 45.2.2를 사용합니다. 이 버전으로 런타임 호환성과 최종 Windows 설치 파일을 확인한 뒤 게시합니다.

## Added

- 프로필 하나에 캐릭터 하나의 숙제와 설정을 저장합니다. v3.2.2의 기존 캐릭터와 숙제 설정은 프로필로 이전됩니다. 프로필 선택창에서 일일·주간 진행률을 확인하고, 게임 종료 후에는 프로필별로 남은 숙제를 볼 수 있습니다.
- Google 로그인 후 이 PC와 클라우드 중 어떤 데이터를 사용할지 선택할 수 있습니다. 프로필·숙제·프로필 설정과 공통 알림 설정을 여러 PC에서 동기화합니다. 모험일지와 채팅 원본은 각 PC에 보관합니다.
- 모험일지에서 프로필별로 조회할 수 있으며 수동 SEED 기록에 지출을 입력할 수 있습니다. 어벤던로드 입장료도 지출로 자동 기록됩니다.
- 환경설정의 **채팅 로그 → 연결**에서 실행 중인 게임의 설치 경로를 찾을 수 있습니다.
- Google 동기화를 **나중에 설정**으로 미뤘다면 **동기화 다시 켜기**로 다시 로그인하지 않고 켤 수 있습니다.

## Changed

- 활동 프리셋 기능을 제거했습니다. 업데이트 직전 적용 중이던 설정과 창 배치는 유지됩니다. 따로 저장한 프리셋은 이전되지 않으며, 새 프로필은 **시스템 메뉴 → 프로필 관리**에서 설정할 수 있습니다.
- 사이드바와 독의 계산기·시뮬레이션 메뉴를 정리했습니다. 사이드바의 원형 배지에 현재 프로필의 첫 글자가 표시됩니다.
- 환경설정을 항목별로 나눴습니다. **HUD → HUD 위치**에서 HUD와 알림 위치를 편집할 수 있고, 고정 메모와 알림 기록은 별도 창으로 열립니다.
- 설정 검색, 체크박스와 드롭다운을 앱 테마에 맞췄습니다. 대메뉴를 펼치면 하위 메뉴가 보이도록 스크롤합니다.

## v3.2.2에서 업그레이드할 때

- 두 PC에서 서로 다르게 쓰던 고정 메모는 Google 동기화로 합칠 때 양쪽 내용을 `---`로 이어 붙여 모두 남깁니다. 발굴지 안내는 한쪽이라도 켜져 있으면 켭니다. 합친 메모가 1000자를 넘으면 **확인할 변경**에서 직접 고릅니다.
- 업그레이드 후 과거 채팅 로그를 복원하면 v3.2.2가 이미 실시간으로 기록한 날의 금화 주머니·엘소 포인트·마정석 합계는 원본을 보존한 채 **확인 필요**로 따로 표시하고, 모든 프로필 합계에는 한 번만 셉니다. 같은 날 v3.2.2가 기록한 숙제 완료는 복원한 프로필의 기록으로 옮겨집니다.
- 프로필 데이터 준비에 실패하면 종료하기 전에 새 버전을 확인할 수 있습니다(Microsoft Store 설치본은 Store에서 업데이트).

## v3.2.2로 돌아가기

v3.3.5는 프로필·설정·모험일지를 `app-data.db`로 이전합니다. 같은 폴더에서 버전만 내리면 v3.2.2의 `diary.db`와 v3.3.5의 기록이 따로 쌓이며 다시 업그레이드해도 자동으로 합쳐지지 않습니다.

1. v3.3.5에서 현재 데이터를 로컬 ZIP으로 백업한 뒤 앱을 종료합니다.
2. `%APPDATA%\twOverlay`의 현재 폴더를 다른 이름으로 보관합니다. 이전 버전에 사용할 새 `twOverlay` 폴더에는 `backups`의 `before-profile-preparation-…` 백업에서 업데이트 전 파일을 복사합니다. `renderer-storage.json`이 있으면 함께 복사하세요. v3.2.2가 처음 시작할 때 이 파일에서 계산기와 버프 프리셋을 불러옵니다. 이 파일이 없는 기존 백업에서 해당 설정까지 되돌리려면 v3.2.2에서 따로 만든 ZIP이나 업데이트 전 사용자 폴더가 필요합니다.
3. 다시 v3.3.5를 사용할 때는 앱을 종료한 뒤 보관한 v3.3.5 폴더를 되돌리거나 v3.3.5에서 만든 ZIP을 복원합니다. v3.2.2를 사용하는 동안 새로 생긴 기록이 필요하면 그 데이터 폴더도 따로 보관하세요.

## Fixed

- 룬·클럽 경험치가 잡은 몬스터 수에 포함되거나 같은 보상 채팅이 여러 번 표시되던 문제를 수정했습니다. 에타 성장 지원 이벤트의 경험의 정수 추가 보상도 감지합니다.
- 어벤던로드 HUD는 한국 시각 월요일 오전 6시에 초기화됩니다. 구형 HUD 주간 집계는 최초 복원 때 한 번 비우며 과거 모험일지는 보존합니다.
- 숙제 체크리스트가 사이드바와 독에서 한 번에 열리도록 수정했습니다. 사이드바를 펼쳐도 겹친 도구 창이 앞에 남습니다.
- 지난 주기의 숙제 동기화 충돌이 다시 나타나는 문제와 한 PC의 손상된 파일이 다른 PC의 정상 변경까지 막는 문제를 수정했습니다.
- 도움말의 **공지 열기**에서 현재 빌드의 버전과 공지 내용을 표시하고 닫기 버튼이 동작하도록 수정했습니다.
- 다른 플레이어의 채팅에 `Date : …` 같은 날짜 문구가 있으면 그 뒤 모험일지 기록의 날짜가 바뀌던 문제를 수정했습니다.
- 디스크가 가득 차는 등 저장에 실패해도 채팅 표시와 기믹 알림은 계속 동작합니다.
