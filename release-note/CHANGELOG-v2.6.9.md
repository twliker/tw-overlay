# 📦 TW-Overlay Release Note - v2.6.9 (2026-08-23)

이번 **v2.6.9 업데이트**는 테일즈위버 종합 데이터베이스 사이트인 **TW DB (TWPage)** 퀵슬롯 바로가기 추가 및 기존 사용자 1회 자동 마이그레이션이 적용된 업데이트입니다.

---

## 🛠️ 주요 변경 사항

### 1. 테일즈 종합 데이터베이스 'TW DB' 퀵슬롯 추가
- **TW DB 사이트 바로가기 추가:** 에타 순위/계산기, 장비 DB 및 비교, 아바타/어빌리티 DB, 대미지 계산기, 시뮬레이터 등을 제공하는 종합 정보 웹 사이트 [TW DB](https://twhome-git.github.io/TWPage/)를 퀵슬롯 기본 목록에 등록했습니다.
- **사이드바 및 독바(Dock) 연동:** 사이드바 하단 퀵슬롯 및 하단 독바에서 `database` 아이콘의 `TW DB` 버튼을 클릭하여 웹 브라우저로 바로 이동할 수 있습니다.

### 2. 기존 사용자 퀵슬롯 자동 마이그레이션
- **1회성 안전 마이그레이션:** 기존 사용자가 앱을 업데이트하면 퀵슬롯 목록 끝에 `TW DB` 항목이 자동으로 1회 추가됩니다.
- **사용자 설정 보존:** `quickSlotsMigratedV2` 플래그를 통해 이후 사용자가 환경 설정에서 해당 슬롯을 직접 삭제하거나 순서를 바꾸더라도 앱 재실행 시 다시 생겨나지 않고 유저 설정이 온전히 보존됩니다.

### 3. 미니게임 메뉴 레이블 정비
- **명칭 통일:** 사이드바 미니게임 메뉴의 표기를 '테일즈위버 무기 강화하기'로 명확하게 개선했습니다.

---

## 📥 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-2.6.9.exe`를 다운로드합니다.
2. 다운로드한 설치 프로그램을 실행하면 기존 설정과 데이터를 안전하게 유지하며 자동으로 업데이트됩니다.
