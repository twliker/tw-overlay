# 📦 TW-Overlay Release Note - v3.1.6 (2026-10-05)

이번 **v3.1.6 업데이트**는 숙제 체크리스트에 상위 컨텐츠 5종을 추가하고, 어벤던로드 HUD에 누 조우 및 마정석 소실 표시를 개선하였으며, 장비 기댓값 계산기의 인크립트 회차별 단계 기댓값을 정밀하게 분석할 수 있도록 보강한 업데이트입니다.

---

## Added

- **숙제 체크리스트 상위 컨텐츠 5종 통합**:
  - 추종하는 환희(일반/어려움), 응시하는 슬픔(일반/어려움), 최후의 결전, 골고다 협곡 방어전, 공허의 영역 숙제 항목이 추가 및 개선되었습니다.
  - 추종하는 환희 및 응시하는 슬픔: 난이도 공유 규칙에 맞춰 단일 숙제로 통합하고, 보상 상자 획득 채팅 로그 감지를 통한 자동 체크를 지원합니다.
  - 최후의 결전: 티로로스 퇴치 시스템 메시지 감지(주간 10회)를 통한 자동 체크를 지원합니다.
  - 골고다 협곡 방어전: 1시간 완주 시 자동 체크(반자동 안내 툴팁 제공)를 지원합니다.
  - 캐릭터별 진행 상태 및 일일/주간 리셋 주기가 안정적으로 보존됩니다.
- **어벤던로드 HUD 누(Nu) 조우 횟수 및 마정석 소실 표시**:
  - 누 조우 시 소실된 마정석 등급/수량 및 누적 차감액을 실시간으로 표시합니다.
  - 총 수익에서 차감된 손실액을 정확하게 반영하여 실질 순수익 집계를 제공합니다.
- **장비 기댓값 계산기 인크립트 현재·목표 횟수 및 비아누 단계별 기댓값 상세 분석**:
  - 대상 장비의 현재 인크립트 횟수(0~19회)와 목표 인크립트 횟수(현재+1~20회)를 직접 입력하여 구간별 기댓값을 산출할 수 있습니다.
  - 넥슨 공식 확률 규격에 따른 비아누의 회차별 성공률 감소(0회 0.070% → 12회 이상 0.010%)를 완벽하게 반영했습니다.
  - 각 단계별 성공률 및 평균 필요 시도 횟수를 한눈에 파악할 수 있는 단계별 상세 분석(Breakdown) 카드를 제공합니다.

## Changed

- **장비 기댓값 계산기 인크립트 옵션 UI 개선**:
  - 인크립트 옵션 설정을 수수료 행과 통일된 5분할 그리드로 정돈했습니다.
  - 현재 횟수와 목표 횟수 간 상호 유효성 자동 보정(목표 > 현재 유지)을 지원합니다.
  - 비아누 선택 시 현재 회차 성공률 배지 및 노패널티 안내 문구를 동적으로 제공합니다.

## 설치 및 업데이트 방법

1. [Releases](https://github.com/twliker/tw-overlay/releases) 페이지에서 `twOverlay-Setup-3.1.6.exe`를 다운로드합니다.
2. Microsoft Store 설치본은 Store 라이브러리에서 업데이트할 수 있습니다.
3. 업데이트 전에 환경 설정의 **데이터 관리 → ZIP 백업**으로 설정과 기록을 보관할 수 있습니다.
