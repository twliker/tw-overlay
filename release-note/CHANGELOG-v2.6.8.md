# 📦 TW-Overlay Release Note - [Mandatory Update] v2.6.8 (2026-08-23)

이번 **v2.6.8 업데이트**는 게임 창 활성화 시 오버레이가 게임 뒤로 가려지던 Z-Order 은폐 버그 해결, 재실행 시 도핑 HUD 위치 보존, 창모드 전체화면 및 독모드 작업표시줄 간섭 완벽 해소가 적용된 **필수 업데이트**입니다.

---

## 🛠️ 주요 변경 사항

### 1. Z-Order 승격 및 오버레이 은폐 방지
- **게임 화면 클릭 시 오버레이 은폐 버그 해결:** 게임 창이 활성화(Foreground)되었을 때 Z-Order 승격 로직이 누락되어 `game-overlay`가 게임 뒤로 숨던 현상을 수정하여, 게임 창 바로 위에 안정적으로 노출되도록 개선했습니다.
- **기믹 알림(에토스 화살표 등) 시각 효과 복구:** 보스 기믹 알림(에토스 방향 화살표 등)이 게임 뒤에 가려져 보이지 않던 문제를 해결했습니다.
- **샌드위치 Z-Order 보호:** 크롬 브라우저, 디스코드 등 외부 일반 프로그램으로 전환 시 오버레이가 외부 앱 화면 위로 튀어나오지 않고 뒤로 자연스럽게 가려지는 동작을 온전히 유지했습니다.

### 2. 도핑/경험치 HUD 위치 저장 안정성 강화
- **재실행 시 위치 초기화 방지:** 앱 기동 및 게임 재실행 시 초기 뷰포트 미형성 상태(0×0 과도기)에서 화면 이탈로 오판하여 위치를 중앙 좌표로 덮어쓰던 버그를 차단했습니다. 이제 사용자가 옮겨둔 도핑/경험치/어벤던로드 HUD 위치가 영구히 안전하게 보존됩니다.

### 3. 창모드 전체화면 및 독모드 작업표시줄 간섭 제거
- **Z-Order 멱등성 보장 (No-Op):** 오버레이들이 이미 올바른 순서로 정렬되어 있을 때 불필요하게 `SetWindowPos`를 반복 호출하지 않도록 하여, 창모드 전체화면 플레이 중 Windows 작업표시줄이 불쑥 튀어나오던 현상을 원천 차단했습니다.
- **독모드 작업표시줄 노출 차단:** 독바(`dock`) 창에 `skipTaskbar: true`를 적용하여 `Ctrl + Shift + D`로 독바를 열고 닫을 때 작업표시줄에 탭이 생기거나 튀어나오지 않도록 개선했습니다.
- **포커스 복원 시 Alt 키 간섭 억제:** 게임 포커스 복원 시 Windows 시작 메뉴 및 작업표시줄을 자극하던 Alt 키(`VK_MENU`) 이벤트를 일반적인 상황에서 발생시키지 않도록 개선했습니다.

### 4. 스크립트 스코프 오류 수정
- **경험치 세션 단축키 오류 수정:** `Ctrl + Shift + Z`로 경험치 세션을 토글할 때 발생하던 `refreshXpStats is not defined` 스코프 참조 에러를 수정했습니다.
