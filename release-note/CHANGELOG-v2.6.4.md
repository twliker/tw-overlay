# 📦 TW-Overlay Release Note - [Mandatory Update] v2.6.4 (2026-08-18)

이번 v2.6.4 버전은 게임 오버레이 경고 알림 6종의 개별 ON/OFF 환경설정 지원, 채팅 로그 특수 공백/HTML 엔티티 디코딩 개선, 오버레이 표시 시 게임 포커스 보호 및 안정화가 적용된 기능 개선 및 편의성 업데이트입니다.

---

## 🚀 주요 변경 사항

### 🔔 게임 오버레이 경고 알림 6종 개별 ON/OFF 설정 추가 (Added)
- **알림별 자유로운 제어 지원**:
  - 환경설정(Settings)의 [HUD 및 실시간 오버레이] 메뉴에 오버레이 경고 알림 6종을 각각 켜거나 끌 수 있는 토글 체크박스를 추가했습니다.
  - **제어 가능 항목**:
    1. **몬스터 웨이브 종료 대기 알림**: 잔존 몬스터 발생 시 "몬스터 처치 대기!" 경고창
    2. **경험의 정수 버프 확인 경고**: 100억 달성 시 자동 교환 버프 꺼짐 확인 경고창
    3. **공허 특별 몬스터 출현 알림**: 공허의 영역 필드에 특별 몬스터 젠 감지 시 알림 카드
    4. **어벤던로드 10회 완료 알림**: 최고 효율 구간(지역 10회) 도달 시 화면 플래시 및 보석 알림 카드
    5. **팔색조 언덕 5회 완료 알림**: 팔색조 언덕 SS 5회 획득 시 알림 카드
    6. **도전과제 완료 알림**: 대장간/골고다/공허 목표 처치 달성 시 완료 축하 카드 및 효과음
- **이중 차단 안전 설계**:
  - 메인 프로세스(이벤트 발송단)와 오버레이 렌더러(수신단) 양쪽에서 설정을 체크하여 불필요한 연산 및 리소스를 완벽히 차단합니다.

### 💬 채팅 로그 특수 공백(`&nbsp;`, `\u00a0`) 및 HTML 엔티티 정규화 (Fixed)
- **채팅 파싱 정확도 향상**:
  - 테일즈위버 채팅 로그 내에 포함되는 `&nbsp;`, `&#160;`, `&#xa0;`, `\u00a0`(NBSP) 등 비표준 공백 및 엔티티를 표준 공백으로 정규화 처리했습니다.
  - 이로 인해 특정 상황에서 웨이브 종료 대기 알림이나 특별 몬스터 출현 문구가 정상 감지되지 않던 문제를 완벽히 해결했습니다.

### 🎯 게임 플레이 포커스 유실 방지 (Changed)
- **비활성 표시(`showInactive`) 적용**:
  - 오버레이 창 동기화 및 표시 시 게임 클라이언트에서 윈도우 조작 포커스(키보드/마우스)를 빼앗지 않도록 개선하여, 사냥 및 보스전 조작이 끊기지 않는 쾌적한 환경을 보장합니다.

### 🚪 웰컴 가이드 팝업 조건 최적화 (Changed)
- **불필요한 재노출 방지**:
  - 이미 가이드를 확인했거나 초기 설정을 완료한 사용자가 앱을 재실행할 때 웰컴 가이드 팝업이 다시 뜨지 않도록 조건을 개선했습니다.

### 🦜 팔색조 언덕 이벤트 처리 일원화 (Refactored)
- **로직 통합 및 등급 정규화**:
  - 분산되어 있던 팔색조 언덕 이벤트 리스너를 정리하고, 대소문자 및 공백 정규화(`SS`/`SSS`)를 적용하여 알림 및 숙제 카운팅의 신뢰도를 높였습니다.
