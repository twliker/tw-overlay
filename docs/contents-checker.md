## 언제 쓰는 기능인가요?

여러 캐릭터의 일일·주간 콘텐츠 완료 횟수를 한곳에서 관리하고, 지원 콘텐츠의 완료 로그를 자동 반영할 때 사용합니다.

## 어디에서 켜나요?

사이드바·독 메뉴의 **숙제 체크리스트**를 엽니다. 설정에서 게임 시작 시 자동 열기를 선택할 수도 있습니다.

## 플레이 프로필 연동

플레이 프로필 기능은 앱 시작 시 준비됩니다. 상단에 현재 숙제 프로필 이름·서버를 표시하고, 프로필 관리는 사이드바·독의 시스템 메뉴에서 엽니다. 각 프로필의 숙제 목록·완료 횟수·N/A는 따로 관리합니다. 편집 중 전환에는 **저장 후 전환 / 저장하지 않고 전환 / 취소**를 제공하며, 저장 실패 때는 입력과 기존 완료 상태를 보존합니다. 저장 결과를 확인하지 못한 경우 **다시 확인**을 누르면 중복 반영 없이 원래 요청을 확인합니다. 새로 입력한 초안은 지우지 않습니다. Google 연동은 [동기화 안내](./google-drive-sync.md)를 따릅니다.

새 프로필에는 기본 숙제 목록이 들어 있습니다. `3.5.0-beta.5`부터 이전 베타에서 누락된 기본 항목은 앱 시작 시 자동으로 보충합니다. 기존 완료 횟수·N/A·숨김·수정한 이름·분류·순서와 커스텀 숙제는 그대로 보존하며 명시적으로 삭제한 항목은 되살리지 않습니다.

프로필 생성에서 **설정 가져오기**를 선택하면 환경설정·계산기 입력뿐 아니라 기본/커스텀 숙제의 이름·분류·표시·순서·자동 감지·초기화 규칙·최대 횟수와 N/A도 가져옵니다. 완료 횟수·완료 시각과 모험일지는 복사하지 않습니다. 원본에서 삭제한 기본 항목은 새 프로필에서도 제외하며, 원본 프로필은 변경하지 않습니다.

프로필 선택/관리 창은 열릴 때 게임창 중앙에 표시합니다. 화면 밖으로 나갈 때에는 게임이 있는 모니터의 작업 영역 안으로 조정합니다. 게임이 최소화된 상태에서는 자동 선택창을 보류하고 복귀 시 표시합니다. 직접 연 관리 창의 입력은 유지하며, 게임이 없을 때는 기존 모니터 중앙에 표시합니다.

선택 창은 작은 프로필 카드에서 이름·서버·일일/주간 현황과 **사용/수정**을 함께 보여줍니다. 기본 크기는 640×520이며 편집 폼은 **추가/수정**을 누를 때만 펼쳐집니다. 처음 설치했거나 이름·서버가 없으면 설정 폼이 바로 열립니다. 편집 닫기에도 미저장 내용을 확인하며, 작은 창에서도 세로 스크롤로 모든 동작에 접근할 수 있습니다.

**미배정 플레이 기록**에는 단순 건수 대신 `어벤던로드 입장료 1건`, `경험치 변동 3건`처럼 종류와 대표 내용을 표시합니다. 기록이 여러 개면 최근 내용 3개까지 펼쳐 볼 수 있습니다. 새 기록의 수는 감지 이벤트 수이며, 구버전의 숙제 대기는 여러 수량을 합쳐 보관한 **묶음 수**와 **보류 수량**으로 구분합니다. 최종 모험일지에 추가될 행 수와는 다를 수 있습니다. 숙제 정보가 누락된 이전 자료는 완료 횟수로 해석하지 않고 정보 누락을 안내하며 **무시하기**로 대기 목록에서 정리할 수 있게 합니다. 정상적인 이전 세션의 기록은 사용할 프로필을 선택한 뒤 명시적으로 배정합니다. 지난 HUD·알림은 다시 재생하지 않습니다.

프로필 목록에서 각 프로필의 **일일·주간 완료 숙제 수, 퍼센트와 진행률 바**를 확인할 수 있습니다. 일일은 파란색, 주간은 보라색입니다. 숨김·N/A 항목은 전체 수에서 제외하며 대상이 없으면 **대상 없음**으로 표시합니다. 여러 번 수행하는 숙제는 최대 횟수를 모두 채웠을 때 완료한 숙제 1개로 집계합니다. 비활성 프로필도 초기화 시각이 지난 완료 기록은 현재 주기 기준으로 표시합니다. 현황을 보는 것만으로 프로필을 바꾸거나 저장된 기록을 수정하지 않습니다.

다른 프로필을 사용하는 동안 초기화 시각이 지났다면 해당 프로필을 선택할 때 지난 주기의 횟수를 바로 초기화합니다. 숙제창을 열기 전에도 새 자동 감지는 새 주기부터 반영되며, N/A 설정과 과거 완료 일지는 유지합니다.

게임 종료 리마인더를 설정했다면 종료 후 **프로필별 탭**에서 남은 숙제를 확인할 수 있습니다. 탭에는 프로필 이름과 남은 숙제 수가 표시되고 마지막 사용 프로필이 먼저 열립니다. 남은 숙제가 없는 프로필도 탭을 유지하며, 숨김·N/A·완료한 항목은 목록에서 제외합니다. 사용하지 않은 프로필도 현재 초기화 주기로 표시합니다. 탭을 바꿔 보는 것만으로 실제 사용 프로필이나 저장된 숙제 기록은 바뀌지 않습니다. 프로필이 많으면 탭을 가로로 스크롤하거나 좌우 방향키·Home·End로 이동할 수 있습니다.

## 기본 사용법

배정하지 않을 과거 기록은 **무시하기 → 내용 확인 → 무시하기**로 대기 목록에서 정리할 수 있습니다. 프로필 선택 전에도 가능하며 숙제나 모험일지에는 반영하지 않습니다. 정보가 누락된 이전 자료에도 이 동작을 제공합니다. 취소하거나 저장에 실패하면 목록에 남고, 확인 중 새 기록이 들어오면 다시 확인하도록 안내합니다. 현재 플레이 중 쌓이는 기록은 무시 대상에서 제외합니다.

1. 시스템 메뉴의 프로필 관리에서 프로필 이름과 서버를 설정하고 사용할 프로필을 선택합니다.
2. 숙제 카드를 좌클릭하면 횟수가 늘고, 우클릭하면 줄어듭니다.
3. 체크박스로 즉시 완료 또는 완료 해제를 할 수 있습니다.
4. 하지 않는 숙제는 N/A로 바꿔 완료율 계산에서 제외합니다.
5. 관리 모드에서 숙제 추가·수정·숨김, 최대 횟수와 순서를 바꿉니다.
6. 여러 캐릭터를 한 번에 보려면 바둑판 보기를 사용합니다.

지원 콘텐츠의 완료 채팅이 감지되면 자동으로 횟수가 올라갑니다. 적용할 캐릭터가 여러 명이면 선택 팝업이 뜹니다. 캐릭터 관리의 **남은 캐릭터가 한 명이면 자동 체크**를 끄면, 미완료 후보가 한 명뿐이어도 직접 캐릭터를 선택합니다. 차감권처럼 앱이 사용 여부를 알 수 없는 아이템을 쓴다면 이 옵션을 끄는 것을 권장합니다.

**설계자의 채굴장**은 `숨겨진 구역으로 이동할 수 있는 포탈이 맵 중앙에 생성되었습니다.` 시스템 안내가 나오면 일일 숙제 1회로 감지합니다. 입장 직후나 조각 획득마다 완료 처리하지 않으며, 숨겨진 구역의 마지막 보상까지 기다릴 필요도 없습니다. 채굴장·발굴지의 하급 조합 조각 획득은 숙제 횟수에 영향을 주지 않습니다. 과거 로그 재분석도 같은 기준을 사용합니다. 이전 버전에서 잘못 완료된 캐릭터 상태는 체크리스트에서 직접 해제할 수 있습니다.

과거 로그 동기화에서 복원한 숙제는 예외입니다. 저장된 채팅 로그만으로는 실제 수행 캐릭터를 판별할 수 없으므로 현재 일일·주간 주기에 해당하는 완료 횟수를 모두 **메인 캐릭터**에 반영합니다. 지난주·지지난주처럼 이미 끝난 주기의 완료 기록도 실제 수행 날짜의 모험일지에 메인 캐릭터 숙제로 복원합니다. 이 동작은 현재 선택한 캐릭터나 캐릭터 목록 순서에 따라 바뀌지 않습니다.

개발 중인 플레이 프로필 모드에서는 복원을 시작할 때 선택한 프로필에 현재 주기 횟수와 지난 주기 일지를 반영합니다. 이미 다른 프로필/미배정으로 복원한 원본 구간을 다시 복사하지 않습니다. 복원 중 숙제 편집·프로필 전환/삭제는 잠시 기다려야 하며 새 자동 감지는 보관 후 반영합니다. 앱 시작 시 프로필을 준비한 뒤 사용합니다.

## 자주 혼동하는 점

숙제창의 가시성 설정(관리 모드)에서 **조작하지 않을 때 자동 접기**를 켤 수 있습니다. 기본은 꺼짐입니다. 창 밖으로 마우스를 옮기고 15초 동안 조작하지 않으면 제목줄만 남으며, 제목에 마우스를 올리거나 펼치기 버튼을 누르면 기존 목록으로 돌아옵니다. 접힌 창의 버튼 위에서는 클릭할 버튼을 유지하므로 펼치기를 눌러도 관리 모드가 열리지 않으며, 닫기는 그대로 창을 닫습니다. 저장한 옵션은 창을 다시 열어도 유지되고 다른 창에서 변경한 설정도 반영합니다. 캐릭터 선택·관리·입력·설정 저장 중에는 접지 않습니다. 접힌 동안 새 캐릭터 선택이 필요해지면 다시 펼칩니다. 검색 내용과 목록 스크롤은 유지하며 프리셋과 창 크기에는 펼친 높이를 저장합니다.

오늘의 요약에는 최근 자동 감지된 숙제를 `설계자의 채굴장 1/1`처럼 제목과 횟수/총횟수 한 줄로 표시합니다. 접힌 요약에서도 보이며, 감지된 숙제가 없으면 줄을 숨깁니다. 캐릭터 선택 전에는 보류 횟수를, 반영 후에는 해당 캐릭터에 적용된 횟수를 보여줍니다. 새 감지로 교체되고 날짜나 숙제 초기화 시각이 지나면 사라집니다. 수동 체크와 과거 로그 복원은 이 줄을 새 감지로 갱신하지 않으며, 앱을 다시 켜면 새 감지부터 표시합니다.

- 일일 숙제는 매일, 주간 숙제는 정해진 주간 초기화 시각에 새 주기로 바뀝니다.
- 검색 중에는 드래그 정렬을 사용할 수 없습니다.
- 최대 횟수를 줄이면 기존 횟수도 새 최대값을 넘지 않게 조정됩니다.
- 최대 횟수를 늘려 현재 횟수가 부족해지면 완료가 해제되고, 줄인 최대값에 도달하면 완료로 바뀝니다. N/A 항목은 완료 처리하지 않습니다.
- 초기화 요일·시각과 최대 횟수를 함께 바꾸면 새 초기화 규칙을 먼저 적용합니다. 지난 주기의 진행도는 0회로 초기화하고, 현재 주기에 유효한 횟수만 최대값에 맞춥니다. 주기 초기화로 과거 완료 일지를 지우거나 오늘 완료 기록을 만들지 않습니다.
- 숙제 숨김·추가·삭제와 캐릭터 추가는 오늘 모험 일지의 완료 수·전체 수에도 즉시 반영됩니다.
- 이전 날짜에 완료한 주간 숙제를 해제하거나 N/A로 바꾸면 원래 완료 날짜의 일지 기록도 취소됩니다.
- 완료된 숙제에서 `+`를 다시 누르거나 같은 횟수의 보류 내역을 적용해도 완료 날짜는 바뀌지 않습니다. 이후 완료를 해제하면 처음 완료한 날짜의 일지 기록이 취소됩니다.
- 단일 후보 자동 체크 옵션은 기존 사용자 동작을 보존하기 위해 기본으로 켜져 있습니다.
- Google 동기화를 연결하면 캐릭터, 숙제 정의, 완료 상태와 캐릭터 선택 대기도 다른 PC와 합쳐집니다.

## 문제 해결

- **자동 완료가 반영되지 않음:** 게임 채팅 로그 저장과 앱의 채팅 로그 경로를 확인하세요.
- **캐릭터 선택 팝업이 반복됨:** 해당 숙제를 이미 완료·제외한 캐릭터와 미완료 후보가 맞는지 확인하세요.
- **원하지 않는 숙제가 보임:** 관리 모드에서 숨기거나 삭제하세요. 기본 숙제는 삭제 대신 숨김만 가능한 항목이 있습니다.
- **다른 PC와 값이 다름:** 체크리스트의 동기화 상태 아이콘을 확인하고 설정의 데이터 관리에서 오류 내용을 확인하세요.

커스텀 숙제 추가 중에는 버튼에 **추가 중…**이 표시됩니다. 목록 반영이 확인되면 버튼 아래에 체크 표시와 초록색 배경의 추가 완료 안내가 숙제 이름과 함께 표시됩니다. 결과 확인이 지연되면 재시도 전에 목록을 확인하세요.

커스텀 숙제 추가가 확인되면 목록 안에서 해당 숙제로 이동하고 잠깐 강조합니다. 검색어는 유지하며 검색에 맞지 않는 숙제는 추가 완료 안내에 표시합니다. 다음 숙제 이름을 입력했거나 다른 항목을 편집 중이면 자동 이동하지 않습니다. 해당 그룹만 펼치며 움직임 줄이기 설정도 따릅니다.
