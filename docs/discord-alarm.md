# 디스코드 알림

## 언제 쓰는 기능인가요?

게임 채팅에서 지정한 단어가 발견됐을 때 디스코드로 알림을 받고 싶을 때 사용합니다. 자리를 비운 동안 거래 문의나 클럽 대화를 확인하는 용도에 적합합니다.

## 어디에서 켜나요?

사이드바 또는 독 메뉴에서 **디스코드 알림**을 엽니다.

## 기본 사용법

1. 알림을 받을 디스코드 채널에서 Webhook URL을 만든 뒤 입력합니다.
2. **테스트**를 눌러 메시지가 도착하는지 확인합니다.
3. 감지할 채팅 종류를 고르고, 필요하면 보낸 사람을 지정합니다.
4. 감지 단어를 입력해 규칙을 추가합니다.
5. **디스코드 알림 사용**을 켭니다.

## 자주 혼동하는 점

- 보낸 사람을 비워 두면 선택한 채팅 종류의 모든 닉네임을 대상으로 검사합니다.
- Webhook URL은 비밀번호처럼 다뤄야 합니다. 다른 사람에게 노출되면 디스코드에서 기존 Webhook을 삭제하고 새로 만드세요.
- Webhook URL은 현재 PC에만 저장되며 Google Drive로 동기화되지 않습니다.
- 앱이 읽을 수 있는 게임 채팅 로그가 기록돼야 알림이 동작합니다.

## 문제 해결

- **테스트 메시지가 오지 않음:** URL 앞뒤의 공백을 지우고 디스코드에서 해당 Webhook이 삭제되지 않았는지 확인하세요.
- **원하는 채팅이 감지되지 않음:** 채팅 종류, 보낸 사람, 감지 단어를 다시 확인하세요.
- **알림이 너무 많이 옴:** 보낸 사람을 지정하거나 감지 단어를 더 구체적으로 등록하세요.
