# 마정석 계산기

![마정석과 금화 주머니의 가치를 계산하는 도구](../screenshot/magic-stone-calculator.png)

## 언제 쓰는 기능인가요?

보유한 마정석과 금화 주머니를 SEED 가치로 환산하거나, 어벤던로드 플레이 중 누적한 마정석을 일지에 기록할 때 사용합니다.

## 어디에서 켜나요?

사이드바 또는 독 메뉴의 **마정석 계산기**를 엽니다.

## 기본 사용법

1. 금화 주머니와 등급별 마정석 수량을 입력합니다.
2. 계산된 총 금화 주머니와 SEED 환산액을 확인합니다.
3. 어벤던로드 추적값이 있다면 **세션 값 가져오기**로 입력할 수 있습니다.
4. 확정한 수익만 **모험 일지에 기록**으로 저장합니다.

## 자주 혼동하는 점

- 금화 주머니 1개는 50만 SEED로 계산합니다.
- 마정석 보유 자체를 자동 수익으로 기록하지 않습니다. 나중에 교환할 수 있으므로 사용자가 계산 결과를 확인한 뒤 일지에 기록합니다.
- 어벤던로드 HUD의 표시·숨김과 통계 집계는 별개입니다. HUD를 직접 숨겨도 현재 게임 세션 동안 계속 숨겨진 채 수치는 집계됩니다.
- HUD를 다시 열면 숨겨진 동안의 누적값을 바로 확인할 수 있으며, 게임을 완전히 종료한 뒤 새로 실행하면 수동 숨김 상태는 해제됩니다.

## 문제 해결

- **세션 값이 비어 있음:** 어벤던로드 채팅 로그가 감지됐는지 확인하세요.
- **계산값이 다름:** 직접 보유한 금화 주머니와 교환 전 마정석을 중복 입력하지 않았는지 확인하세요.
- **일지에 중복 기록함:** 모험 일지에서 해당 수동 기록을 확인해 삭제하세요.
