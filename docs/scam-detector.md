# 사기꾼 탐지 (1:1 대화)

## 언제 쓰는 기능인가요?

테일즈위버 1:1 메신저 대화에서 사칭, 추가 입금 유도 같은 의심 패턴을 로컬 AI로 점검하고 싶을 때 사용합니다.

## 어디에서 켜나요?

사이드바 또는 독 메뉴의 **사기꾼 탐지(1:1 대화)**를 엽니다. 게임의 1:1 대화창에서도 **Log**를 미리 켜야 합니다.

## 기본 사용법

1. 게임 1:1 대화창의 **Log** 버튼을 켭니다.
2. 앱에서 메신저 로그 폴더가 맞는지 확인합니다.
3. 기능을 켜고 필요한 로컬 AI 모델·실행 파일을 내려받습니다.
4. 감지된 대화 세션을 선택해 분석 결과를 확인합니다.

## 자주 혼동하는 점

- 외치기가 아니라 1:1 메신저 로그만 분석합니다.
- AI 판정은 참고 정보이며 거래 안전을 보장하지 않습니다. 금전 거래 전에는 상대방과 조건을 직접 재확인하세요.
- 분석은 사용자 PC에서 실행되지만 최초 모델 설치에는 인터넷과 여유 저장 공간이 필요합니다.
- 메신저 로그 경로와 경고 사운드의 로컬 파일 경로는 Google Drive로 동기화되지 않습니다.

## 문제 해결

- **대화가 나타나지 않음:** 대화를 시작하기 전에 게임 대화창의 Log를 켰는지 확인하세요.
- **AI 서버가 시작되지 않음:** 다운로드 상태, 저장 공간, 보안 프로그램 차단과 선택한 GPU 방식을 확인하세요.
- **분석이 오래 걸림:** CPU 분석은 PC 사양에 따라 오래 걸릴 수 있습니다. 지원되는 GPU 방식을 선택하거나 기능을 잠시 끄세요.
