# 플레이 보조 도구

설정 카드와 편집창은 공통 입력·버튼 스타일을 사용합니다. 게임 안내는 보스 빨강, 경험치 파랑, 개인 메모 회색으로 구분합니다. 보급품 기믹은 실제 발판 색상과 이름을 표시합니다.

## 플레이 프로필

활동 프리셋 기능은 제거했습니다. 프로필은 시스템 메뉴에서 관리하며, 기존에 적용해 두었던 환경설정과 창 배치는 유지합니다. 이전 프리셋을 자동 적용하지 않습니다.

## 알림 위치 통합 설정

환경 설정 → 게임 오버레이에서 게임 진행 알림, 버프 만료, 입장·사냥 안내, 독 알림의 위치를 각각 선택합니다. 기존 위치 또는 화면의 9개 구역을 사용할 수 있으며 화면 크기에 맞춰 여백을 확보합니다. 화면 전체를 감싸는 위험 테두리는 계속 전체 화면을 사용합니다.

게임 진행 알림이 겹치면 행동이 필요한 기믹, 시간 안내, 완료·획득 안내 순으로 표시합니다. 다른 위치의 알림은 함께 보이며, 가려진 안내도 원래 시간이 지나면 끝나므로 뒤늦게 몰아 띄우지 않습니다. 기존 감지·기록·게임 알림 소리는 유지합니다. 같은 원인·회차의 사이드바/독 토스트가 떠 있는 동안 반복되면 한 카드에 횟수만 더합니다. 등록 득템의 Windows 알림은 0.75초 안의 같은 아이템을 수량으로 묶고 일지에는 각 획득을 그대로 기록합니다.

배치 예시와 ‘게임 화면에서 미리보기’로 저장 전에 확인할 수 있습니다. 실제 미리보기는 게임 화면이 보일 때 5초간 샘플만 띄우며 기록이나 소리를 발생시키지 않습니다. 종료 시 최신 저장 위치로 돌아갑니다.

## 보급품 탈환

환경 설정 → 게임 플레이 → 게임 진행 알림에서 **보급품 발판 안내**를 켜거나 끕니다. 경보 장치 네 개를 해제하라는 입장 안내 이후 알려진 암호를 감지하면, 게임 화면에 **순서대로 밟으세요**와 **파랑 → 노랑 → 빨강**처럼 색상 순서를 10초간 표시합니다. 실제 게임에서 잘라낸 발판 이미지와 색상 이름을 함께 보여 줍니다.

입장 직후나 암호 대기 중에는 아무것도 표시하지 않습니다. 새 암호가 나오면 순서와 표시 시간을 갱신하고, 성공·실패하면 즉시 숨깁니다. 과거 로그 복원으로 안내를 재생하지 않으며 입장 상태는 최대 30분간 유지합니다. 지도와 별도 HUD는 없으며, 위치는 에토스·로카고스 등과 같은 **게임 진행 알림** 위치 설정을 따릅니다.

## 화면 고정 메모

환경 설정 → 게임 오버레이에서 내용을 적고 **메모 저장**을 누릅니다. 메모는 게임 화면 위에 표시되며 기존 **HUD 위치 설정**으로 옮깁니다. 편집 취소는 이전 위치를 복원하고 위치 초기화는 기본 위치로 되돌립니다. 빈 메모는 표시하지 않습니다. 로컬 설정과 ZIP 백업에 내용을 보관합니다.

기존 카드에서 글자 크기(12~28px), 글자 색, 배경 표시를 고르고 예시를 확인합니다. 기본은 14px·흰색·배경 표시입니다. 배경을 끄면 평상시에는 제목 없이 글만 표시하고, 위치 편집에서는 제목을 다시 보여 줍니다. 메모의 읽기 설정과 내용은 해당 프로필에 보관합니다.

설정의 긴 화면 예시는 내부에서 스크롤할 수 있습니다. 메모를 다시 편집하면 이전 저장 완료 안내가 사라지므로, 바꾼 내용을 반영하려면 다시 **메모 저장**을 누릅니다.

긴 메모는 화면의 일부 높이 안에서 표시하고 **내용이 더 있습니다** 안내를 붙입니다. **HUD 위치 설정**을 켠 뒤 메모 본문에서 휠이나 스크롤바를 사용하면 마지막 줄까지 읽을 수 있습니다. 위치 이동은 제목을 끌어서 합니다. 위치 설정을 종료하면 다시 게임 입력을 투과합니다. 화면이 작아지면 메모를 화면 안에 맞춰 표시하며, 이 보정만으로 저장된 위치가 바뀌지는 않습니다.

## HUD 위치 설정

HUD를 선택하면 작은 도구 영역에 대상 이름이 표시됩니다. **모서리 맞춤**은 화면 경계나 다른 HUD의 가장자리 가까이 끌어온 대상을 안내선에 맞추며, 끄면 자유롭게 배치합니다. 옆에 붙일 때는 작은 간격을 두고, 고정 메모는 평상시와 같은 화면 여백을 유지합니다.

**저장**은 디스크 저장에 성공한 뒤 편집을 끝내고 입력 투과를 복원합니다. 저장을 기다리는 동안 중복 조작을 잠시 막고, 실패하면 위치와 편집 상태를 유지해 다시 저장할 수 있습니다. **취소**나 설정 창 닫기는 편집 시작 위치로 돌아갑니다. 저장 중 창을 닫아 취소된 이전 요청이 나중에 도착해도 새 편집의 위치를 저장하지 않습니다.

## 모험일지 수익

기존 날짜·월별 총 수익을 사용합니다. 금화 주머니는 1개당 500,000 SEED로 한 번 환산합니다. 개발 중 추가했던 보물창고 전용 캐릭터·회차 표와 별도 집계는 제거했습니다. 기존 수익 기록과 보물창고 숙제 감지는 유지하며, 이미 저장된 전용 집계 테이블을 삭제하지 않습니다.
