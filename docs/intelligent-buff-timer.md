# 지능형 버프 타이머

![감지할 버프와 알림 시점을 정하는 버프 타이머 설정](../screenshot/buff-timer-settings.png)

## 언제 쓰는 기능인가요?

채팅 로그로 감지한 버프의 남은 시간을 게임 위에서 확인하고 만료 전에 알림을 받을 때 사용합니다.

## 어디에서 켜나요?

사이드바·독 메뉴의 **버프 타이머**를 열고, 설정에서 감지할 버프와 HUD·소리·중앙 알림을 선택합니다.

## 기본 사용법

1. 사용할 버프와 만료 몇 초 전에 알릴지 정합니다.
2. HUD, 소리, 화면 중앙 알림 중 원하는 방식을 켭니다.
3. 게임에서 버프 사용 메시지가 기록되면 타이머가 자동으로 시작됩니다.
4. 같은 버프가 다시 감지되면 더 최근 사용 시각을 기준으로 갱신됩니다.
5. 불필요한 활성 버프는 HUD의 해당 아이콘을 눌러 숨길 수 있습니다.

## 자주 혼동하는 점

- 앱이 버프 아이콘이나 캐릭터 상태를 직접 읽는 것이 아니라 채팅 로그 문구를 기준으로 시작합니다.
- 앱이 꺼져 있던 동안에도 저장된 시작 시각으로 남은 시간을 계산합니다.
- 절전 중 지난 경고는 복귀 후 소리를 몰아서 재생하지 않고 놓친 알림 이력으로 남깁니다.
- 커스텀 사운드 파일 경로는 Google Drive로 동기화되지 않습니다.

## 문제 해결

- **타이머가 시작되지 않음:** 해당 버프가 설정에서 켜져 있는지, 채팅 로그에 사용 문구가 기록됐는지 확인하세요.
- **남은 시간이 다름:** 같은 버프의 재사용 문구가 정상 기록됐는지 확인하세요.
- **알림이 안 남:** 알림 방식, 경고 시각, 음량과 Windows 음소거를 확인하세요.
