# 테시스 코어 계산기

![목표 단계까지 필요한 재료를 계산하는 테시스 코어 계산기](../screenshot/thesis-core-calculator.png)

## 언제 쓰는 기능인가요?

테시스 코어 조각을 현재 단계에서 목표 단계까지 강화할 때 필요한 가루, 재화와 비용의 기댓값을 미리 확인할 때 사용합니다.

## 어디에서 켜나요?

사이드바 또는 독 메뉴의 **테시스 코어 계산기**를 엽니다.

## 기본 사용법

1. **머큐리얼/어비스** 또는 **이클립스/루비코나** 지역을 선택합니다.
2. 주스탯·부스탯, 시드·엘소, 조각 수량을 선택합니다.
3. 현재 단계와 목표 단계를 지정합니다.
4. 이벤트 할인이 적용 중이면 할인율을 입력하거나 **이벤트 할인(20%)**을 누릅니다.
5. 화면의 가루 소모량과 비용 기댓값을 확인합니다.

## 자주 혼동하는 점

- 결과는 확률에 따른 평균값이므로 실제 강화 결과와 다를 수 있습니다.
- **1조각**과 **6조각 전체**는 계산 수량이 다릅니다.
- 할인율은 강화 비용에 적용되며, 이벤트가 끝났다면 **초기화**로 0%로 돌려놓으세요.
- 마지막 입력값은 이 PC에 저장됩니다.

## 문제 해결

- **결과가 예상과 크게 다름:** 지역, 스탯 종류, 화폐와 조각 수량을 먼저 확인하세요.
- **단계를 선택할 수 없음:** 목표 단계는 시작 단계보다 앞설 수 없습니다.
- **이벤트가 아닌데 비용이 낮음:** 저장된 할인율을 0%로 초기화하세요.
