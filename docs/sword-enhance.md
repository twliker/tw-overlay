# 검 강화하기

## 언제 쓰는 기능인가요?

테일즈위버 무기 강화 과정을 간단한 미니게임으로 체험하고 싶을 때 사용하는 연동 도구입니다.

## 어디에서 켜나요?

사이드바 또는 독 메뉴의 **검 강화하기**를 엽니다.

## 기본 사용법

1. 창이 열리면 내부에 표시되는 검 강화하기 게임을 기다립니다.
2. 게임 화면의 안내에 따라 강화 재료와 행동을 선택합니다.
3. 사용을 마치면 창 오른쪽 위의 닫기 버튼을 누릅니다.

## 자주 혼동하는 점

- 이 화면은 TW-Overlay 제작자가 소유한 게임 데이터나 실제 캐릭터 장비를 변경하지 않습니다.
- 외부 웹 도구를 앱 안에 표시하므로 인터넷 연결이 필요합니다.
- 실제 테일즈위버의 강화 결과나 비용을 보장하는 계산기가 아닙니다.

## 문제 해결

- **빈 화면이 계속 보임:** 인터넷 연결을 확인한 뒤 창을 닫았다가 다시 여세요.
- **화면 일부가 잘림:** 창 크기를 늘려 보세요.
- **계속 열리지 않음:** 외부 사이트 접속이 방화벽이나 보안 프로그램에서 차단됐는지 확인하세요.
