# 프로필 선택 간소화와 미배정 기록 요약 (2026-11-04)

사용자 요청에 따라 기본 창을 820×680에서 640×520으로 줄이고 최소 크기를 560×400으로 조정했다. 헤더/카드/설명/진행률 간격을 줄이고 빈 상태 footer를 숨겼다. 프로필 이름·서버·상태·사용/수정을 한 줄에 모으고 일일/주간 수치·퍼센트·진행률 바를 유지한다.

선택 시 편집 폼은 숨기고 추가/수정 또는 필수 이름·서버 설정 때만 펼친다. 편집 닫기는 미저장 입력을 확인한다. 작은 창은 세로 스크롤로 폼/설정 가져오기/배정 버튼까지 접근하며 넓은 창에서는 편집과 목록을 나란히 표시한다. 사용자가 저장한 크기는 보존하고 열기 시 게임 중앙 배치는 유지한다.

## 미배정 기록 표시 계약

후속 신고에서 구형 자료에 ID/적용 방식이 누락된 경우가 확인됐다. 아래 최초 구현의 단순 수량 표시는 이 경우에 충분하지 않았다. 현재 구형 묶음/수량 구분과 배정 보호는 [후속 진단과 수정](./profile-legacy-pending-diagnosis-2026-11-04.md)을 우선 따른다.

- `1건`은 파서가 감지한 이벤트 하나다. 같은 이벤트를 여러 기능에서 소비해도 한 건이며, 최종 일지 행 수와 동일하다고 표시하지 않는다.
- `profilePendingPreview`가 종류별 수와 최근 원문 3개를 요약한다. 예: **어벤던로드 입장료 1건 / 입장료 50,000 Seed를 지불하였습니다.** 원문이 없으면 금액/횟수 등 표시 가능한 정보로 안내한다.
- 지난 숙제 형식은 이름/횟수로, 알 수 없거나 손상된 내용은 기타 기록으로 보존한다. 전체 payload를 렌더러로 보내지 않고 원문은 각 180자까지 표시한다. 사용자 문구는 textContent로 표시한다.
- 조회는 SQL 집계와 세션별 LIMIT 3을 사용하며 DB/원본/배정/ACK/이력을 수정하지 않는다. 로컬 프로필 getter에만 파생 값을 추가하고 일반 상태 알림/자동 기록/Google 저장 형식은 변경하지 않는다.
- 현재 플레이 세션은 선택 때 반영하므로 과거 세션 배정 목록에서 제외한다. 기존 명시적 배정과 실패 재시도는 유지하고 확인 창에도 종류와 대표 내용을 보여준다. 지난 HUD/알림은 재생하지 않는다.
- 기존 현황 조회 예약을 공유한다. 상태의 개수/최초·마지막 시각과 일치하는 요약만 표시하고 늦은 응답을 버린다. 요약 실패는 별도로 안내하며 프로필 선택/초안을 유지한다. 내용이 같으면 DOM/포커스·펼쳐보기를 다시 만들지 않는다.

- `npm run typecheck`, `npm run build`: 통과.
- `npm run test:profiles-ui`: 실제 SQLite/제품 HTML/preload/IPC에서 간결한 기본 화면, 편집 펼침/미저장 닫기 보호, 생성/복사/선택/삭제/배정 흐름과 기존 현황을 확인했다. 종류 합계/금액 부호/이전 숙제/기타·손상/원문 제한/원본 무변경/안전한 텍스트/다중 감지/조회 실패·복구·개수 변경/로컬 페이지 제한/복구 중 보류를 포함한다. 640×520·560×400·800×600에서 동작 접근을 확인했다.
- `electron dist-tools/check-refactor-regressions.js`: 기본/최소/저장 크기·작은 작업 영역과 기존 공통 계약 통과.

실제 화면 `output/profiles-ui/compact-selection-640.png`, `pending-summary-640.png`를 직접 검토했다. 로그와 소스 fingerprint는 `output/profile-compact/latest.json`에 보관한다. 검사에는 소유한 임시 폴더/게임 대역만 사용했다. 실제 Roaming 데이터나 사용자 게임은 검사 입력으로 사용하지 않았다.
