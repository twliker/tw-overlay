# 게임 종료 안내의 프로필별 남은 숙제 (2026-11-04)

게임 종료 리마인더에 프로필별 탭과 남은 숙제 수를 추가했다. 처음에는 마지막 사용 프로필을 표시하며 완료한 프로필도 탭을 유지한다. 같은 이름의 프로필은 ID로 구분하고 서버를 함께 안내한다. 조회용 탭은 실제 사용 프로필을 선택하거나 기록 대상을 바꾸지 않는다.

## 데이터와 화면 계약

- `gameExitReminderContents.collectProfileIncompleteContents`가 살아 있는 프로필 전체를 읽는다. 기존 선택 프로필의 설정 projection 하나로 모든 프로필을 판단하지 않는다.
- 프로필 현황과 `readCurrentProfileHomework`를 공유한다. 기존 체크리스트 초기화 규칙을 메모리에서 적용하며 비활성 프로필의 만료도 현재 주기로 표시한다. 숨김/N/A/완료한 항목은 제외하고 부분 수행한 반복 숙제는 남긴다.
- 프로필 이름/숙제 이름/분류는 DOM `textContent`로 표시한다. 일일 파란색/주간 보라색, 12px 이상 설명/14px 숙제 이름과 기존 공통 토큰을 사용한다.
- 긴 이름은 탭에서 생략하되 전체 이름·서버·남은 수를 툴팁과 접근성 이름으로 제공한다. 많은 탭은 가로 스크롤, 방향키/Home/End와 선택 탭 자동 노출을 지원한다. 프로필별 목록 스크롤 위치를 유지한다.
- 기존 500×560 창, 리마인더 활성화/비어 있지 않은 메시지 조건, 메시지/확인 버튼/Esc 닫기를 유지한다. 긴 메시지와 숙제 목록은 각각 스크롤해 확인 버튼을 가리지 않는다.
- 저장소 복구 중/닫힘/조회 실패는 확인 불가 안내를 표시한다. 이를 전체 완료로 표시하거나 현재 프로필 목록만 대신 보여주지 않는다. 런타임이 없는 구형 경로 및 이전 배열 IPC도 표시할 수 있다.
- 조회는 선택·세션·원본 숙제·일지·변경/동기화 이력을 수정하지 않는다. DB 스키마나 Google 전송 형식은 변경하지 않는다. 이번 범위는 종료 시점의 조회 화면이며 열린 안내 창을 주기 갱신하지 않는다.

검사에는 소유한 임시 사용자 폴더와 일반 권한 게임 대역만 사용한다. 실제 사용자 Roaming 폴더를 열거나 변경하지 않는다. 실패 경로 검사의 의도한 잘못된 JSON은 오류 로그를 남기지만 제품 DOM 오류는 없다. 검사 완료 전 앱 종료는 실패로 처리하고 검사 전체에도 시간 제한을 둔다.

로그/현재 소스 fingerprint는 `output/game-exit-reminder/latest.json`, 실제 화면은 `output/game-exit-reminder/profile-tabs.png`에 보관한다. 해당 크기의 창 캡처를 직접 검토했다. 통합 기록은 `output/profile-review/latest.json`의 종료 안내 후속 항목에서 연결한다.

이번 후속은 관련 검사만 실행했다. 전체 `npm test`, 전체 Windows 12개 조합, 관리자 Z-order·실계정 Google·물리 PC 2대·설치/업데이트 실기를 새로 통과했다고 표시하지 않는다. 기존 전체/관리자 결과는 당시 소스의 별도 기록이다. 버전/원격 브랜치/태그는 변경하지 않으며 사용자 승인 없이 푸시하지 않는다.
