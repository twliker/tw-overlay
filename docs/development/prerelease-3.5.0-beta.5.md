# v3.5.0-beta.5 기본 숙제 복구 최종 검증

[beta.4 수정](./prerelease-3.5.0-beta.4.md)의 기본 목록 연결·자동 복구 구현을 그대로 포함한다. beta.4 CI에서 발견한 과거 로그 복원 검사 오류를 수정했다. `profile_homework`의 첫 행에 의존하지 않고 `weekly-eternal-floor` ID와 프로필 ID를 지정해 메모리·DB의 rollback 및 성공 후 횟수를 확인한다. 실패 직전 전체 숙제 행의 snapshot도 비교해 다른 기본 항목과 다른 프로필이 바뀌지 않았는지 검증한다. 검사를 생략하거나 실패를 허용하지 않는다.

로컬 `test:profile-log-restore`와 직접 부팅 소비자인 `test:profile-stopwatch`는 통과했다. 기존 beta.4 관련 검사 결과와 구분하며 제품 코드가 동일해 이미 통과한 검사를 반복하지 않는다. 최종 beta.5 타입·빌드·버전/채널을 확인한 후 새 태그를 푸시한다. 설치 파일은 Actions가 생성한다. beta.4 태그와 실패 기록은 유지한다.

실제 사용자 데이터 초기화는 수행하지 않았다. 실제 Google 계정·물리 PC 2대·실게임·관리자 권한·실제 설치 업데이트는 아직 확인하지 않았으며 자동 검사로 대체하지 않는다.

## CI 중단 및 후속 검수

[beta.5 CI](https://github.com/twliker/tw-overlay/actions/runs/41797487931)는 기본 숙제·과거 로그 복원 등 앞선 검사를 통과한 후 `profile-checklist`의 고정 450ms 대기에서 실패했다. 실제 기본 목록을 처리하는 전환 중 첫 재시도가 실패해 다음 1초 예약을 기다려야 하는데 검사가 먼저 읽었다. 실패 기록을 보존하며 설치 파일은 생성되지 않았다. 고정 대기를 실제 원래 프로필의 기록 확정 조건으로 바꾸고, 이후 사용자 요청에 따른 프로필 설정 가져오기/최소화 시작과 주변 경로 전체 검수는 [통합 검수 기록](./profile-integration-review-2026-11-04.md)에 남긴다. 사용자의 새 지시에 따라 이후 수정은 푸시 전 승인을 받는다.
