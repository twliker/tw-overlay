# 프로필·Google 동기화 통합 검수 (2026-11-04)

기본 숙제 누락에 이어 사용자가 실제 설정 가져오기와 최소화된 게임 시작 동작을 지적하고, 지정한 항목에 한정하지 않는 잠재 버그/사이드 이펙트 검수를 요청했다. 모든 수정은 로컬에서 수행하며 이후 푸시는 명시적 승인을 받는다. beta.4/beta.5 실패 태그를 성공이나 설치 완료로 표시하지 않는다.

사용자 관리자 검사 결과를 받은 뒤 추가로 요청한 선택창 중앙 배치와 그 이후 소스의 관련 검수는 [프로필 창 중앙 배치](./profile-window-placement-2026-11-04.md)에 별도로 기록한다. 아래 전체 검사/관리자 결과는 중앙 배치 추가 전 기준이며 이후 코드에 소급하지 않는다.

## 발견과 수정

선택 창의 여백/상시 편집 폼과 미배정 기록의 모호한 건수는 [간결한 선택·대기 기록 요약](./profile-compact-selection-2026-11-04.md)에서 후속 개선했다. 이 단계도 관련 검사만 실행하며 아래 과거 전체/관리자 결과와 구분한다.

이후 요청한 [프로필별 현황·진행률 바](./profile-homework-progress-2026-11-04.md)와 [종료 안내의 프로필 탭](./profile-exit-reminder-2026-11-04.md)은 각각 별도 관련 검사로 검증했다. 이 후속 코드의 검증 범위를 아래의 과거 전체/관리자 검사와 구분한다.

## 검수 범위

- 실제 배포 리소스 → 부팅 → 프로필 생성/설정 가져오기 → 숙제 화면, 원본·신규 프로필 간 격리.
- 선택 전 기록 대기, 전환/삭제/과거 복원/백업 중 소유권·늦은 응답·실패 rollback, 계산기/스톱워치 귀속.
- 기본 항목 누락 복구와 명시 삭제, Google 수신/동시 변경/연결 해제/복원된 기기 ID 경계.
- 기존 수익/지출·실시간/과거 로그·창 가시성·UI 경계 및 전체 자동 검사.

실제 사용자 Roaming 데이터를 검사 입력으로 사용하거나 초기화하지 않는다. 실제 Google 계정 왕복·물리 PC 2대·실게임 보호 모듈/권한 조합·새 설치 파일 실행은 이 검수에서 수행했다고 표시하지 않는다. 사용자 관리자 권한 Z-order는 아래 별도 결과를 따른다. 자동 검사나 코드 검토가 잠재 버그의 완전한 부재를 보장하지 않는다.

Z-order: 일반 권한 시도는 기본 fixture 시작 시간 초과와 명시한 일반 권한 fixture의 foreground 확보 시간 초과로 실패했다. 이 시도를 제품 창 순서의 합격 결과로 해석하지 않는다. 로그: `test-zorder-development.log`, `test-zorder-development-final.log`. 이후 2026-11-04 사용자가 관리자 권한으로 직접 실행한 결과를 제공했다. `passed=true`, `elevated=true`이며 windowed/borderless 모두 게임/외부 창 전경 보존·외부 창 우선·오버레이 순서 복구·앱 활성화 시 게임 올림이 true다. 원문 JSON과 사용자 제공 출처는 `output/profile-review/zorder-admin-user.json`에 저장했다. 관리자 결과 수령 시점에 전체 자동 검수 당시 소스 fingerprint와 같은 것도 확인했다. 이후 중앙 배치 추가는 위 별도 기록을 따른다. 실게임 보호 모듈/권한 조합 검증을 대신하지 않는다.
