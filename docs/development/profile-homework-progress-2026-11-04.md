# 프로필별 일일/주간 숙제 현황 (2026-11-04)

프로필 목록의 각 카드에 일일/주간 완료 수·퍼센트·진행률 바를 표시한다. 일일은 기존 XP 파란 토큰, 주간은 숙제 보라 토큰을 사용한다. 일반 글자 12px 이상, 완료 수 14px와 기존 카드/테두리/모서리 규격을 유지한다.

## 집계와 저장 계약

- 기존 체크리스트와 같은 **완료한 항목 수 / 참여 대상 항목 수**다. 숨김/N/A는 제외하고, 반복 숙제는 최대 횟수를 모두 채워야 완료한 항목 1개다.
- 대상이 없으면 `대상 없음`과 `—`를 표시하고 진행률 바는 비운다. 0개를 100% 완료로 표시하지 않는다.
- 기존 만료 정규화/통계 함수를 재사용한다. 비활성 프로필의 지난 완료도 현재 주기에 맞춰 표시하되 정규화는 메모리에서만 수행한다.
- 로컬 프로필 화면의 getter에서 살아 있는 숙제를 한 번에 읽어 snapshot을 반환한다. 일반 service.status/파서 호출에 전체 집계를 붙이지 않는다. 선택·원본 숙제·모험일지·변경/전송 이력은 읽기로 수정하지 않는다. DB 스키마/Google 저장 구조 변경은 없다.

## 갱신과 실패 처리

처음 열 때, 프로필 상태/설정 변경, 창 복귀, 다음 초기화 시각과 표시 중 주기 확인 때 갱신한다. 연속 알림은 모으고 조회는 최대 초당 한 번으로 제한하며 동시에 중복 실행하지 않는다. 대기 중 새 변경은 이어서 확인하고 늦은 현황으로 새 목록/선택/초안을 교체하지 않는다. 숫자/진행률 영역만 갱신해 사용 버튼 DOM과 포커스를 유지한다.

현황 조회 실패는 카드에 `확인 불가`로 표시하고 프로필 관리·선택은 유지한다. 백업/복구로 DB가 닫혀 있으면 현황을 보류하고 저장소가 준비되면 다시 확인한다. 일반 시간 변경에 갱신 제한이 길어지지 않도록 제한 간격은 단조 시간으로 계산한다.

- 타입 검사·최종 빌드 통과.
- `test:profile-homework-progress`: 실제 SQLite/배포 목록에서 프로필별 집계·일요일 06시 전후/월요일 주간 유지·숨김/N/A/부분 횟수/대상 없음/비활성 만료/삭제 제외를 확인. 읽기 전후 모든 테이블 snapshot이 같은지 검증했다.
- `test:profiles-ui`: 실제 HTML/preload/IPC/DB의 서로 다른 프로필 수치와 bar value/퍼센트 일치, 모두 N/A, 동시 조회 중 변경, 초안/버튼 DOM·선택/세션 유지, 조회 실패와 복구, 저장소 연결 중단/재연결, 외부 페이지에 현황을 전달하지 않음을 확인했다. 기존 생성/설정 가져오기·재시도·삭제 검사도 유지했다.
- 직접 영향의 `test:profile-checklist` 및 실제 앱/게임의 `game-first/sidebar/windowed` 시작·중앙 배치·선택/기록·재시작 검사 통과.
- 800×600 화면과 가로 넘침을 확인했으며 `output/profiles-ui/homework-progress-800.png`를 직접 검토했다.

로그와 소스 fingerprint는 `output/profile-progress`에 보관한다. 이전 전체 검사/관리자 Z-order와 [중앙 배치 관련 검사](./profile-window-placement-2026-11-04.md)는 각 시점의 기록으로 유지한다. 이번 추가 뒤 전체 묶음이나 관리자 Z-order는 반복 실행하지 않았으며, 실계정 Google/실제 PC 2대/설치 실기도 완료한 것으로 표시하지 않는다. 현재 수정은 로컬이며 사용자 승인 전에는 푸시하지 않는다.
