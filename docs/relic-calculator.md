# 렐릭 강화 시뮬레이션

## 언제 쓰는 기능인가요?

현재 렐릭 능력치에서 목표 단계 MAX까지 필요한 강화 횟수, 재료와 SEED를 예상할 때 사용합니다.

## 어디에서 켜나요?

사이드바 또는 독 메뉴의 **렐릭 강화**를 엽니다.

## 기본 사용법

1. 펜던트 또는 브라이슬릿을 선택합니다.
2. 현재 단계와 목표 단계를 고릅니다.
3. 각 능력치의 현재 값을 입력합니다.
4. 실제로 도전할 성소 난이도를 선택합니다.
5. **기댓값 조회**에서 평균 소모량을 보거나 **시뮬레이션**에서 한 번의 무작위 결과를 실행합니다.

## 자주 혼동하는 점

- 기댓값은 많은 시도를 평균낸 값이고, 시뮬레이션은 한 번의 무작위 결과입니다.
- 단계 진화는 100% 성공하는 것으로 계산하며 단계별 MAX 능력치를 이어받습니다.
- 어빌리티와 부가 옵션은 계산하지 않습니다.
- 선택한 난이도에서 성공 확률이 0%인 단계가 포함되면 결과를 계산할 수 없습니다.

## 문제 해결

- **계산할 수 없다는 안내가 나옴:** 성소 난이도를 높이거나 목표 단계를 낮춰 보세요.
- **남은 강화 횟수가 이상함:** 펜던트와 브라이슬릿의 능력치 개수가 다르므로 종류와 현재 값을 확인하세요.
- **실행할 때마다 값이 달라짐:** 시뮬레이션은 확률을 직접 한 번 실행하므로 정상입니다. 평균은 기댓값 조회를 사용하세요.
