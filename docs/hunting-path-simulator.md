# 사냥터 동선 시뮬레이션

![지도 위에 반복 사냥 동선을 그리는 시뮬레이터](./screenshot/hunting-path-simulator.png)

## 언제 쓰는 기능인가요?

사냥터 지도 위에 이동 경로를 그려 반복 사냥 동선을 계획하거나 게임 위에 반투명하게 띄워 보고 싶을 때 사용합니다.

## 어디에서 켜나요?

사이드바 또는 독 메뉴의 **사냥터 동선 시뮬레이션**을 엽니다.

## 기본 사용법

1. 위쪽 탭에서 사냥터를 선택합니다.
2. 빈 지도에서 `Ctrl + 클릭`하여 경로 점을 차례로 추가합니다.
3. 선 색상, 진행 방향 표시와 시작·끝 연결 여부를 선택합니다.
4. 필요하면 **오버레이 모드**로 전환해 게임 위에서 경로를 확인합니다.
5. 경로는 사냥터별로 현재 PC에 자동 저장됩니다.

## 자주 혼동하는 점

- 기존 선을 `Ctrl + 클릭`하면 경로 중간에 점이 들어갑니다.
- 점을 우클릭하면 삭제되고, 선을 우클릭하면 해당 구간의 색상을 바꿀 수 있습니다.
- 오버레이 모드에서는 게임 조작을 방해하지 않도록 기본적으로 마우스가 통과합니다.
- 경로 데이터는 로컬 DB에 저장되며 Google Drive 설정·숙제 동기화 대상이 아닙니다.

## 문제 해결

- **점을 추가할 수 없음:** `Ctrl` 키를 누른 채 지도나 경로 선을 클릭하세요.
- **오버레이를 움직이고 싶음:** 오버레이 상단의 이동 영역을 드래그하세요.
- **처음부터 다시 그리고 싶음:** 현재 사냥터에서 **동선 초기화**를 누르세요.
