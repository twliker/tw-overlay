# 집중 대화방

게임 채팅창에 여러 사람의 메시지가 섞여도 놓치고 싶지 않은 사용자들의 대화만 별도 창으로 모아보는 기능입니다.

## 사용 방법

1. 사이드바 또는 독의 `실시간 모니터링` 메뉴에서 `집중 대화방`을 엽니다.
2. `내 닉네임`에 사용하는 캐릭터 닉네임을 입력하고 저장합니다.
3. 대화 상대 입력창에서 감지된 닉네임을 선택하거나 원하는 닉네임을 직접 입력하고 `추가`를 누릅니다.
4. 여러 명을 등록하면 한 대화방에서 등록된 사용자들의 메시지를 함께 확인할 수 있습니다.
5. 등록된 닉네임의 `×` 버튼을 누르면 해당 사용자를 필터에서 제거합니다.
6. 제목줄의 화살표 버튼으로 닉네임 설정 영역을 접거나 펼칠 수 있습니다.

## 표시 기준

- 닉네임은 앞뒤 공백과 영문 대소문자를 제외하고 정확히 일치할 때 표시됩니다.
- 등록 사용자의 일반, 팀, 클럽, 귓속말 채팅을 왼쪽 말풍선으로 표시합니다.
- 내 닉네임과 일치하는 일반, 팀, 클럽, 귓속말은 오른쪽 노란 말풍선으로 표시합니다.
- 시스템 메시지와 외치기는 대화 흐름을 방해하지 않도록 제외합니다.
- 이 창은 읽기 전용입니다. 메시지 입력과 전송은 게임 채팅창에서 진행합니다.
- 카카오톡 형태의 각 메시지는 말풍선 위에 `닉네임 · 채널 · 에타`, 그 아래에 `내용 · 시간`을 간결하게 표시합니다.
- 오른쪽 아래 손잡이를 드래그하면 창 크기를 조절할 수 있으며 조절한 크기는 앱 설정에 유지됩니다.

내 닉네임만 앱 설정에 저장됩니다. 대화 상대와 자동완성 후보는 메모리에만 있으며 집중 대화방을 닫으면 즉시 삭제됩니다. 다시 열면 현재 세션의 최근 채팅 기록에서 자동완성 후보를 새로 구성합니다. 채팅 내용은 기존 채팅 오버레이와 같은 현재 세션의 최근 기록을 사용합니다.
