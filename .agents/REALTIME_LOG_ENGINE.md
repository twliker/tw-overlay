# 실시간 채팅 로그 처리와 과거 로그 복원

TW-Overlay는 테일즈위버 채팅 로그 파일에 새로 추가된 줄만 추적해 알림과 일지 기능에 전달합니다.

## 처리 흐름

1. 설정된 채팅 로그 폴더와 현재 날짜 로그 파일을 확인합니다.
2. 마지막으로 처리한 위치 이후의 새 로그만 읽습니다.
3. 인코딩과 로그 형식을 검증한 뒤 채팅, 경험치, 득템, 숙제 및 버프 이벤트로 분류합니다.
4. 이벤트를 오버레이, 알림, 숙제 체크리스트와 모험 일지에 전달합니다.

`chatLogManager.ts`는 감시와 읽기 위치를 관리하고 `chatParser.ts`는 이벤트를 생성합니다. `chatLogProcessor.ts`는 채팅을 표시하고 `ProfileService`는 자동 기록의 세션과 프로필을 확정합니다. 선택 전에도 채팅을 계속 표시하며 자동 기록의 원본은 선택할 때까지 보관합니다. 이전 세션 수동 배정에서는 과거 경험치·버프·현황판과 소리를 재생하지 않습니다.

앱이 종료되어 있던 기간의 로그는 과거 로그 동기화 기능으로 다시 분석할 수 있습니다. 기본 동기화는 아직 완료되지 않았거나 이후 내용이 추가된 파일만 이어서 처리합니다.

**일지 보관 → 영구 보관**을 선택하면 날짜 제한 없이 현재 채팅 로그 폴더에 남아 있는 과거 원본을 복원할 수 있습니다.

**이미 동기화한 로그도 다시 분석**을 체크하면 보관 기간 안의 완료 파일을 처음부터 읽습니다. 프로필 저장소는 누락된 개별 득템·SEED를 원본과 대응해 복구하며 수동 일지와 원본 소유권을 보존합니다. 오늘 로그는 동기화 시작 시점까지의 완전한 줄을 먼저 처리하고, 그동안 새로 들어온 줄부터 실시간 감시로 이어갑니다. 파일이 교체되거나 안전하게 이어받을 수 없으면 기존 기록을 보존합니다.

이전 단일 저장 방식의 복원은 메인 캐릭터를 대상으로 합니다. 해당 호환 경로는 공개 가이드에서 설명하는 현재 프로필 모드와 별도로 `check-refactor-regressions.ts`에서 검사합니다.

현재 앱에서는 복원 시작 시 선택한 프로필에 숙제와 일지를 반영합니다. 시작 전 대상 이름과 서버를 표시합니다. 이미 복원한 구간과 기존 미배정 기록은 원래 귀속을 유지하며, 이후 추가된 구간은 새로 선택한 프로필로 복원할 수 있습니다. 외치기 기록은 공통입니다.

복원 중에는 프로필 전환·삭제와 해당 설정·숙제 편집을 잠급니다. 그동안 새로 감지한 자동 기록은 보관했다가 완료 후 원래 플레이 세션에 반영합니다. 저장 실패 시 기존 기록과 재시도에 필요한 정보를 보존합니다.

사용 흐름은 [환경설정 가이드](../docs/settings.md#과거-채팅-로그-복원)를 따릅니다.

어벤던로드 입장료 지불 로그도 과거 분석 시 음수 SEED로 복원합니다. 이미 처리한 파일까지 확실히 재구성하려면 **이미 동기화 완료된 로그도 다시 분석하여 자동 기록 재구성**을 선택합니다. 보관된 원본 로그가 없는 지출은 복원할 수 없습니다.


오늘 로그의 복원 범위에는 마지막 행에 개행이 없어도 `</br>`로 완전히 닫힌 줄이 포함됩니다. 작성 중인 행과 범위를 확정한 뒤 닫힌 줄은 실시간 이어받기로 처리합니다. 회귀 검사는 `test:profile-log-restore`와 `test:profile-lifecycle`에서 확인합니다.

파일 날짜 헤더는 `parseChatLogDateHeader`만 판정한다. 시각 태그 `[ HH시 mm분 ss초 ]`가 없고 줄 전체가 `Date : YYYY-MM-DD` 또는 `Date : YYYY년 M월 D일`인 줄만 헤더이며, 채팅 본문의 "Date :"는 파서 날짜를 바꾸지 않는다(회귀: `test:profile-recording`).

실시간 감시 북마크 저장 실패는 읽기를 멈추지 않는다(`saveWatchBookmark`). DB에는 마지막으로 저장에 성공한 위치가 남고 다음 읽기에서 다시 저장하며, 재시작하면 그 위치부터 at-least-once로 다시 읽는다(회귀: `test:profile-lifecycle`). 남은 한계: `prepareProfileLogSource` 쓰기가 실패하면 새 파일 감시를 시작하지 못하고 재연결 경로로 간다.
