# 플레이 보조 기능 재기획 진행표

2026-09-21 사용자 지시를 기준으로 관리한다. 기존 미푸시 기능의 재기획과 비교 프로젝트에서 발견한 후보 전체가 대상이며, 아래 일부 구현을 전체 완료로 보고하지 않는다.

## 개발 기준

1. 기존 톤앤매너·화면·용어·조작 방식을 따른다.
2. 일반 사용자가 직관적으로 사용할 수 있는 단순한 기능을 제공한다.
3. 기존 기능과 연결해 중복 화면·입력·집계를 줄인다.
4. 게임플레이에 도움을 주고 화면 점유·입력 방해를 줄인다.
5. 판단 근거가 부족한 사항은 사용자에게 확인한다.

사용자는 **전체 구현 후 실게임 테스트**를 진행한다. 단계마다 사용자 실기 확인을 요구하지 않는다. 개발 중 타입 검사·자동 회귀·Electron 재현은 계속하고 실게임·DPI·설치 검증과 구분한다. 어울리지 않는 기능은 억지로 넣지 않고 이유와 대안을 모아 나중에 의견을 확인한다. 미푸시 작업은 한 커밋으로 유지하며 푸시·릴리즈는 별도 범위다.

## 현재 구현과 남은 작업

| 항목 | 상태 | 실제 범위 |
|---|---|---|
| 숙제 감지·요약·캐릭터 선택 안내 | 1차 완료 | 포탈 문구 감지, 제목·횟수 한 줄, 선택 안내 정리 |
| 닉네임 정보·메모 | 1차 완료 | 기존 창에 캐릭터·에타·기준일, 선택적 메모 간단 표시 |
| 수익 표시 | 결정 반영 완료 | 보물창고 전용 표 제거. 기존 금화 주머니 환산·총수익 유지 |
| 프리셋 | 1차 완료 | 적용과 상세/관리 구분, 변경 범위 표시 |
| HUD 편집 | 3차 구현·개발 검사 완료 | 화면/HUD 간 정렬·안내선·저장 확인·취소·긴 메모 스크롤 |
| 전체 창 숨기기·복원 | 2차 구현·개발 검사 완료 | 기존 트레이·선택 단축키, renderer/입력 보존, 게임 상태별 복원 |
| 숙제창 자동 접기 | 2차 구현·개발 검사 완료 | 기본 꺼짐, 15초 무조작, 선택/입력 보호, 임시 높이와 저장 크기 분리 |
| 메모 읽기 설정·사용자 글꼴 | 3차 구현·개발 검사 완료 | 메모 크기·색·배경, 기존 채팅 글꼴 선택/예시에 로컬 파일 연결, 없으면 기본 글꼴 사용 |
| 알림 우선순위·반복 묶기 | 3차 구현·개발 검사 완료 | 겹치는 게임 알림 기믹 우선, 같은 토스트 횟수·짧은 연속 득템 수량 묶기. 원본 기록 유지 |
| 창끼리 정렬 | 3차 구현·개발 검사 완료 | HUD 편집 중 안내선 정렬. 독립 창은 선택 옵션으로 놓는 순간 맞춤·최종 위치 저장. 실게임/DPI 미검증 |
| 채팅 시각·배지 등 세부 표시 | 4차 구현·개발 검사 완료 | 기본 표시 유지. 간단 표시에서 시간·에타를 접고 채널·주의·메모 유지, 기존 미리보기·저장·이력 보존 경로 통합 |
| 기간별 기록 내보내기·선택 설정 공유 | 4차 구현·개발 검사 완료 | 사용자 승인 범위: 일지의 기간별 숙제·득템·수익 HTML, 배치·외관·알림 선택 JSON 공유와 변경 비교. 채팅 원문·개인 메모·계정 연동 제외 |

2차 구현의 자동 검사·Electron 결과는 로컬 `output/companion-replan-2026-09-20/phase2-implementation.md`에 기록한다. 이 진행표는 실행하지 않은 실게임 검증을 완료로 표시하지 않는다.

3차 구현과 검증 범위는 `output/companion-replan-2026-09-20/phase3-implementation.md`에 기록한다. 위 후속 세 묶음과 아래 의견 확인/후속 설계 후보는 다른 범위다. 전체 후보를 모두 제품에 추가한 것으로 보고하지 않는다.

## 나중에 의견을 확인할 후보

| 후보 | 어울리지 않을 수 있는 이유 | 우선 검토할 대안 |
|---|---|---|
| 모든 창을 다루는 통합 편집 패널 | 도구별 지원 설정이 달라 복잡한 관리 화면이 될 수 있음 | 기존 창별 설정 유지, HUD와 정렬 조작부터 확장 |
| 지인/거래 주의 분류·태그 일괄 관리 | 일반 사용자의 관리 부담, 현재 개인 메모와 중복 | 개인 메모로 부족한 상황이 확인된 분류만 제공 |
| 등급별 사운드·아이콘 득템 팝업 | 기존 등록 아이템 알림과 중복, 화면 점유·소음 증가 | 기존 알림에서 반복 획득을 묶어 먼저 개선 |
| 1:1 상대 정보 자동 팝업 | 기존 대화 조회·닉네임 정보창과 중복, 포커스 방해 가능 | 기존 정보창의 수동 접근 활용 |

설정 공유·기록 내보내기 범위는 2026-09-21 사용자 승인으로 위 구현 범위에 반영했다. 채팅 원문 내보내기는 이번 범위에서 제외했다. 보류 후보와 별개로 남아 있던 두 항목이며, 최종 검사 근거는 `output/companion-replan-2026-09-20/phase4-implementation.md`에 기록한다.

## 이미 보류·제외한 항목

- 보물창고 전용 캐릭터/회차/주간 표: 사용자 결정으로 제외. 총수익이 목적이다.
- 주간 보상 상한·예상액: 필요와 게임 규칙을 확인하기 전 보류.
- 외치기 전체 자동 팝업·닉네임 자동 복사: 기존 전용 채팅·클릭 복사를 우선하며 보류.
- 보급품 지도: 기존 발판 순서 안내 유지, 지도는 사용 필요와 자료 근거 확인 전 보류.
- 번들 글꼴 확대: 사용자 글꼴 활용을 먼저 검토하며 보류.
- 게임 프로세스 우선순위 상승: 제거 상태 유지.

비교 결과는 구현 지시 전체와 같지 않다. 보류·의견 확인 항목을 미구현 결함이나 구현 완료로 바꾸어 보고하지 않는다.
