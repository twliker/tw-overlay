# v3.0.0 전 기능 전수조사 기록

조사일: 2026-08-27  
대상 브랜치: `beta/v2.7.0`  
자동 검증 기준 커밋: `ceffbef`

## 판정 기준

- `자동 통과`: 격리 fixture, Electron 렌더러 또는 정적 계약 검사가 통과했다.
- `구조 확인`: 호출·저장·IPC·종료 경계를 코드로 역추적했지만 외부 환경까지 재현하지 않았다.
- `실기 대기`: 실제 게임, 두 PC, 관리자 권한, Store 서명본 또는 외부 서비스가 필요하다.
- 자동 검증이 있어도 화면의 가독성·클릭감·실제 게임 포커스는 실기 검증을 대체하지 않는다.

## 성능 역검토 결과

- 변경 없는 Google Drive 자동 pull은 공유 meta만 확인하고, 이전에 검증한 file ID·version·MD5·수정 시각·크기와 원격 revision이 모두 같으면 설정·숙제 media 다운로드 및 동일 로컬 atomic write를 생략한다. 수동 불러오기와 fingerprint 변경 시에는 기존 전체 검증 경로를 유지한다(`f7b06e5`).
- 일반 채팅 한 줄마다 전체 AppConfig를 깊은 복사하던 경로는 실제로 사용하는 서버·Discord·지정 단어 알림 필드 10개만 독립 복사하도록 제한했다. 기본 설정 구조 20,000회 측정에서 전체 읽기 약 889ms, 선택 읽기 약 72ms로 해당 복사 구간이 약 12.3배 단축됐으며, burst·지속 부하 정합성 검사를 다시 통과했다(`ad5e588`).
- 사용자 허용을 받아 `C:\Nexon\TalesWeaver\ChatLog`의 HTML 46개(약 206MB)를 원문 저장 없이 집계했다. 총 1,536,257줄 중 `XP_CHANGED` 760,066건, `ITEM_LOOTED` 397,905건, `NORMAL_CHAT` 365,814건이었고 실제 활성 초 최대 1,115줄, p95 20줄, p99 39줄이었다. `ITEM_LOOTED+MAGIC_STONE_GAIN` 15,736줄과 `ARCHITECT_MINE_ENTRY+ITEM_LOOTED` 11,453줄처럼 한 줄에서 복수 이벤트가 발생하는 패턴도 확인했다. 이 결과를 기준으로 아이템 획득·외치기·읽기 전용 기믹 알림과 숙제 자동 감지의 전체 config 복사를 각각 필요한 필드만 복사하도록 줄였다. 현재 리셋 주기에 이미 같은 최대 횟수가 저장된 단일 참여 캐릭터 숙제만 파일 저장·UI 갱신·클라우드 dirty 생성을 생략하며, 미완료 횟수 증가·새 리셋 주기·여러 캐릭터 선택은 기존 경로를 유지한다(`ceffbef`).
- 시작 시 32MB 상한 로그의 전체 읽기·정규화는 약 121~141ms, 탭별 최근 150개 replay는 약 114~129ms로 합계 약 250~255ms였다. Tail 연결과 비동기 replay 사이의 실시간 로그 순서 버퍼를 새로 도입할 정도의 이득이 확인되지 않아 제품 코드는 변경하지 않았다.
- 전역/per-window renderer background throttling 해제는 게임 오버레이의 가려진 상태 타이머·알림 시각과 연결된 초기 정책이다. 패키지 유휴 CPU 프로파일 없이 축소하면 회귀 위험이 더 크므로 이번 최적화 범위에서는 유지한다.

AppX 검증은 기존 `twOverlay-2.7.0-beta.1.appx`의 **패키지 구조 검증기 확인**이다. 현재 HEAD로 만든 3.0.0 패키지나 Store 서명 설치본 실행 완료를 뜻하지 않는다.

## 릴리즈 차단 상태

현재 소스 자동 검증에서 추가로 재현되는 제품 결함은 없다. 그러나 다음은 테스트하지 않았으므로 완료로 표시하지 않는다.

1. 현재 HEAD의 관리자 권한 `npm run test:zorder:windows` 재실행
2. 실제 테일즈위버 창모드·창모드 전체화면 장시간 Z-order 실기
3. 실제 Google 계정의 두 PC 순차 동기화·토큰 철회·네트워크 복구
4. Windows 로그오프·재부팅과 DPI·모니터·RDP 실기
5. 최종 3.0.0 NSIS 설치/업데이트 및 AppX 내부 검증
6. Store 서명본의 첫 실행·완전 종료 후 두 번째 실행
7. 외부 갤러리·거래 사이트와 사기 감지 모델의 실제 네트워크 흐름

실행 기록은 `docs/v3-release-manual-test-checklist.md`에 남긴다. 위 필수 항목이 미완료인 상태에서는 3.0.0 릴리즈 준비 완료로 판정하지 않는다.
