# TW-Overlay v3.0.1 사용자 실기 테스트 체크리스트

이 문서는 실제 PC에서 테스트하면서 직접 체크하고 코멘트를 남기는 실행용 문서다. 기술적인 합격 기준과 증거 수집 명령은 [`v3-manual-validation.md`](v3-manual-validation.md)를 참고한다.

## 작성 규칙

- 실제로 확인해 정상인 항목만 `[x]`로 변경한다.
- 실패하거나 애매하면 `[ ]`를 유지하고 코멘트에 증상을 적는다.
- 실패 시 가능하면 `시각`, `PC-A/PC-B`, `직전 동작`, `예상 결과`, `실제 결과`, `debug.log 관련 구간`을 남긴다.
- 이메일, OAuth token, Discord Webhook, 캐릭터 이름, 로컬 절대경로는 문서나 공유 로그에 기록하지 않는다.
- 결함이 발견되면 이후 데이터가 오염될 수 있는 항목은 중단하고 먼저 수정·재검증한다.

## 3. Google Drive와 두 PC 순차 동기화

두 PC에서 같은 Google 계정으로 로그인한다. 기존 개발용 원격 데이터가 섞일 가능성이 있으면 새로운 테스트 계정을 사용한다. 원격 AppData를 임의로 삭제하거나 수정하지 않는다.

- [ ] **CLD-01 — 최초 로그인과 초기 동기화가 정상이다.**
  - 절차: PC-A에서 로그인하고 설정·숙제·메타 세 파일의 전송 완료를 확인한 뒤 PC-B에서 로그인한다.
  - 합격: 체크섬 오류 없이 두 PC의 profile이 `established`가 되고 같은 설정·숙제 상태가 표시된다.
  - 코멘트:
  - 증거/로그:

- [ ] **CLD-02 — PC-A의 숙제 변경이 PC-B에 도착한다.**
  - 절차: PC-A에서 미완료 숙제를 플레이하거나 수동 변경한 뒤 PC-B에서 확인한다.
  - 합격: 게임 실행 중 약 30초 이내에 반영되거나 앱 시작·게임 시작 시 즉시 반영된다.
  - 코멘트:
  - 증거/로그:

- [ ] **CLD-03 — PC-B의 숙제 변경이 PC-A에 도착한다.**
  - 절차: PC-B에서 다른 미완료 숙제를 변경한 뒤 PC-A에서 확인한다.
  - 합격: PC-A의 기존 변경을 잃지 않고 PC-B의 변경도 함께 반영된다.
  - 코멘트:
  - 증거/로그:

- [ ] **CLD-04 — 양쪽 앱을 켜 둔 상태에서 다음 변경도 자동 수렴한다.**

  - 합격: 앱 재시작이나 수동 동기화 없이 변경이 도착한다. 게임 미실행 상태에서는 최대 약 5분까지 기다린다.

  - 사전 조건: 숙제에 캐릭터가 두 명 이상 등록돼 있다.
  - 합격: 수신 PC에서 팝업이 뜨고 사용자가 선택한 캐릭터 한 명에게만 적용된다. `나중에 하기` 후에는 다음 표시 시 다시 나타난다.

> 두 PC에서 1초 이내에 변경하는 물리적 동시 충돌과 같은 숙제의 완료/해제/횟수 충돌은 필수 실기에서 제외했다. 이 정책은 교차 overwrite, 응답 유실과 재시작을 포함한 자동 테스트로 고정돼 있다.
