# v3.0.0 사용자 가이드 전수 감사

감사일: 2026-08-27

## 감사 원본

- 앱 메뉴: `src/assets/data/sidebar_menus.json` 34개
- 관리 창: `src/modules/managedWindowRegistry.ts` 36개
- 설정 검색: `src/settings.html` 검색 인덱스 43개
- 사용자 가이드 탐색: `docs/guide/index.html` 26개 문서 링크(빠른 시작·클라우드 포함)
- 기계 판독 대응표: `.agents/development/guide-coverage.json`

## 결론

- 앱 메뉴 34개는 대응표에 모두 포함했다.
- 감사에서 누락됐던 8개 메뉴의 전용 사용자 문서를 FUP-12에서 추가했다: 디스코드 알림, 테시스 코어 계산기, 사냥 경험치 계산기, 렐릭 강화, 장비 강화·인챈트, 검 강화하기, 사냥터 동선 시뮬레이션, 시간 측정 및 기록.
- `버프 백과 & 계산기`를 포함해 앱 메뉴 34개가 모두 사용자 문서와 가이드 왼쪽 탐색에 연결돼 있다.
- 관리 창 36개도 전용 문서 또는 공유 문서에 모두 연결돼 있으며, `gameOverlay`·채팅 SUB 창·독은 기존 오버레이/채팅 가이드가 함께 설명하는 공유 대상이다.
- 설정 검색 43개는 모두 `settings.md` 하나로 연결돼 있으나, 현재 문서는 실제 설정 화면의 43개 진입점과 사용 흐름을 설명하지 못한다.
- 현재 가이드 탐색의 모든 `data-doc` 링크는 실제 Markdown 파일이 존재한다. 삭제된 파일을 가리키는 링크는 없다.

## 현재 동작과 다른 설명 처리

- `quickstart.md`의 마우스 투과 기본 단축키를 실제 기본값 `Ctrl + Shift + T`로 수정했다.
- `settings.md`를 숨겨진 창 재사용 정책과 실제 저장·동기화 범위 중심으로 재작성했다.
- Fast Ping, 커서와 메뉴 관리는 적용 범위·되돌리기·주의사항을 함께 안내한다.
- 실시간 로그 엔진 문서를 `.agents/development`로 옮기고 사용자 가이드 탐색에서 제거했다.
- Google 동기화의 schema/checksum/revision·전체 allowlist는 `.agents/development/google-drive-sync-contract.md`로 옮기고 공개 문서는 연결·병합·제외·문제 해결만 설명한다.
- `experience-hud.md`는 FUP-17의 HUD 표시와 세션 상태 분리 구현 뒤 실제 기본값과 동작에 맞춰 다시 확인한다.

## 후속 처리 경계

- FUP-11은 누락과 불일치를 식별하고 대응표·정적 검사를 고정하는 단계다. 문서 내용을 추측해 채우지 않는다.
- FUP-12에서 누락 8개 문서를 실제 화면·코드 계약 기준으로 작성하고 기존 문서를 사용자 흐름 중심으로 정리한다.
- 개발용 동기화 계약과 실시간 로그 엔진 설명은 `.agents/development` 아래로 이동하되, 사용자에게 필요한 문제 해결 요약만 공개 가이드에 남긴다.
- FUP-13에서 이미지 뷰어, FUP-14에서 일지 달력 카드의 접기/펼치기를 별도 구현한다.
